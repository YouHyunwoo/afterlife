씬을 단독으로 열고 Game 뷰에 포커스를 둔다. 자세한 과거 변경 배경은 [누적 개발 기록](../records/day-01-history.md)에 보존했다. 과거 기록의 경로와 이전 수치는 최신 구조보다 우선하지 않는다.

After 모든 나무에 잎 스프라이트를 적용하며 기본은 랜덤 회전이다. G로 각 잎의 고정 랜덤 0~360도 회전을 전환한다. L은 잎 스프라이트 표시 여부를 바꾼다. 바닥 풀 회전 실험은 제거했고 기존 바람/호버 표현으로 복구했다.

## 폐허 중앙 수정 발광

After의 Ruins_Pivot에만 청록색 정점 팔레트 기반 HDR 발광을 적용한다. 발광 강도 3.5, 약한 주기 변화 ±4%. URP Bloom threshold 1.15, intensity 0.45, scatter 0.6. 전용 런타임 Volume과 HDR 픽셀 렌더 텍스처를 사용한다. 원래 메시/재질은 보존하고 종료 시 카메라와 PropertyBlock 상태를 복원한다. Bloom은 수정 주변의 화면상 빛 번짐이며 주변 돌을 비추는 실제 광원은 아니다.

검증: C# 12개 어셈블리 빌드 통과. Play 중지/Refresh 후 After에서 수정의 청록 발광과 주변 번짐, N 낮/밤, P 픽셀 전환을 확인한다. GPU/Play 검증은 미실행.

Bloom 연결 보완: 전용 ShowcaseDepthRenderer의 postProcessData가 비어 있었음을 확인했다. Day01BloomSetup이 에디터 임포트 후 URP 기본 PostProcessData를 연결한다. Bloom intensity 0.7, scatter 0.7로 조정했다. 반영 후 실제 빛 번짐 확인 대기.

창문 Bloom 적용: After 공용 Bloom intensity 0.7→0.55, scatter 0.7→0.6으로 낮췄다. 수정 발광량은 유지한다. 창문 팔레트 영역만 밤에 HDR (1.8,1.55,1.25)로 전환해 수정보다 약한 따뜻한 빛 번짐을 만든다. 집 주변 시야 반경과 벽/목재 표현은 유지한다. 낮에는 기존 색이다. Play/GPU 확인 대기.

창문 추가 조정: 고정 크림색 대신 창문 정점색×재질 Tint의 색조를 사용하며 최대 HDR 채널 강도를 1.8→3.4로 높였다. 공용 Bloom 강도/범위와 수정 발광은 유지한다. 밤에만 적용하며 셰이더 GPU 확인 대기.

## After 시작 프리셋

6번 After 진입 시 Pixels ON, 나뭇잎 ON·랜덤 회전, 낮, Dissolve, Rounded 해안, 풀 Sway, 피해 마크 ON을 적용한다. 이후 키/버튼으로 비교할 수 있으며 다른 단계에서 After로 돌아오면 기본 조합으로 복원한다. R은 현재 설정을 유지하고 촬영 상태만 초기화한다.

## 마우스 시야 테스트

안내 패널의 `Mouse vision test` 또는 `V` 키로 전환한다. 기본 OFF이며 OFF에서는 기존 Day01 조명을 사용한다. ON에서는 마우스를 가리킨 지면을 중심으로 원형 시야를 적용하고, 집의 고정 시야를 제외한다. 반경은 기존 Inspector의 CursorVisionRadius(기본 3.2)를 사용한다.

시야 밖에서는 지형/수면만 남기고 풀·잎·오브젝트·연기/먼지는 제거한다. 지형의 시야 밖 밝기는 낮 0.48, 밤 0.15로 유지한다. 일반 오브젝트의 깊이/그림자 패스에도 시야 제거를 적용한다. 맵/패널 밖으로 마우스를 빼거나 앱 포커스를 잃으면 마지막 시야가 0.8초에 걸쳐 사라지고, 다시 들어오면 0.15초에 켜진다. 이동 경로에는 최대 32개 시야 흔적을 남긴다. 기본 1.4초 동안 유지/감쇠하며 Inspector의 VisionTrailSeconds로 조절한다. 처음 20% 시간은 유지하고 이후 부드럽게 사라진다. 빠른 이동은 중간 위치를 보간하고, 정지 상태에서는 최신 흔적을 갱신한다. 조명 테스트이며 알파/디더 비교 기능은 추가하지 않았다.

1. Day01 씬을 실행하고 4번(Life) 또는 6번(After)으로 이동한다.
2. V를 눌러 켜고 마우스를 풀/꽃/장식 주변에서 움직인다. 마우스 중심 원형 시야가 따라야 한다.
3. 패널 위로 마우스를 옮긴다. 마지막 시야가 부드럽게 어두워질 때 풀·타일·장식 대비를 비교한다.
4. 6번 단계에서 N으로 밤을 켜 같은 절차를 반복한다.
5. V를 끄면 기존 조명으로 복귀한다. F8 영상 모드에서는 테스트를 일시 해제하며, 영상 모드 종료 후 선택을 다시 적용한다. 단계 전환 시 마지막 마우스 시야는 초기화한다.

Devlog 21개 C# 모듈 빌드 통과. Unity Play/HLSL 화면 검증은 미실행이다. 씬 재진입 시 중복 시야 오브젝트나 이전 테스트 전역값 잔류가 없어야 한다.

시야 밖 표시 확인: V를 켜고 마우스를 패널 위에 둔 뒤 VisionTrailSeconds 이상 기다린다. 지형/수면은 남고 풀·나무·집·장식은 보이지 않아야 한다. 마우스를 맵으로 옮기면 시야 안 대상만 다시 보이고, V를 끄면 기존 표시로 돌아와야 한다. C# 빌드 통과, HLSL/Play 화면 확인 대기.

잔상 확인: V를 켜고 마우스로 맵을 길게 훑은 뒤 패널로 이동한다. 지나간 경로가 잠시 밝게 남고 오래된 위치부터 어두워져야 한다. 최종적으로 지형/수면만 남고 오브젝트는 숨겨져야 한다. R 초기화·단계 전환·V OFF·영상 모드 진입 시 흔적을 비우며 씬 종료 시 셰이더 전역값을 복원한다. Devlog C# 빌드 통과, Unity/HLSL 화면 검증은 미실행이다.

해안 단면 보정: BlockSoil/BlockSand/BlockRock은 `_Ground=0`인 측면 재질이어서 시야 밖에서 일반 오브젝트처럼 제거되고 있었다. 전용 `_VisionGround` 속성으로 지형 표시를 분리해 색/깊이/그림자 패스에서 단면을 유지한다. 재질 생성 경로에도 반영했다. Unity에서 V를 켜고 시야를 해안 밖으로 이동했을 때 윗면에서 수면으로 내려가는 단면이 남아 있어야 한다. C# 빌드와 별개로 실제 HLSL/화면 확인은 미실행이다.

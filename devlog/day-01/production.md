# Day01 제작 목표와 촬영 계획

## 확정한 방향

마케팅 목적의 Devlog다. 개발량을 나열하기보다 화면의 변화와 클릭 반응으로 게임의 품질을 전달한다. 기존 중세 판타지 모델을 사용하며 새 모델링은 하지 않는다. 녹화는 사용자가 필요한 부분을 선택해서 진행한다.

게임의 기본 지형은 평지다. 표현용 타일 내부 굴곡은 있으며 이동 규칙에 고저차를 추가한 것은 아니다. 완성본을 먼저 다듬은 다음 중간 단계를 더 나눈다.

## 현재 공간

|키|공간|위치|내용|
|---|---|---|---|
|1|Before_Primitives|(0, 0, 0)|기본 도형과 단순 지형|
|2|Process_ModelPlacement|(50, 0, 0)|기존 모델과 색상 배치|
|3|After_PixelForest|(100, 0, 0)|블록·바이옴·픽셀·물·식생·상호작용|

각 공간은 12×10 타일이다. 같은 카메라 구도로 차이를 비교한다. 위치 사이의 빈 공간과 AdditionalTakeSpace는 추가 촬영에 사용할 수 있다.

## 촬영 구성 제안 — 아직 채택/구현하지 않음

|순서|보여줄 변화|시청자가 느낄 핵심|
|---|---|---|
|도입|완성 맵에서 나무·돌을 한 번씩 타격|만지고 싶은 환경|
|기본 형태|Before → 모델 배치|익숙한 도형이 세계가 되는 과정|
|지형 표현|색 → 블록·굴곡·바이옴 혼합|작은 맵의 밀도|
|환경 표현|풀·물·눈·집 연기|정적인 모델이 살아나는 변화|
|반응|호버·타격·파괴·소리|클릭의 즐거움|
|마무리|낮/밤, 동일 구도 Before/After|짧고 명확한 전후 비교|

각 효과를 별도 공간으로 복제할지, 같은 공간의 토글로 촬영할지는 다음 결정 사항이다. 영상 길이와 컷 수는 아직 확정하지 않았다.

## 공개 전

게임/영상 크레딧은 [음원 크레딧 지침](../../docs/audio-credits.md)을 따른다. 개발 문서에 출처를 적은 것과 영상 설명란 반영 완료는 별개다.

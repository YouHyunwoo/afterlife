# Day01 제작 목표와 촬영 계획

## 확정한 방향

마케팅 목적의 Devlog다. 개발량을 나열하기보다 화면의 변화와 클릭 반응으로 게임의 품질을 전달한다. 기존 중세 판타지 모델을 사용하며 새 모델링은 하지 않는다. 녹화는 사용자가 필요한 부분을 선택해서 진행한다.

게임의 기본 지형은 평지다. 표현용 타일 내부 굴곡은 있으며 이동 규칙에 고저차를 추가한 것은 아니다. 완성본을 기준으로 단계별 표현을 분리해 전후 차이를 촬영한다.

## 6단계 공간 — Unity 씬·프리팹 저장 완료

최신 After의 배치를 기준으로 앞의 다섯 공간을 구성한다. 원래 개발 시점의 재현이 아니라 화면 변화가 명확한 순서로 정리한 촬영용 단계다.

|키|위치 X|단계|화면 변화|
|---|---:|---|---|
|1|0|Before|회색 기본 도형, 평면 격자|
|2|20|형태와 스타일|기존 모델, 기본 바이옴 색, 픽셀 출력|
|3|40|지형과 물|블록 굴곡, 지형 경계 혼합, 해안, 깊이와 거품|
|4|60|살아 있는 환경|풀·꽃·장식, 잎 빌보드, 바람, 눈, 연기, 환경음|
|5|80|상호작용|호버, 타격, 자국, 파괴·디졸브, 효과음|
|6|100|After|현재 완성본, 낮/밤, 시야, 수정과 창문 발광|

각 공간은 12×10 타일이며 같은 카메라 구도를 사용한다. 숫자 키와 패널의 6개 버튼으로 전환한다. 이전 Before/Process는 비활성 보관하고 원본 After는 100 위치에 유지한다. [설치·보존·확인 절차](../records/stage-progression.md).

## 촬영 구성

1. After에서 짧은 타격 장면으로 완성 모습을 먼저 보여준다.
2. Before로 돌아가 같은 화면에서 1→2→3을 차례로 비교한다.
3. 4에서는 풀·잎·눈·연기의 움직임을 보여준다.
4. 5에서는 같은 나무/바위의 호버와 타격, 파괴를 보여준다.
5. 6에서는 밤과 창문·수정의 빛으로 마무리하고 Before/After를 다시 비교한다.

H로 패널 숨김, R로 테이크 초기화. 영상 길이와 컷 수는 아직 확정하지 않았다.

## 공개 전

게임/영상 크레딧은 [음원 크레딧 지침](../../docs/audio-credits.md)을 따른다. 개발 문서에 출처를 적은 것과 영상 설명란 반영 완료는 별개다.

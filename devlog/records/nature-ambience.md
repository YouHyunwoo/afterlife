# 풀 접촉음·간헐적 새 소리

- 작업일: 2026-09-20
- 변경 전: After에서 바람과 풀 소리가 상시 반복됐다.
- 변경 후: 바람 소리를 제거하고 풀 소리는 마우스로 실제 풀 군락을 스칠 때만 재생한다. 새 울음은 유지한다.

## 동작과 설정

- 바람 AudioSource 생성·클립 로딩·볼륨 설정·Wind 오디오 연동 제거. 시각적 바람은 그대로다. 기존 wind 파일은 미사용 보관본이다.
- 풀은 실제 생성된 After 풀의 밑동 위치와 폭에 따른 지면 접촉 영역으로 판단한다. GPU 빌보드의 투명 픽셀 단위 판정은 아니다. 빈 군락과 장애물 때문에 풀이 생성되지 않은 곳은 제외된다.
- After의 유효한 지면 선택과 실제 마우스 이동이 모두 있을 때 풀 소리가 난다. UI 위, 화면 밖, 앱 포커스 이탈, 오브젝트에 가린 지면, 커서 정지에서는 추가 재생을 하지 않는다.
- 풀 소리는 사용자가 선택한 2·3·4번(0.60/0.70/0.70초)만 랜덤 선택한다. 1번은 재생 목록에서 제외했다. 직전 클립 연속 선택과 중첩을 막고, 클립 종료 후 0.06~0.16초 간격을 둔다. 마우스 정지/풀 이탈 시 새 재생을 멈추되 이미 시작한 짧은 여운은 끝까지 보존한다. After 이탈 시 0.12초 페이드 아웃한다.
- 새 울음은 낮 진입 후 3~8초, 울음 종료 후 9~23초 대기한다. 피치 ±3%, 좌우 ±0.55, 음량 80~100% 변형 유지. 밤에는 1초 페이드 아웃하고 추가 울음을 멈춘다.
- R은 두 채널과 타이머 초기화. OnDisable은 채널 중지·오브젝트 제거·이벤트 구독 해제.
- Day01Showcase Inspector의 Ambience: GrassVolume 0.28, BirdVolume 0.38, BirdMinimumGap 9, BirdMaximumGap 23.

## 구조·출처

AmbientAudio.Core는 엔진 비의존 타이머/페이드, Runtime은 주입된 음원/상태의 재생을 담당한다. Vegetation은 실제 풀 배치의 접촉 영역을 제공하며 Day01이 입력 판정과 오디오를 조합한다. 공용 모듈 사이의 직접 참조를 추가하지 않았다.

실녹음은 Freesound CC0 HQ MP3 미리듣기에서 편집했다. [음원 출처와 편집 기록](../../docs/audio-credits.md), `res/audio/nature-ambience/sources.json`, `prepare.py`, `analysis.json`에 원 자료와 변환 이력을 보관한다. 추가 편집은 `extract_grass_variants.py`로 재현한다. 기존 grass.wav의 0.10~0.65, 1.55~2.15, 4.15~4.85, 6.45~7.15초를 발췌하고 피크 완화·35ms 시작/140ms 끝 페이드·RMS -25dBFS 조정했다. 결과와 해시는 `grass-variants-analysis.json`, 발췌본은 `grass-variants/`, 순서대로 듣는 미리듣기는 `grass_variants_preview.wav`다. Unity는 Resources/DevlogAmbience/GrassRustles만 풀 음원으로 로딩한다. 파형 기준 선정이며 실제 청취는 사용자 확인 대기다.

## 검증

- `dotnet build --no-restore`로 의존 순서대로 Devlog 17개 모듈 통과. 기존 ShowcaseTarget CS0252 경고는 유지.
- 에디터 재시작 뒤 Unity의 AmbientAudio DLL과 Day01 프로젝트 참조가 생성된 것을 확인했다. 이전에는 별도 빌드만 통과하고 Unity 임포트가 누락돼 있었으므로 두 상태를 구분한다.
- Unity Play/Test Runner와 실제 청취는 실행하지 않았다.

## 사용자 확인 절차

1. Day01 Play → 3번 After: 커서를 멈추면 바람/풀 소리가 없어야 하고, 새 울음만 간헐적으로 들려야 한다.
2. 실제 풀 군락 위로 마우스를 움직이면 풀 소리가 나고, 정지하거나 빈 땅/물/UI로 이동하면 새 소리가 시작되지 않고 재생 중인 0.60~0.70초 클립만 마무리되어야 한다. 연속 스침에서는 선택한 세 가지 음색이 랜덤으로 바뀌며 직전 클립이 연속 반복되지 않아야 한다.
3. N으로 밤 전환: 새 울음이 사라지되 풀 접촉음은 작동해야 한다.
4. 1/2번 공간 전환·R 초기화·Play 종료/재진입: 풀 소리가 남거나 중복되지 않아야 한다. 기존 타격/물 효과음도 확인한다.

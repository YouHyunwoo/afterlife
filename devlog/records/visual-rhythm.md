# 화면 밀도와 타격 타이밍 보완

## 작업 목록
- [x] 해안 중심 거품과 물 중앙 여백
- [x] After 풀·꽃 군집과 빈 공간, 기존 장식 재사용
- [x] 접촉 시 짧은 정지·빠른 복귀·방향성 파편
- [x] C# 빌드와 변경 기록

기존 거품 레이어·색·시드와 표면 접촉 위치를 유지한다. 새 모델은 만들지 않는다. Before/Process의 풀 분포는 유지하고 After에서만 군집을 적용한다. Play/GPU 테스트는 실행하지 않는다.

## 변경 전후

|대상|이전|변경|
|---|---|---|
|거품|흰색 하한이 물 중앙까지 강하게 적용|해안 0.48m 이내 집중, 중앙은 큰 노이즈 군집과 옅은 잔여 거품|
|기본 풀|대부분 위치에서 중간 이상의 생성 확률|After 고정 좌표 노이즈에 따라 약 3.5~88%(숲 최대 94%) 확률|
|꽃|풀마다 2% 독립 추첨|별도 꽃 군집 안에서 모여 피고 밖에서는 기본 풀 유지|
|기존 꽃·고사리 장식|타일별 분산|군집 밖 일부만 실행 중 숨기고 Dispose에서 원래 활성 상태 복원|
|도구|접촉 직전 감속, 0.05초 접촉 후 회수|접촉 직전까지 가속, 0.045초 접촉, 전체 동작 0.285초|
|피격 반응|바로 시작하는 감쇠 진동|동일 정지 구간 뒤 반대 방향 반동, 감쇠를 높여 빠르게 안정|
|플래시|Update 순서에 따라 시작|Hit에서 즉시 적용, 짧은 유지 후 부드럽게 종료|
|파편|월드 수평 방사형|표면 바깥 방향 원뿔로 방출, 교차점 색 유지|

타격음과 파편은 기존 단일 접촉 이벤트에서 함께 시작한다. 전역 timeScale이나 다른 오브젝트의 애니메이션은 멈추지 않는다. 파괴 타격의 기존 효과음·바위 조각 동작과 눈 파편의 하강은 유지한다.

## 파일과 수명

- Water의 ShowcaseWater.shader: 거품 공간 분포
- Vegetation의 ShowcaseGrass.cs: 고정 군집, 런타임 장식 숨김/복원
- Destruction의 ShowcaseImpactTiming.cs: 도구와 타깃이 공유하는 정지·반동·플래시 수치
- Day01Showcase/ShowcaseTarget: 접촉 이벤트와 시각 반응 조합

## 검증 및 사용자 확인

2026-09-20: 12개 Devlog 모듈 dotnet build --no-restore 통과. Unity TestRunner/Play/GPU 테스트는 실행하지 않았다.

Play를 멈추고 최신 코드가 임포트된 뒤 다시 Play → 3번 After에서 확인한다.

1. 물 중앙의 반복 거품은 옅고 해안 거품과 접촉선이 더 또렷한지 확인한다.
2. 풀·꽃이 군집을 이루고 바닥이 드러나는 여백이 있는지 확인한다. 재실행해도 위치가 바뀌지 않아야 한다.
3. 나무와 바위에 타격 시 실제 날이 표면에 도착할 때 소리·플래시·파편이 시작하고, 짧은 접촉 유지 후 회수되는지 확인한다.
4. 눈 나무와 파괴 타격, R 초기화 및 1/2/3 공간 전환의 기존 동작을 확인한다.

# 기능 모듈 적용 지침

새 기능과 기존 기능의 재사용 버전을 만들 때 다음을 기본 조건으로 삼는다.

1. **한 번의 추가로 시작한다.** 씬에 프리팹 하나를 배치하거나 대상 오브젝트에 컴포넌트 하나를 추가하는 경로를 먼저 제공한다. 여러 요소가 필요한 기능은 조립된 프리팹도 함께 제공한다.
2. **기능별 책임을 분리한다.** 순수 규칙과 상태는 Unity에 의존하지 않는 코어에, 표시·입력·에셋 수명은 Unity 컴포넌트에 둔다. 프리팹은 내부 참조를 저장하거나 자식 컴포넌트를 자동 탐색한다.
3. **게임별 연결은 어댑터에서 한다.** 공용 모듈이 특정 씬 경로, 게임 상태 enum, 모델, 전역 싱글턴을 직접 참조하지 않게 한다. 명령과 결과는 작은 메서드·이벤트로 전달한다.
4. **안전한 수명을 제공한다.** 초기화, 중복 이벤트 차단, 비활성화·씬 해제 시 구독과 RenderTexture·Material 등의 정리를 모듈 안에서 처리한다. 기존 직렬화 참조와 게임 소비자를 보존한다.
5. **설치와 검증을 기록한다.** 필수 외부 참조, 프리팹/컴포넌트 추가 순서, 게임별 어댑터 연결, 컴파일 명령, 사용자가 확인할 플레이 절차를 기능 문서에 적는다. 한 번 추가하는 경로가 불가능하면 이유와 필요한 최소 연결을 명시한다.

ThresholdLab 화면 모듈과 프로토타입 연결은 [적용 기록](../game-process/62-threshold-prototype-integration.md)을 예제로 삼는다.

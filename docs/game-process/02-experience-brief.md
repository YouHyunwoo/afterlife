# 타깃과 핵심 경험 · 확정

> 최신 규칙: 초반의 모든 커서 작업은 대상 직접 클릭 1회로 실행하며, 자동화 강화 후에만 호버 주기 작업이 열린다. 아래의 시작부터 자동 기여 설명/과거 QA는 변경 전 기록이다. [최신 규칙·구현·검증](46-click-work-and-automation.md).


- 핵심 요약: 복잡한 개별 유닛 조작 부담을 줄이고, 주민·커서 강화와 마을 방어 투자 판단의 재미를 제공한다.
- 상태: 사용자 채택. M1 기획 정리 완료. 재미·시장성은 실제 검증 전이다.

## 주 타깃 · 사용자 채택

복잡한 유닛 조작 부담 없이 마을 성장과 웨이브 방어의 투자 판단을 즐기고 싶은 플레이어.

## 핵심 경험 · 사용자 채택

주민과 강화를 늘릴수록 커서 작업 능력이 강해지고, 내가 키운 마을이 더 강한 공격을 버텨내는 성취감.

## 반복 동기 · 사용자 채택

위험을 감수하고 다음 웨이브에 도전할지, 지금 환생해 더 강한 상태로 재도전할지 선택하는 재미.

## 이를 만드는 규칙

주민은 인원 수로 커서 범위·작업 효율을 높이고, 일반 스킬 트리는 범위 증가율 효율·작업 효율을 강화한다. 커서 지휘에 주민이 자동 배정되는 컨셉이며 수동 주민 지휘는 없다. 원형 범위 자동 기여로 채집·건설·수리를 수행한다. 병력은 별도로 생산해 마을 주변에 배치·순찰한다. 준비 시간 뒤 웨이브가 시작하며 집이 모두 파괴되면 다른 건물이 남아 있어도 패배한다.

환생은 제단 조건을 충족한 상태에서 웨이브 종료 후 정비 시간에 가능하다. 일반 강화와 마을 진행은 초기화하고 환생 강화·남은 특수 재화는 같은 판 안에서 유지한다. 최종 클리어·패배 시 강화는 초기화하며 콘텐츠 영구 해금이 다음 판의 선택지를 넓힌다. 판 종료 시 특수 재화 처리는 아직 미정이다.

## 설계 검토 기준

- 주민 개별 지휘를 다시 늘리지 않고 범위·투자·병력 배치 선택에 집중한다.
- 주민 증가와 범위 강화의 복합 효과가 과도한 성장으로 이어지는지 확인한다.
- 깊은 웨이브 도전과 환생 중 한쪽만 정답이 되지 않는지 확인한다.
- 타깃과 의도 확정은 실제 재미 검증을 뜻하지 않는다. 수치·콘텐츠·세부 입력은 M2 이후 설계·검증한다.

## 세계관 · 사용자 채택

중세 판타지 마을에 슬라임·고블린·오크·리자드 등 마물들이 침공한다. 신을 모시는 제단이 존재한다. 신의 정체와 환생 원리는 아직 미정이며 플레이어를 신으로 확정하지 않는다.

# 타깃과 핵심 경험 · 확정

> 현재 조작(2026-09-24): 영력을 써서 위치에 8초 유지되는 필드를 설치한다. 필드는 커서와 무관하게 범위 안 대상을 주기적으로 처리한다. 대상 클릭·빈 타일 Shift+클릭이 설치 입력이며 R8은 작업 간격을 줄인다. 아래의 과거 입력·QA 기록은 당시 버전 설명이다. [현재 구현·검증](47-divine-interaction-fields.md).


- 핵심 요약: 복잡한 개별 유닛 조작 부담을 줄이고, 영력 필드의 위치·시점과 마을 방어에 투자하는 판단의 재미를 제공한다.
- 상태: 사용자 채택. M1 기획 정리 완료. 재미·시장성은 실제 검증 전이다.

## 주 타깃 · 사용자 채택

복잡한 유닛 조작 부담 없이 마을 성장과 웨이브 방어의 투자 판단을 즐기고 싶은 플레이어.

## 핵심 경험 · 사용자 채택

주민과 강화를 늘릴수록 영력 필드의 작업 능력이 강해지고, 내가 키운 마을이 더 강한 공격을 버텨내는 성취감. 핵심 조작은 직접 반복 작업이 아니라 지금 영력을 어느 장소에 투자할지 빠르게 판단하는 것이다.

## 반복 동기 · 사용자 채택

위험을 감수하고 다음 웨이브에 도전할지, 지금 환생해 더 강한 상태로 재도전할지 선택하는 재미.

## 이를 만드는 규칙

주민은 인원 수로 작업 효율과 필드 반경을 높이고, 일반 스킬 트리는 반경·작업량·주기를 강화한다. 영력 30을 투자하면 설치 좌표에 8초 유지되는 필드가 생성되어 범위 안에서 채집·건설·수리·공격을 주기적으로 수행한다. 병력은 별도로 생산해 마을 주변에 배치·순찰한다. 준비 시간 뒤 웨이브가 시작하며 집이 모두 파괴되면 다른 건물이 남아 있어도 패배한다. [구현 규칙](47-divine-interaction-fields.md)

환생은 제단 조건을 충족한 상태에서 웨이브 종료 후 정비 시간에 가능하다. 일반 강화와 마을 진행은 초기화하고 환생 강화·남은 특수 재화는 같은 판 안에서 유지한다. 최종 클리어·패배 시 강화는 초기화하며 콘텐츠 영구 해금이 다음 판의 선택지를 넓힌다. 판 종료 시 특수 재화 처리는 아직 미정이다.

## 설계 검토 기준

- 주민 개별 지휘를 다시 늘리지 않고 범위·투자·병력 배치 선택에 집중한다.
- 주민 증가와 범위 강화의 복합 효과가 과도한 성장으로 이어지는지 확인한다.
- 깊은 웨이브 도전과 환생 중 한쪽만 정답이 되지 않는지 확인한다.
- 타깃과 의도 확정은 실제 재미 검증을 뜻하지 않는다. 수치·콘텐츠·세부 입력은 M2 이후 설계·검증한다.

## 세계관 · 사용자 채택

원래 세계는 마물이 존재하는 중세 판타지 세계다. 영웅의 운명은 출생 시 정해지고, 선택된 아이는 성인이 될 때 잠들어 사후세계에서 영웅 자격의 시험을 받는다. 주인공은 플레이어 자신이며 몸 없이 주어진 영력으로 마을 재건을 돕고 밤의 마물 침공을 막아 일정 기간 생존시킨다. 통과하면 현실로 귀환하고 이후 영웅으로서 마왕 드래곤을 처치하는 서사로 이어진다. 현재 게임 범위는 시험과 귀환까지다.

신을 모시는 제단은 기존 설정으로 유지한다. 신의 정체와 기존 환생의 원리·시험의 관계는 미정이다. 시험 마을은 실제 원래 세계의 지역으로 확정했다. 플레이어는 신이 아니라 영웅 후보로 구체화했다. 자세한 설정과 화면 방향은 [53 사후세계 설정과 화면 연출](53-afterlife-world-and-screen-direction.md).

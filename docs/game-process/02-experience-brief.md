# 타깃과 핵심 경험 · 확정

> 확정 기획 · 2026-10-03: 채집·건설·수리·공격은 버튼을 누르고 있는 동안 작업 주기에 맞춰 반복하고, 강화는 작업 1회당 효과을 높인다. 자동 수입은 농장 건설·생산 강화로 확장한다. 본편 상호작용 필드·슬롯·충전·호버 자동 작업은 폐기한다. [새 규칙·사용법·검증](71-click-work-and-farm-automation.md). 새 규칙은 게임 코드·에셋에 아직 적용하지 않았다. 이전 규칙·수치·QA는 당시 기록으로 보존한다.

- 핵심 요약: 버튼 유지 작업으로 첫 마을을 만들고, 농장 생산이 성장하면서 마을 운영·방어 판단에 집중한다.
- 상태: 사용자 채택 · 기획 갱신 완료 · 새 규칙의 실제 경험 검증 전.

## 주 타깃

복잡한 유닛 조작 부담 없이 마을 성장과 웨이브 방어의 투자 판단을 즐기고 싶은 플레이어.

## 핵심 경험

처음에는 버튼을 누르고 채집해 번 돈으로 마을을 만든다. 이후 농장과 생산 강화가 수입을 맡고, 플레이어는 시설·병력·방어에 투자하면서 필요한 자원을 채집하거나 급한 공사·수리·적에 직접 개입한다. 같은 유지 입력에서 작업 1회당 더 많은 결과를 만든다.

## 이를 만드는 규칙

- 유효 대상에서 버튼 유지 중 주기별 작업 반복. 채집량·공사량·수리량·피해를 강화한다.
- 농장은 완공 뒤 자동 골드 생산, 생산량·주기 강화로 효율 증가. 기존 인접·비옥 보너스 유지.
- 건물 기본 자동 공사, 군사 무료 자동 충원·골드 가속, 병력·타워 자동 전투 유지.
- 필드 설치와 슬롯·충전 학습을 요구하지 않는다. 본편 주민/인구는 64에서 제거된 상태를 유지한다.
- 한 판 10일·25~30분을 목표로 검토하며 환생 없는 MVP 방향 유지. 세부 시간·침공·영구 해금은 기존 제안/미검증 상태.

## 검토 기준

첫 유지 작업의 반복/중단 결과와 첫 농장 생산을 알아볼 수 있는가. 중후반에 장시간 직접 채집에 붙잡히지 않고 기본 운영을 유지할 수 있는가. 회당 작업 효율이 농장을 무의미하게 만들거나 농장만 늘리는 것이 정답이 되지 않는가. 급한 수리·공사·공격이 병력 배치와 생산 판단을 방해할 만큼 오랜 직접 작업 유지를 요구하지 않는가.

## 세계관 · 사용자 채택

원래 세계는 마물이 존재하는 중세 판타지 세계다. 영웅의 운명은 출생 시 정해지고, 선택된 아이는 성인이 될 때 잠들어 사후세계에서 영웅 자격의 시험을 받는다. 주인공은 플레이어 자신이며 몸 없이 주어진 영력으로 마을 재건을 돕고 밤의 마물 침공을 막아 일정 기간 생존시킨다. 통과하면 현실로 귀환하고 이후 영웅으로서 마왕 드래곤을 처치하는 서사로 이어진다. 현재 게임 범위는 시험과 귀환까지다.

신을 모시는 제단은 기존 설정으로 유지한다. 신의 정체와 기존 환생의 원리·시험의 관계는 미정이다. 시험 마을은 실제 원래 세계의 지역으로 확정했다. 플레이어는 신이 아니라 영웅 후보로 구체화했다. 자세한 설정과 화면 방향은 [53 사후세계 설정과 화면 연출](53-afterlife-world-and-screen-direction.md).

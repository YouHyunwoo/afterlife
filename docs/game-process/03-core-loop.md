# 한 판의 흐름 · 마우스 자동 행동과 지휘 병행

규칙→행동→경험 연결과 미검증 위험은 [04 규칙·행동·경험](04-mda-risks.md)을 따른다.

## 2026-09-16 최신 변경 · 사용자 피드백 반영

기존 클릭 고정 기여·영역 인구 보너스·커서 필수 공사·자동 환전 규칙은 대체되었다. 커서는 마우스를 따라 기본2초마다 기여하며 주기는 스킬로만 단축한다. 주민은 집에서만 공급하고 집당 주민 수를 강화한다. 주민은 회당 기여량/반경을 높인다. 공사는 자동+커서지원이며 자동 속도 강화가 있다.

낮/황혼/밤/새벽 정산과 공유 시야·마우스 탐험·잔상·임의 암흑 침공을 추가했다. 귀중품은 새벽에 돈으로 정산한다. 에테론은 환생 전용이다. 교역소는 클릭 모달의 재료별 비율 슬라이더와 환전 버튼으로 한 번 판매하며1개 제한은 유지한다. 병영은 생산/병종 목록 모달, 모든 모달ESC. 병력 클릭/박스 선택과 선택 몸체 드래그 공격 이동, 비중첩·배회. 카메라는 화면 가장자리까지의 최소 거리별 직사각형 구간 속도를 사용하며 중앙에서는 정지한다.

구체 구현/가설 수치·검증 상태는 [10 플레이 피드백 반영](10-playtest-revision.md)을 따른다. 이전 절의 대체된 규칙/첫 계산을 현행으로 사용하지 않는다.


- 핵심 요약: 마우스 기반 자동 행동과 마을 지휘를 함께 수행한다. 제한 준비 시간 후 웨이브 자동 시작은 채택되었으며 세부 조작은 미정이다.
- 채택: 마우스 자동 채집 등 자동 행동과 지휘 병행, 채집과 건물 고도화로 반복 웨이브 대비, 최종 웨이브 방어 시 클리어, 시간 안에 대비하는 긴장감.
- 증거: 사용자 방향 선택. 아래 세부 설계는 AI 제안이며 플레이 검증 없음.

## 플레이어와 자동 행동 · 제안

| 플레이어의 결정 | 자동으로 실행할 행동 |
|---|---|
| 기본 작업 상태에서 위치 클릭 | 커서 자체가 지정한 원형 범위 안의 오브젝트들에 채집·건설·수리. 기본 작업 상태 우클릭으로 취소 |
| 주민 수 증가에 투자 | 주민 수에 따라 커서 범위·작업 효율 향상 |
| 건물 위치, 생산·연구에 쓸 자원 선택 | 배치 시 건설 비용 지불 후 커서 기여로 공사 진행 |
| 병력의 마을 주변 방어 위치 배치 | 순찰하며 적 방어（사용자 방향 채택, 구체 교전·복귀 규칙 미정） |
| 위기 때 스킬 대상과 시점 선택 | 선택한 효과 실행과 재사용 대기시간 처리 |

작업 완료·자원 고갈 시 반복 명령을 얼마나 줄일지는 후속 규칙으로 정한다. 적 추격 때문에 방어선이 무너지는 일을 막도록 기본 병력 행동은 지정 위치 주변 방어를 제안한다. 정확한 범위와 이동 중 교전은 미정이다.

주민 개별 지휘는 제거되었다. [조작 문서](06-player-flow.md)의 인구 기반 커서 기여를 따른다. 병력 지휘 세부 입력은 미정이다.

## 반복 흐름 · 제안

1. 시작: 집 1채·주민 1명·상한 1, 목재 0·석재 0으로 출발한다. 첫 건설 재화는 커서로 자연 자원을 채집해 마련한다.
2. 준비: 다음 적의 주요 특징과 진입 방향을 확인한다. 재화를 인구·커서 강화와 방어 준비에 나눠 쓴다.
3. 방어: 병력은 자동 교전하고 플레이어는 재배치·커서 수리·스킬로 위기에 대응한다. 전투 중 채집·건설도 계속되지만 범위 배치에 따라 어디를 지원할지 선택한다.
4. 종료 판정: 해당 웨이브의 스폰이 끝나고 남은 적을 처리하면 다음 준비로 넘어가는 안을 제안한다. 단순 스폰 종료와 방어 성공을 구분한다.
5. 복구·발전: 다음 준비 시간 안에서 피해를 수리하고 생산·병력·기술을 개선한다. 웨이브 성과를 기록하고 에테론은 정산 시 획득한다（최신 사용자 변경）.
6. 최종 방어 성공 또는 패배: 판을 끝내고 일반·환생 강화를 초기화한다. 조건에 따른 콘텐츠 영구 해금은 유지한다. 집이 모두 파괴되면 다른 건물·병력이 남아 있어도 패배한다.

## 채택된 준비 방식

사용자 채택: **제한된 준비 시간 뒤 자동으로 웨이브 시작**. 시간 안에 대비하는 긴장감을 원한다. 첫 준비 90초·웨이브 간 정비 30초를 초기 기준으로 채택했으며 조기 시작 기능은 채택하지 않았다.

기존 준비 완료 버튼 대안은 현재 채택하지 않는다.

추천의 위험: 초심자에게 시간 압박과 동시 명령이 과도할 수 있다. 첫 웨이브 안내, 배속·일시정지 허용 여부는 후속 UX 설계에서 검토한다. 15웨이브와 준비 시간은 첫 밸런스 기준이며 플레이 검증에 따라 조정한다.

## 가상 장면 · 실제 테스트 아님

다음 적이 동쪽에서 빠르게 접근할 예정이다. 플레이어는 커서 기여 범위를 석재 채집 위치에서 방어 시설 건설 위치로 옮기고 병력을 동쪽에 배치한다. 전투가 시작되면 커서 수리와 스킬로 대응한다. 방어 후 파손 시설을 수리할지 생산 시설을 늘릴지 결정한다.

이 장면이 재미있다는 증거는 아직 없다. 생산 투자와 방어 투자 모두 유효한지, 기여 범위 이동이 반복 노동이 되는지, 적 예고가 선택에 충분한지 검증해야 한다.

## 같은 판 안의 환생 · 채택

새 게임 시작 → 준비·웨이브 반복 → 웨이브 종료 후 정비 시간에 환생 선택 → 환생 화면에서 강화 → 첫 웨이브부터 재진행 → 최종 클리어 또는 패배 → 콘텐츠 해금 판정과 해당 판 강화 초기화 → 새 게임.

환생은 같은 판의 진행을 되돌리는 행동이다. 일반 강화는 환생 시 초기화하며 환생은 제단 조건을 충족한 정비 시간에 가능하며 에테론은 웨이브 클리어 즉시 지급하지 않고 정산 시 획득한다. 환생 강화는 그 판이 끝날 때까지 유지한다. 정확한 유지 표는 [성장 문서](05-system-map.md)를 따른다. 도식에 환생이 들어가도 매 판 필수 환생으로 확정한 것은 아니다.

일반 스킬 트리 강화는 연구소 조건을 충족한 뒤 웨이브 진행 중 재화로 수시 구매한다. 영구 해금은 새 병종·건물·스킬을 사용할 선택지로 제공하며 구체 조건은 미정이다.

에테론은 정산 시 획득하도록 변경되었다. 도달 웨이브·처치 횟수·남은 재화의 반영 방식과 최종 승패 시 지급 여부는 검토 중이며 정확한 계수·집계 범위는 [경제 문서](05-system-map.md)의 제안과 미정 항목을 따른다.

환생 시 마을·주민·병력·일반 재화·일반 강화는 시작 상태로 초기화한다. 환생 강화와 미사용 특수 재화, 영구 해금은 유지한다. 판 종료 후 특수 재화 잔액 처리는 미정이다.

최신 선행 조건은 [06 콘텐츠 문서](06-player-flow.md)를 따른다. 집당 주민 +1, 연구소의 일반 강화·기사 해금, 제단의 마법탑·마법사·환생·일부 노드 해금을 적용한다.

## 판 종료와 에테론 지급 · 사용자 확정

- 에테론은 환생할 때 이번 진행 성과를 정산해 지급한다. 웨이브 클리어 또는 최종 클리어·패배 시에는 지급하지 않는다.
- 환생은 같은 판 안의 재시작이므로 기존 환생 강화와 미사용 에테론을 유지하며, 새 정산분으로 환생 강화를 구매할 수 있다. 마을·주민·병력·일반 재화·일반 강화는 시작 상태로 초기화한다.
- 최종 클리어·패배하면 해당 판은 종료된다. 에테론 잔액·환생 강화·일반 강화·재화·마을·병력 등 모든 판 내부 진행 데이터는 다음 판에 이월하지 않는다.
- 판 종료 성과로 영구 해금 조건을 판정하고 해금 결과를 보존한 뒤 판 데이터를 초기화한다. 영구 해금만 다음 판에도 유지하며, 새 판은 정의된 시작 상태로 시작한다.
- 이는 게임 진행 데이터의 유지 규칙이다. 환경설정 등 비플레이 데이터 삭제를 뜻하지 않는다. 이전 문서의 판 종료 에테론 잔액 미정·종료 시 지급 검토는 이 결정으로 대체한다.
- 돈·교역소 및 구체 환산 계수는 여전히 제안 상태다. 이번 결정으로 함께 채택하지 않는다.

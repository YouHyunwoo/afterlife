# 주민·건물·자원의 성장 구조

## 2026-09-16 최신 변경 · 사용자 피드백 반영

기존 클릭 고정 기여·영역 인구 보너스·커서 필수 공사·자동 환전 규칙은 대체되었다. 커서는 마우스를 따라 기본3초마다 기여하며 주기는 스킬로만 단축한다. 주민은 집에서만 공급하고 집당 주민 수를 강화한다. 주민은 회당 기여량/반경을 높인다. 공사는 자동+커서지원이며 자동 속도 강화가 있다.

낮/황혼/밤/새벽 정산과 공유 시야·마우스 탐험·잔상·임의 암흑 침공을 추가했다. 귀중품은 새벽에 돈으로 정산한다. 에테론은 환생 전용이다. 교역소는 클릭 모달의 재료별 비율 슬라이더와 환전 버튼으로 한 번 판매하며1개 제한은 유지한다. 병영은 생산/병종 목록 모달, 모든 모달ESC. 병력 클릭/박스 선택과 선택 몸체 드래그 공격 이동, 비중첩·배회. 카메라는중심400px이내정지·바깥비선형가속.

구체 구현/가설 수치·검증 상태는 [10 플레이 피드백 반영](10-playtest-revision.md)을 따른다. 이전 절의 대체된 규칙/첫 계산을 현행으로 사용하지 않는다.


> 최신 변경: 주민은 커서 공격 효율도 높인다. 특수 재화 명칭은 에테론이며 웨이브 클리어 즉시 지급은 폐기하고 정산 시 획득한다. 아래 이전 지급표·공격력 분리 제안은 현행 규칙이 아니다. 돈·교역소는 문서 마지막의 검토안 참조.

- 핵심 요약: 목재·석재를 생산과 방어에 투자하고 건물 고도화로 상위 병력·스킬을 확보하는 구조를 제안한다.
- 상태: 건설 선불 지불·주민과 병력 별도 생산은 사용자 채택. 나머지 추천 초안은 미채택이며 실제 검증 없음.

## 이미 채택된 기반

집 하나에서 시작, 반복 웨이브와 최종 방어, 준비 시간 종료 후 자동 공격 시작, 커서 범위 기여 유지. 주민 개별 지휘를 제거하고 주민 수가 커서의 작업 효율을 높인다. 이전 커서 보조·주민 독립 생산 역할 분담은 대체되었다. 건물을 고도화해 강한 캐릭터와 스킬을 확보하려는 사용자 의도를 유지한다.

## 성장 연결 · 제안

목재·석재 채집 → 주거·생산 확장 또는 당장 필요한 방어에 투자 → 추가 주민과 개선된 수급 → 군사·연구 시설 고도화 → 상위 병력·스킬 확보 → 강한 웨이브 대응 → 수리·재건·추가 투자.

| 구성 | 역할 | 상태 |
|---|---|---|
| 집 | 주민 모집, 집 하나당 주민 +1 | 사용자 채택 |
| 농장 | 1×1, 주민 상한 +3 | 사용자 채택 |
| 목장 | 2×1, 주민 상한 +10 | 사용자 채택 |
| 목재·석재 자동 수급 건물 | 커서 작업과 별개의 지속 자원 공급 | 사용자 방향 채택·생산 조건 미정 |
| 병영 | 별도 병력 생산 | 존재 확정·병종 해금 조건 미정 |
| 연구소 | 일반 강화 이용·기사 생산 해금 | 사용자 채택 |
| 제단 | 마법탑·마법사·환생·일부 강화 노드 해금 | 사용자 채택 |
| 화살·마법 방어탑 | 위치 기반 방어 | 존재 확정·공격 특성 제안 |

이전 주택의 인구 상한 역할을 농장으로 옮긴다. 기존 작업장 후보 대신 목재·석재 자동 생산 시설을 설계한다. 콘텐츠 목록과 세부 역할은 [06 콘텐츠 문서](06-player-flow.md)를 따른다. 고도화 비용·선행 조건은 미정이다.

## 주민과 병력 · 별도 생산 채택

- 주민은 인원 수로 표시하며 커서 채집·건설·수리 효율을 높이고 병력은 별도로 생산한다（사용자 변경 반영）. 구체 생산 건물·비용·시간은 후속 설계다.
- 주민을 전투원으로 전환하는 안은 현재 채택하지 않는다. 경제 유지와 병력 확보에 쓸 자원을 배분하는 선택에 집중한다.
- 주민은 집 하나당 +1이다. 농장 인구 상한과 적용 시점·초과 처리·집 파괴 시 인구 변화는 미정이다. 별도 모집 버튼·비용·시간을 자동 확정하지 않는다.
- 환생은 한 판 내부의 웨이브 재시작이다. 클리어·패배 후에는 강화가 초기화되고 콘텐츠 영구 해금만 남는 구조를 채택했다. 아래 유지 범위를 따른다.

## 자원과 작업 비용 · 제안

- 첫 경제 초안은 목재·석재로 작성한다. 추가 재화는 필요한 역할이 생길 때 검토한다.
- **건설 비용은 배치할 때 지불한다（사용자 채택）.** 커서 범위 기여로 건설 진행도를 올리며 주민 수가 효율에 반영된다. 비용이 부족하면 배치를 시작할 수 없고, 이미 비용을 낸 공사는 다른 작업의 자원 소비로 중단되지 않는다. 비용 수치·취소·환급은 미정이다.
- 수리 재료가 부족하면 해당 수리만 대기하고 채집 등 가능한 작업은 계속한다（사용자 채택）. 복구량에 따른 소비율은 아직 제안이다.
- 자원이 확보되면 대기 작업을 자동 재개한다. 완료되지 않은 대기 작업은 완료로 판단하지 않는다.
- 자원 부족 때문에 모든 작업이 막혔으면 범위를 유지하며 부족 표시를 한다. 사용자는 위치 변경·우클릭으로 중단할 수 있다.
- 같은 자원을 여러 작업이 요구할 때의 분배, 수리로 건설용 자원을 모두 소비하지 않도록 할 예산·예약 정책, 철거·파괴 환급은 미정이다.

## 완료와 대기의 차이

**완료:** 원 안의 나무가 고갈되고 건물이 완공·완전 수리되어 남은 일이 없다. 사용자 규칙에 따라 범위 기여가 종료된다. 종료 후 새 피해가 생겼을 때 다시 클릭해야 한다는 것은 기존 규칙을 연결한 해석이며 사용자가 이번에 설명을 요청했다. 질문을 새 승인으로 취급하지 않는다.

**대기:** 손상된 건물에 할 일은 남아 있지만 수리 재료가 없다. 위 비용안을 채택한다면 필요한 자원이 들어올 때 다시 진행하도록 추천한다. 자원 비용이 없는 작업에는 이 예외가 필요 없다.

## 다음 결정과 위험

다음은 주민과 병력을 늘리는 시설·비용·시간의 연결을 정한다. 추천 초안은 집에서 주민 모집, 농장으로 주민 수용 한도 확장, 군사 시설에서 병력 생산, 군사 시설 고도화로 상위 병종 해금이다. 주민과 병력의 인구 한도를 공유할지는 별도 미정이다. 시설 고도화가 이미 생산한 병력을 자동으로 강화하는지는 아직 결정하지 않았다.

반경·효율 수치는 역할 분담이 실제로 성립하는지 확인할 때 정한다. 주민 증가와 생산 증가가 서로 과도하게 가속하거나 생산 투자만 반복하는 것이 정답이 될 위험이 있다. 지금은 실제 게임 검증을 실행하지 않았다.

## 주민 수와 스킬 트리 · 방향 변경

- 사용자 채택: 주민은 개별 유닛 지휘 대신 숫자로 표시하고 인원이 많을수록 커서 효율을 높인다. 재화를 쓰는 스킬 트리 강화를 포함한다.
- 주민 5명과 10명은 설명용 예시다. 실제 초기 인원·배율은 미정이다.
- 사용자 변경 채택: 주민 수가 커서 범위와 작업 효율을 모두 높인다. 일반 스킬 트리는 범위 증가율 효율과 수행 효율을 강화한다. 연구소 필요, 제단으로 일부 노드 추가 해금.
- 새 규칙은 인구에 따른 범위·속도 동반 증가를 채택한다. 영향 대상 수까지 늘어나는 복합 상승은 수치·비용으로 검증하며 과거 분리안을 현행 규칙으로 적용하지 않는다.
- 범위가 넓어지는 것과 대상당 작업량은 별도 조정한다. 작업량 분배·상한·강화 곡선은 아직 미정이다.
- 일반 강화와 환생 강화는 모두 한 판 안에서만 유효하다. 클리어·패배 시 초기화한다. 콘텐츠 영구 해금은 별도 유지한다. 일반 강화는 연구소 조건을 충족하면 웨이브 진행 중 재화로 수시 구매 가능하며 환생 시 초기화한다.
- 주민 확보 방식, 농장 파괴로 상한 감소 시 인구 처리, 인구 0명의 기본 커서 효율, 병력 조작은 후속 결정.

## 한 판·환생·영구 해금 · 사용자 채택

한 판은 새 게임 시작부터 최종 웨이브 방어 성공 또는 패배까지다. 한 판 중 환생으로 첫 웨이브부터 다시 시작할 수 있으며 환생은 판 종료가 아니다. 환생은 제단 조건을 충족하고 웨이브 종료 후 정비 시간에 가능하다. 횟수 제한은 미정이다.

| 항목 | 환생 시 | 클리어·패배 후 새 판 |
|---|---|---|
| 웨이브 진행 | 처음으로 돌아감 | 처음부터 시작 |
| 마을·주민·병력·일반 재화 | 모두 시작 상태로 초기화. 정확한 시작 수치는 미정 | 시작 상태로 새 게임 |
| 미사용 특수 재화 | 같은 판의 다음 환생까지 유지 | 판 종료 시 처리 미정 |
| 일반 스킬 트리 강화 | 초기화 | 초기화 |
| 환생 화면에서 구매한 강화 | 같은 판에서 유지, 다음 진행에 적용 | 초기화 |
| 콘텐츠 영구 해금 | 이미 해금된 콘텐츠 사용 가능 | 유지 |

환생 화면에서 강화할 수 있고 이 강화는 해당 판의 클리어·패배까지 유지한다. 환생 강화에는 웨이브 클리어 보상과 환생 추가 정산으로 얻는 특수 재화를 사용한다. 미사용 특수 재화는 환생을 넘어 유지한다. 보상·비용 수치와 판 종료 시 잔액 처리는 미정이다. 클리어·패배 시 콘텐츠를 영구 해금하는 시스템을 둔다. 해금 종류는 새 병종·건물·스킬 선택지이며 구체 콘텐츠와 조건은 미정이다. 또한 매 실패마다 반드시 새 콘텐츠를 지급한다는 뜻은 아니다.

### 강화 구분 · 사용자 채택

- 일반 강화는 연구소 조건을 충족하면 웨이브 진행 중 재화로 수시 구매한다. 환생 시 웨이브는 처음으로 돌아가고 일반 강화는 초기화된다. 환생 화면에서 구매한 강화만 같은 판 안에서 유지된다. 일반 강화 구매를 준비 단계에만 제한하지 않는다.
- 영구 해금은 새 병종·건물·스킬 선택지로 준비한다. 해금은 사용 가능해지는 것이고 다음 판에 무료로 건물·병력을 소유한다는 뜻은 아니다.

### 환생 조건·보상 · AI 제안 / 미채택

- 환생 보상은 진행 성과와 연결해 즉시 환생 반복이 최적 전략이 되지 않게 설계한다. 자동 환생·패배 후 환생은 채택하지 않았다.
- 초반 반복이 길어져 지루해지는 위험과 죽기 직전 환생으로 패배를 무한 회피하는 위험을 함께 검토한다. 환생은 정비 시간에 한정되며 횟수는 미정이다.

## 병력 배치·순찰 · 사용자 채택

병력은 마을 주변에서 적을 막을 위치에 배치하고 순찰한다. 주민 수와 별개다. 순찰 경로 지정 방식, 적 발견 시 추격·복귀, 병력 선택 입력은 미정이다.

### 다음 환생 설계 추천 · 미채택

- 환생은 웨이브가 끝난 뒤 정비 시간에 선택한다（사용자 채택）. 전투 중 환생은 불가하다.
- 기존 새 웨이브 기록에만 보상하는 제안은 사용자 안으로 대체한다. 각 웨이브 클리어 시 특수 재화를 지급하고 후반일수록 보상을 높인다. 환생 후 같은 웨이브 재진행을 보상 대상에서 제외하지 않는다.
- 환생 화면에서 강화하고 첫 웨이브로 돌아간다. 보상 수치·구매 비용·환생 횟수는 미정이다. 남은 특수 재화는 환생을 넘어 유지한다.
- 초반 반복 대비 후반 진행의 보상 효율과 위험을 검증한다. 단순히 후반의 1회 보상이 더 크다는 것만으로 시간당 효율이 더 높아지는 것은 아니다.

## 특수 재화 획득과 환생 정산 · 사용자 채택

### 두 종류의 지급

1. 웨이브 클리어 지급: 클리어할 때 특수 재화를 얻는다. 초반은 적게, 후반일수록 많이 지급해 더 깊이 진행할 동기를 만든다.
2. 환생 추가 정산: 환생할 때 몬스터 처치 횟수·남은 일반 재화 등을 종합해 특수 재화를 추가 지급한다. 진행 중 적극적인 플레이의 성과를 인정하려는 의도다.

특수 재화는 환생 화면의 강화 구매에 사용한다. 일반 강화는 기존 일반 재화로 진행 중 수시 구매하는 규칙을 유지한다. 환생 후 같은 웨이브의 재클리어도 기본 지급 대상이다. 새 최고 기록 달성만 보상한다는 이전 AI 제안은 채택하지 않는다.

### 정산 흐름 · 추천 상세 / 미채택

환생 선택 → 이번 환생 전까지의 성과와 보유 일반 재화 확정 → 추가 특수 재화 산출 → 항목별 내역 표시 → 환생 강화 구매 → 일반 강화·웨이브 초기화 후 재시작.

추가 지급액 = 처치 성과 보너스 + 남은 일반 재화 환산 보너스 + 추후 채택한 성과 항목. 이는 구조 설명이며 계수·수식 확정이 아니다. 동일 클리어 사건을 환생 정산에서 중복 지급하지 않는 것과, 환생 후 다시 클리어한 웨이브에 새 보상을 지급하는 것은 구분한다. 사용자의 “다시 지급”은 후자의 반복 클리어 보상으로 해석한다.

- 성과는 한 번만 정산한다（사용자 동의）. 이번 판 시작 또는 직전 환생 이후 구간을 집계하고 이미 정산한 처치 등은 다음 정산에서 다시 세지 않는 방식으로 연결한다.
- 보유 일반 재화도 이번 환생 확정 시점에 한 번만 정산한다. 정산 뒤 초기 일반 재화·재건 상태·취소 가능 시점은 아직 미정이다.
- UI는 보유 특수 재화, 이번 추가 획득 내역, 구매 후 잔액을 구분해 보여주는 안을 추천한다. 이미 지급한 클리어 보상은 참고 내역으로 구분한다.
- 미사용 특수 재화는 다음 환생까지 이월한다（사용자 채택）. 클리어·패배 후 새 판의 잔액 처리는 별도 미정이며 영구 해금 재화로 자동 해석하지 않는다.
- 판 종료 때에도 별도 정산할지 여부는 미정이다. 이번 요청의 정산은 환생 시점에 한정한다.

### 설계 위험과 보완 제안 · 미채택

- 후반 보상은 1회 지급액뿐 아니라 도달 시간·실패 위험을 고려해 초반 반복보다 유리한지 비교해야 한다.
- 비축 억제는 타이트한 웨이브에서 생산·강화·방어에 자원을 계속 써야 하도록 만드는 방식을 우선한다（사용자 방향）. 이는 설계 의도이며 실제 비축 억제 효과는 미검증이다. 환산률 점감·강제 재화 소멸은 채택하지 않는다.
- 후반으로 갈수록 적 수가 증가한다면 처치 수 보너스와 클리어 보상이 함께 커진다. 둘의 합계로 성장 곡선을 조정한다.
- 보상 주축은 웨이브 클리어, 추가 정산은 보조로 두는 안을 추천한다. 구체 비중·상한·추가 항목은 미정이며 임의 확정하지 않는다.
- 평가 기준은 신규 기록 유무가 아니라 깊이 진행하는 것의 보상과 비용이다. 초반 반복 보상을 임의로 삭제하지 않는다.

## 반복 보상과 환생 강화 비용 · 사용자 조정

- 후반 웨이브는 도달 시간과 도전 부담 때문에 너무 자주 반복되지 않아도 된다. 다만 도달 시간이 지나치게 길어져서는 안 된다. 모든 후반 구간의 시간당 보상이 반드시 최대여야 한다는 규칙을 두지 않는다.
- 후반일수록 클리어 보상 증가라는 기존 방향은 유지한다. 비교할 것은 지급량·도달 시간·생존 위험·강화 비용을 합친 진행 가치다.
- 타이트한 웨이브를 통해 건설·일반 강화·방어 투자를 계속 요구해 비축 여유를 줄인다. 재화 보유 상한이나 강제 소비로 해석하지 않는다.
- 환생 후 동일 웨이브를 재클리어하면 특수 재화를 다시 지급한다. 성과 정산은 중복 처리하지 않는다.
- 초반 반복만으로 고급 환생 강화를 쉽게 사지 못하도록 환생 강화 비용을 높이는 방향을 채택한다. 가격은 강화 단계에 따라 증가한다（사용자 채택）. 구체 곡선·증가량은 미정이다.

### 환생 강화 비용 · 사용자 채택

강화 단계가 높아질수록 해당 강화의 다음 구매 비용이 증가한다（사용자 채택）. 환생 횟수 자체에 따라 모든 가격이 일괄 증가하는 규칙은 자동 채택하지 않는다. 낮은 단계는 초반 보상으로 접근하고, 높은 단계는 더 깊은 웨이브 보상이 효율적인 경로가 되도록 설계한다.

성공 기준은 “환생을 많이 한 플레이어가 막힌다”가 아니라 “낮은 웨이브 반복으로도 조금씩 진행할 수 있지만 고급 강화에는 후반 진행이 매력적이다”라는 제안이다. 보유 특수 재화 이월 정책과 구매 비용을 함께 정해야 한다. 아직 수치나 실제 효율을 검증하지 않았다.

## 패배와 환생의 경계 · 사용자 채택

- 집이 모두 파괴되면 다른 건물·병력이 남아 있어도 패배한다. 여러 집 중 한 채만 파괴된 경우에는 남은 집이 있으면 계속 진행한다. 기존 모든 건물 파괴 조건도 성립하지만 마지막 집 파괴 시 먼저 종료한다.
- 환생은 제단 조건을 충족하고 웨이브가 끝난 뒤 정비 시간에 가능하다. 패배 후 환생으로 판을 이어가지 않는다.
- 환생 시 마을·주민·병력·일반 재화·일반 강화를 시작 상태로 완전히 초기화하고 첫 웨이브부터 시작한다. 시작 상태의 집과 초기 수치는 별도 정의하며 모든 수량을 0으로 만든다는 뜻은 아니다.
- 초기화 예외는 기존 환생 강화, 미사용 특수 재화, 영구 해금이다. 환생 강화는 해당 판의 최종 클리어·패배까지만 유지한다.
- 환생 전 남은 일반 재화·성과는 정산 후 초기화하는 흐름을 따른다. 동일 성과 재정산은 하지 않는다.
- 건설 중인 집을 생존 집으로 세는지, 마지막 집 파괴와 최종 웨이브 클리어가 동시에 발생했을 때 우선순위는 후속 판정 예외다. 초기화 중 임시 건물 0개 상태를 정상 게임 중 전멸과 혼동하지 않는다.

## 집·주민·해금 조건 갱신 · 사용자 채택

집 하나당 주민 +1. 커서로 지휘하면 주민이 자동으로 배정되어 작업하는 컨셉이며 개별 수동 지휘는 없음. 주민 수가 커서 반경과 수행 효율을 높이고 일반 강화가 반경 증가율 효율·수행 효율을 개선한다. 주민이 물리 유닛으로 이동하는 구현까지 확정한 것은 아니다.

연구소는 일반 강화와 기사 생산의 선행 조건이다. 제단은 마법 방어탑 건설·마법사 생산·환생·일부 일반 강화 노드 해금의 선행 조건이다. 일반 강화의 연구소 조건과 제단 전용 노드 조건은 함께 적용하는 것으로 해석한다.

연구소·제단 파괴 시 기존 강화·병력·건물 유지, 해당 선행 조건의 새 행동 제한은 확정이다. 반경과 인구의 세부 수식은 미정이다. 기본 주민 상한 1, 시작 집 1개·주민 1명으로 확정되었다.

## 인구 계산과 즉시 갱신 · 사용자 채택

사용자 확정: 기본 상한 1, 집당 주민 +1, 농장당 상한 +3, 목장당 상한 +10, 마을 영역 10타일 단위마다 주민 +1. 주민은 상한을 넘지 않는다.

현재 집·영역·인구 상한을 기준으로 즉시 재계산한다. 영역 타일의 세부 포함 판정은 미정이다:

```text
주민 상한 = 1 + 농장 수 × 3 + 목장 수 × 10
주민 수 = min(주민 상한, 집 수 + floor(마을 영역의 고유 타일 수 / 10))
```

여기서 영역 타일 중복은 한 번만 세는 안이고, 일반 강화·환생 강화로 추가되는 인구 효과는 아직 포함하지 않았다. 수량은 완공 건물 기준을 추천하며, 건물·영역 감소에 따른 현재 주민 수의 즉시 재계산은 채택되었다. 주민 +1 보너스는 면적이 10타일을 넘나들 때마다 반복 지급하는 재화가 아니라 현재 영역에 따른 인구 기여로 해석하는 안이다.

가상 계산 예（시뮬레이션 아님）: 집 2개·농장 1개·목장 0개·영역 25타일이면 상한 4, 집 기여 2+영역 기여 2로 주민 4. 시작 집 하나만 있으면 영역 보너스가 있더라도 기본 상한 1이 적용된다.

### 다음 결정

새 집은 기존 마을 영역 안에 배치하고 완공 시 새 집의 영역으로 바깥을 확장한다（사용자 채택）. 건설 중인 집은 영역을 확장하지 않는다. 시작 시 제공하는 집은 배치된 초기 상태다. 집 파괴 시 영역을 재계산하지만 영역 밖 기존 건물은 정상 작동한다（사용자 채택）. 인구는 현재 조건에 따라 즉시 재계산하며 마지막 집 소멸 시 게임 오버이므로 복구 예외는 필요 없다.

### 주민 변화의 작업 반영 · 사용자 채택

집·농장·목장 파괴와 마을 영역 변화에 맞춰 주민 수·상한을 즉시 재계산한다. 감소한 인구로 커서 범위·작업 효율도 갱신한다. 활성 기여의 중심 위치는 유지하고 줄어든 범위 안의 남은 작업은 계속한다. 남은 작업이 없다면 기존 전체 완료 종료 규칙을 따른다. 재건하면 현재 조건에 맞춰 주민과 작업 능력을 회복한다.

변경 이유를 함께 표시한다. 예: “주민 8 → 7 · 농장 파괴”. 이 수치는 설명용이며 시작 값·밸런스 수치가 아니다. 집 파괴는 집 인구와 영역 보너스가 함께 줄 수 있어 복구 난이도 상승을 검증해야 한다. 실제 테스트는 수행하지 않았다.

## 건설·생산 비용의 후속 묶음

해금 시설 파괴 후 기존 성과 유지·신규 행동 제한은 채택되었다. 진행 중 작업 지속, 병영 파괴 시 생산 취소, 미완성 건설 취소 비례 환급·적 파괴 무환급, 수리 재료 대기는 [06 정책 묶음](06-player-flow.md)으로 채택되었다. 병력 생산비는 주문 시 선불, 미시작 전액·진행 중 미진행 비율 환급으로 채택되었다. 별도 후속 사용자 채택으로 생산비 선불도 확정되었다.

## 자원 수급·생산 운영 확정

벌목소·채석장은 고갈 없이 주기적으로 재화를 지급하고, 커서는 고갈되는 자연 자원을 채집한다. 병력은 병영에서 수량 예약·주문 시 비용 지불·한 기씩 순차 생산한다. 선행 시설 소멸 시 아직 시작하지 않은 관련 주문은 대기하며 이미 시작한 작업은 계속한다. 취소·병영 파괴 시 미시작 주문 전액, 진행 중 주문 미진행 비율을 환급한다. 비용·주기·생산 시간은 후속 수치 설계 대상이다.

## M2 첫 수치 묶음 v0.1 · 초기 기준 채택 / 미검증

수치는 출시 밸런스가 아니라 첫 비교·설계를 위한 가설이다. 범위당 작업량·적 능력치·인구 곡선이 아직 없어 경제가 실제로 성립한다고 주장하지 않는다. 2026-09-15 사용자 채택으로 대화에서 제시한 수치를 초기 기준으로 사용하며 플레이 증거에 따라 바꾼다. 문서에만 제시한 세부 가격·자동 수급량은 제안 상태로 구분한다.

### 웨이브와 시간

- 총 15웨이브, 15번째 보스와 호위. 1~3 기본, 4~6 전사형 추가, 7~9 주술사, 10~12 오크·리자드, 13~15 종합 대응 구간 제안.
- 첫 준비 90초, 웨이브 간 정비 30초. 환생 후에도 첫 준비 90초 적용을 초안으로 두며 조기 시작·배속은 별도 미정.
- 각 전투는 대략 45~75초에 끝나도록 적 수·생성을 설계하는 목표다. 시간 만료로 클리어하지 않고 기존 적 전멸 조건을 유지한다.
- 환생 없는 첫 웨이브부터 최종까지 약 20~27분 목표: 준비 총 8.5분 + 전투 11.25~18.75분. 강화 UI·환생 화면·정지 시간과 환생 반복은 별도다.
- 한 판은 환생을 포함하므로 전체 한 판이 20~27분이라는 뜻이 아니다. 실제 총 시간과 후반 피로는 별도 검증한다.

### 자원과 커서 작업량

- 시작 집 근처에서 목재 최소 100·석재 최소 50을 자연 자원으로 확보할 수 있게 배치한다. 즉시 지급하지 않으며 채집에 재료 비용은 없다. 병영을 놓을 빈 마을 영역과 적 접근 통로도 확보한다.
- 주민 1명의 커서 전체 작업량은 초당 2 작업점. 목재 1개는 1점, 석재 1개는 2점 소모: 해당 채집만 하면 목재 2/초 또는 석재 1/초다.
- 원 안의 작업은 모두 동시에 진행하되 전체 작업량을 대상 수로 균등 분배한다. 나무 1개든 5개든 총 목재 생산량은 2/초다. 완료·대기 대상은 분배에서 빠지고 다른 가능한 작업에 재분배한다. 수리도 같은 작업량을 공유하되 재료 소비 수치는 후속 설계한다.
- 주민 증가로 전체 작업량과 반경이 함께 늘어나는 기존 방향은 유지한다. 주민별 증가 곡선은 별도 미정이다. 넓은 범위는 더 많은 대상을 한 번에 관리하는 이점이고, 대상 수만으로 전체 작업량이 무제한 늘지는 않는다.

### 첫 준비의 가상 계산

인구 증가·강화 없이 주민 1명, 필요한 작업만 범위에 포함하고 즉시 조작한다는 계산이다. 자원 배치와 입력 소요 시간은 실제 검증 전이다.

| 시각 | 행동 | 결과 |
|---|---|---|
| 0~20초 | 목재만 채집 | 목재 40 |
| 20~40초 | 석재만 채집 | 석재 20 |
| 40~55초 | 목재40·석재20으로 병영 배치, 단독 공사 | 55초 병영 완공, 재화 0 |

### 첫 웨이브와 검증 목표

- 한 방향에서 슬라임 총 6마리. 웨이브 시작 후 0·15·30초에 각 2마리 생성하는 안을 제안한다. 마지막 생성 후에도 모두 처치해야 클리어한다.

- 전투45~75초 목표는 유지한다. 생성 지점에서 마을까지 이동 시간, 전사·슬라임 체력과 공격력, 집 체력·수리량을 함께 맞춰야 한다. 6마리라는 수만으로 승패를 보장하지 않는다.
- 특히 작업 분배의 이해 가능성, 처음 접하는 플레이어의 90초 여유, 생산 시설 선투자 경로가 막히는지 확인한다. 문서상 병영 우선 경로만 계산했으며 다른 경로의 성립은 미검증이다.

## 커서 공격·대상별 독립 작업과 초반 흐름 v0.3

### 시간·작업·공격 묶음 · 새 AI 제안 / 미채택

- 첫 준비를 기존 채택90초에서 60초로 단축하고, 첫 웨이브 종료 후 정비만 기존30초에서 45초로 늘리는 안. 이후 정비는30초 유지. 첫 방어를 빨리 경험하고 이후 병영 건설·생산 시간을 확보한다.
- 주민1 기준 나무 각각 목재2/초, 바위 각각 석재1/초를 제안한다. 나무3개·바위1개가 들어오면 목재6/초·석재1/초가 동시에 쌓인다. 자원 고갈까지의 양은 별도다.

### 시간 계산 예시 · 실제 플레이 검증 아님

첫 준비60초 안에 나무 하나30초로 목재60, 바위 하나20초로 석재20을 확보하면 조작 여유10초가 남는다. 이는 병영40목재20석재와 전사2명20목재의 비용이다. 다른 건물에 쓰지 않고 각 대상에 충분한 자원이 있다는 가정이며 동시 채집·주민 증가의 이득은 계산에 넣지 않았다.

첫 전투는 커서로 방어한다. 첫 클리어 후 정비45초 동안 병영 공사15초 → 전사2명 순차 생산20초 → 집결 여유10초가 가능하다는 산술 예다. 초보자의 재화 사용·입력 지연·병력 이동 거리·집 수리비에 따라 달라지므로 보장된 진행이 아니다. 병영을 미리 지으면 더 여유로울 수 있다.

이 시간안 채택 시 환생 없는15웨이브 준비 합계는8분15초, 전투 목표를 합친 진행 목표는19분30초~27분이다. 기존90초/30초 시간은 위 변경안 채택 전까지 확정값이며 새 제안과 구분한다.

반경 확대는 대상 수와 대상별 속도를 함께 늘릴 수 있어 성장 폭이 크다. 사용자 의도인 독립 동시 처리는 유지하고, 자원 밀도·고갈량·인구 성장률·공격 피해를 통해 조정한다. 기존 v0.2의 경제와 전투 결론을 재사용하지 않는다.

| 5 | 1.2배 | 1.4배 |
| 10 | 1.4배 | 1.8배 |

강화가 없는 상태의 비교 기준점 제안이다. 중간 인원 보간·10명 초과 증가율·기본 반경 타일 수는 미정이며 여기서 상한10명을 정하는 것은 아니다. 대상별 독립 동시 작업을 유지한다. 반경1.4배는 원 면적 약1.96배이므로, 균일하고 충분한 대상이 있다는 가정에서는 작업속도1.8배와 합쳐 총량 약3.53배가 될 수 있다. 실제 대상 수는 타일 배치·자원 고갈에 따라 달라진다.

이전 공격력 분리 제안은 사용자 피드백으로 철회했다. 주민이 커서 범위와 채집·건설·수리·공격 효율을 함께 높인다. 정확한 증가율과 강화 구성은 최신 갱신을 따른다.

### 일반 스킬 트리: 현재 마을의 투자 방향

연구소가 있어야 목재·석재로 수시 구매하며 환생 시 초기화되는 기존 규칙을 유지한다. 최초 구성은 다음4개 계열을 제안한다. 각 계열의 개별 노드 수·가격·단계별 효과량은 다음 수치화 대상이다.

| 계열 | 효과 | 조건 |
|---|---|---|
| 지휘 범위 | 주민 증가로 얻는 반경 보너스의 증가율 개선 | 연구소 |
| 작업 숙련 | 대상별 채집·건설·수리 속도 증가 | 연구소 |
| 전투 훈련 | 전사·궁수·마법사·기사의 공격력·생존력 강화 노드 | 연구소, 병종 생산 해금 조건은 별도 유지 |
| 신의 손길 | 커서의 대상별 공격 피해 강화 | 연구소+제단 |

지휘 범위는 전체 반경에 무조건 곱하는 효과가 아니라 주민 증가분을 키우는 방향이다. 예를 들어 반경1.2배의 인구 보너스0.2를50% 개선하면1.3배가 된다. 이는 효과 설명용 예시이며 실제50%를 확정하지 않는다. 전투 훈련은 기존 병력과 이후 생산 병력에 함께 적용하는 안이다. 건물 방어탑 강화 계열은 이번 초안에 자동 포함하지 않는다.

### 환생 강화: 다음 재건을 더 수월하게

정비 중 제단을 통해 환생하고, 특수 재화로 구매하며, 같은 판의 후속 환생에도 유지되는 기존 규칙을 따른다. 최종 클리어·패배 때 초기화한다.

| 계열 | 효과 | 목적 |
|---|---|---|
| 숙련의 기억 | 주민1 상태부터 기본 채집·건설·수리 속도 향상 | 초반 재건 반복 시간 단축 |
| 수호의 축복 | 모든 집의 최대 체력 증가 | 재건 중 마지막 집을 지킬 여유 |
| 군세의 기억 | 병영의 병력 생산 시간 감소 | 방어 전력 복구 가속 |

초기 목재·석재는0, 집·주민 각1을 유지한다. 환생 강화로 시작 자원을 지급하거나 주민을 추가하는 효과는 제안하지 않는다. 구매비8→16→32→64→128의 기존 초기 기준은 유지하되 세 계열의 실제 단계 수·효과량은 미정이다. 생산 시간 감소의 합산 방식·하한도 후속 수치화한다.

일반 강화는 현재 마을에서 경제와 군사 중 어디에 투자할지, 환생 강화는 다음 재건에서 어느 약점을 보완할지 선택하는 역할이다. 숙련의 기억과 작업 숙련처럼 겹치는 효과의 합산/곱연산 규칙은 미정이며 과도한 복합 성장을 검증해야 한다.

### 다음 작업과 완료 경계

이 묶음과 초반 시간안의 중요 선택을 정리한 뒤 마을 기본 반경·근접 보너스, 남은 전투/경제 기준, 환생 정산·결과·영구 해금·저장 흐름을 묶어 정리한다. M2 완료를 선언할 단계는 아직 아니다. 이후 M3 최소 제작 범위·개발 순서·검증 계획을 작성하며 명시적 개발 요청 전 구현하지 않는다.

## 주민 효율·돈·에테론 경제 갱신 · 최신

### 사용자 변경 반영

- 주민이 커서 공격 효율도 높이는 방향으로 통일한다. 공격만 인구 성장에서 제외했던 AI 제안은 철회한다. 일반 강화는 인구 성장에 더해 특정 능력을 추가 개선하는 역할이며 공격 강화만이 피해 증가의 유일한 경로가 아니다.
- 특수 재화 명칭은 에테론. 영혼 같은 개념이며 웨이브 클리어 시 즉시 획득하지 않고 정산 시 획득한다. 과거 웨이브별1/3/6/10/15 지급표는 현행 지급 규칙에서 제외한다.
- 환생 내부 유지·판 종료 초기화·영구 해금은 기존 방향을 유지한다. 정산 시점의 세부 범위(환생 외 최종 승리·패배 포함 여부)는 아직 미정이다.

### 일반 경제 · AI 추천 / 미채택

목재·석재는 건설과 수리 재료로 유지하고 돈을 병력 생산·일반 강화 비용으로 도입하는 안을 추천한다. 모든 소비를 돈으로 통합하면 채집 재료를 구분해 확보하는 건설 선택이 약해진다.

교역소를 새 건물 후보로 추가한다. 목재만으로 건설하고 목재·석재를 돈으로 판매할 수 있게 하여 돈이 없어 돈 생산 건물을 지을 수 없는 순환을 피한다. 시작 돈도0을 제안하며 시작 목재·석재0 확정은 유지한다. 교역소 판매는 커서 작업을 요구하지 않는 건물 기능으로 제안한다.

판매는 자원별 보유량 기준을 정해 초과분만 자동 판매하는 안을 추천한다. 초기 설정은 자동 판매 꺼짐, 플레이어가 목재·석재 각각 남겨둘 양을 지정한 뒤 켠다. 남겨두기 설정은 재료를 따로 잠그지 않고 판매만 제한하므로 건설·수리에 쓸 수 있다. 교역소가 없으면 새 판매 불가, 보유 돈은 유지한다. 구매/역환전·적 돈 드롭·판매 속도·환율은 이번에 자동 추가하지 않는다.

가격·환율은 아직 정하지 않는다. 전사 목재10 제안은 돈 생산비 안 채택 시 다시 산정하고, 첫 준비/첫 정비 예시에는 교역소 건설과 환전 시간이 추가되므로 기존35초 병영+병력 계산만으로 초반 성립을 주장하지 않는다. 첫 웨이브 커서 단독·두 번째 전사2명 목표는 유지한다.

### 에테론 정산 · AI 추천 / 미채택

환생 정산에서 이번 진행 구간의 도달 웨이브를 주축으로, 실제 처치 수를 보조로 에테론을 계산하는 안을 추천한다. 구간은 새 판 또는 직전 환생 이후부터 이번 정산까지다. 후반 웨이브 기여를 크게 하되 기존 클리어별 지급표를 그대로 새 환산표로 확정하지 않는다. 웨이브 종료 때는 진행 성과만 기록하며 에테론 잔액을 늘리지 않는다.

정비 화면에 환생하면 받을 예상 에테론을 보여주고 환생 확정 시 한 번 지급·성과 구간 종료하는 안이다. 환생 취소/예상치 조회는 지급이 아니다. 정산 후 환생 화면에서 구매하고 미사용 에테론은 같은 판의 다음 환생까지 유지한다. 환생 뒤 같은 웨이브 재진행 성과는 새 구간에서 다시 평가할 수 있다.

기존 사용자가 원한 남은 일반 재화 성과 반영은 삭제하지 않는다. 다만 돈 전환을 넣으면 목재·석재·돈의 잔액을 하나의 가치 기준으로 환산해 작은 보조 보상으로 반영하는 안을 추천한다. 판매한 원재료를 잔액에 다시 세거나 누적 판매액과 돈 잔액을 함께 보상하지 않는다. 환전 행위 자체는 추가 성과로 보상하지 않는다. 비축보다 웨이브 진행이 보상 주축이 되도록 환산 계수/보너스 상한은 후속 결정한다.

최종 클리어·패배 시 에테론을 지급할지는 별도 중요 결정이다. 현재 구조에서는 판이 끝나면 환생 강화가 초기화되고 판 밖 에테론 용도가 없으므로, 종료 화면은 성과·영구 해금만 정산하고 소비용 에테론은 환생 때만 지급하는 안을 추천한다. 아직 채택하지 않았으며 판 종료 잔액 이월·새 영구 성장 재화 도입으로 확대하지 않는다.

### 다음 묶음

돈/교역소 구조 채택 여부와 에테론 정산 시점을 확인한 뒤 교역소 비용·환율·병력 돈 가격·초반 시간·에테론 환산 및 강화 가격을 함께 재산정한다. M2 진행 중이며 게임 구현·실제 밸런스 검증 없음.

## 판 종료와 에테론 지급 · 사용자 확정

- 에테론은 환생할 때 이번 진행 성과를 정산해 지급한다. 웨이브 클리어 또는 최종 클리어·패배 시에는 지급하지 않는다.
- 환생은 같은 판 안의 재시작이므로 기존 환생 강화와 미사용 에테론을 유지하며, 새 정산분으로 환생 강화를 구매할 수 있다. 마을·주민·병력·일반 재화·일반 강화는 시작 상태로 초기화한다.
- 최종 클리어·패배하면 해당 판은 종료된다. 에테론 잔액·환생 강화·일반 강화·재화·마을·병력 등 모든 판 내부 진행 데이터는 다음 판에 이월하지 않는다.
- 판 종료 성과로 영구 해금 조건을 판정하고 해금 결과를 보존한 뒤 판 데이터를 초기화한다. 영구 해금만 다음 판에도 유지하며, 새 판은 정의된 시작 상태로 시작한다.
- 이는 게임 진행 데이터의 유지 규칙이다. 환경설정 등 비플레이 데이터 삭제를 뜻하지 않는다. 이전 문서의 판 종료 에테론 잔액 미정·종료 시 지급 검토는 이 결정으로 대체한다.
- 돈·교역소 및 구체 환산 계수는 여전히 제안 상태다. 이번 결정으로 함께 채택하지 않는다.

## 돈·교역소·첫 병력 경제 v0.5 · AI 제안 / 미채택 / 미검증

사용자의 진행 요청에 따라 돈 도입안을 구체화한다. 아래 가격·환율·자동 판매는 채택 전 초안이다. 에테론의 환생 시 지급·판 종료 초기화는 사용자 확정 규칙 그대로 유지한다.

### 재화 역할과 교역소

| 항목 | 추천 기준 |
|---|---|
| 목재·석재 | 건물 건설·수리 재료 |
| 돈 | 병력 생산·일반 강화 비용 |
| 시작 돈 | 0 |
| 교역소 | 목재20, 1×1, 주민1 기준 공사10초, 마을 영역 내 건설 |
| 판매 환율 | 목재1 → 돈1, 석재1 → 돈2 |

목재·석재 대상별 채집량2/초·1/초 초안 기준으로 동일한 시간에 같은 돈 가치를 얻도록 환율을 둔다. 이는 자원 밀도·고갈량·자동 수급까지 고려한 검증된 균형이 아니다. 자동 수급 건물도 목재·석재를 공급하며 판매 설정을 통해 돈으로 바뀐다. 건설 배치 시 선불 규칙 유지, 병력 선불·취소 환급은 돈 기준으로 적용한다. 기사·궁수·마법사 가격은 후속 산정한다.

교역소는 완공 즉시 판매 기능 사용 가능, 판매 자체는 커서나 주민 배정·별도 공정 시간을 요구하지 않는 안이다. 목재로 건설하므로 돈0에서 경제가 막히지 않는다. 구매·역환전·세금·병력 유지비는 추가하지 않는다.

### 판매 조작과 재료 보존

자원별 남겨둘 보유량과 자동 판매 켜기/끄기를 설정한다. 기본은 꺼짐이며 켠 자원의 초과분만 고정 환율로 판매한다. 예: 목재40 보존, 목재60 보유라면20 판매해 돈20 획득. 이 보유량 설정은 판매 제한이지 건설·수리의 사용 제한이 아니다.

교역소가 파괴되면 판매가 중단되며 이미 보유한 돈과 주문은 유지한다. 재건 시 다시 판매 가능. 설정은 마을 공통으로 두고 교역소를 여러 개 지어도 환율·판매 속도 보너스는 없도록 하는 안이다. 여러 교역소의 역할은 판매 기능의 생존 여유이며 필수 다중 건설을 요구하지 않는다.

### 첫60초 준비·첫45초 정비 연결 계산

첫 준비60초·첫 정비45초·이후30초는 아직 제안이다. 이 계산은 해당 시간안과 대상별 채집 속도 초안을 함께 적용한다. 시작 주민1·재화0, 시작 반경에 나무와 바위를 동시에 넣을 수 있고 목재80·석재20 이상이 접근 가능하다는 배치 가정을 둔다.

| 구간 | 행동 및 잔액 |
|---|---|
| 준비0~20초 | 나무·바위 동시 채집 → 목재40·석재20 |
| 준비20~40초 | 목재 추가40 채집 → 목재80·석재20 |
| 준비40~50초 | 목재20으로 교역소 건설 → 목재60·석재20 |
| 준비50~60초 | 목재40 보존으로 자동 판매 설정 → 목재40·석재20·돈20. 첫 전투 준비 |
| 첫 웨이브 | 커서만으로 방어하는 목표. 이 예시는 전투 중 추가 수급을 요구하지 않음 |
| 첫 정비0~15초 | 목재40·석재20으로 병영 건설 |
| 첫 정비15~35초 | 돈20으로 전사2명 순차 생산 |
| 첫 정비35~45초 | 방어 위치 집결 |

총 소비는 교역소 목재20 + 병영 목재40·석재20 + 판매 목재20이다. 첫 준비에 공사·설정까지50초 이상 필요하므로 자원 배치·입력 지연에 따라 여유가 부족할 수 있다. 첫 전투의 수리 소비·피해와 집결 거리는 아직 반영하지 않았다. 실제 플레이 검증 없이 성공을 보장하지 않는다. 시작 자원 위치가 이 동시 채집 가정을 충족하지 못하면 시간 또는 비용을 다시 조정해야 한다.

### 선택과 다음 단계

재료를 건설에 남길지 판매해 병력·강화에 쓸지 선택하는 구조다. 돈30의 일반 강화 초안은 전사3명과 비교 가능한 기회비용 예시이며 효과량은 미정이므로 동등한 가치라는 뜻은 아니다.

이 경제 묶음 검토 후 에테론 정산식과 환생 강화 효과/가격을 연결해 제안한다. 반영되지 않은 영역·전투·저장·해금 흐름을 정리해야 M2를 완료할 수 있다. 게임 구현·테스트는 시작하지 않았다.

## 교역소 자동 환전·단일 건설 · 사용자 확정

교역소는 자동 환전하며 On/Off 토글로 작동을 제어한다. 교역소는 하나만 건설할 수 있다. 이전 여러 교역소의 생존 여유 제안은 폐기한다. 중복 건설을 막기 위해 건설 중인 교역소도1개 제한에 포함하고 파괴/취소 후 다시 건설할 수 있는 안을 추천한다.

환전 대상 자원·보존량 설정·기본 토글 상태·환율·가격·판매 주기는 여전히 제안이다. 이번 사용자 결정으로 보존량 기능까지 확정하지 않는다. 건설 재료를 모두 팔지 않도록 기존 보존량 제안을 유지하되 On일 때 전량 판매인지 초과분 판매인지 후속 확인한다.

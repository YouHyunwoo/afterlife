## 사람 경험·경제 측정 계획

첫 누르기/첫 작업/첫 골드/농장 착공·완공·첫 생산/병영 완공·첫 충원·첫 방어 시각을 기록한다. 일차별 직접 수입과 농장/기타 수입, 채집·공사·수리·공격 유효 작업 횟수·버튼 유지 시간, 채집 시간·자금 대기·농장 가동 시간·손실·복구를 분리한다.

후반 농장 수입만으로 기본 운영을 유지하고 유지 작업이 긴급 개입이 되는지, 유지 작업에만 매달리는 것이 유일한 효율 경로가 되는지, 수리/공사 유지 작업이 시설 배치 판단을 방해하는지 확인한다. 입력 피로감·다음 행동 이해·실패 원인 설명도 관찰한다. 반복 간격1초·시작 완충은 확정됐으며 유효 유지 시간과 입력 피로는 사람 측정 대상이다.

검증 순서: 회당 작업량 → 농장 회수/강화 → 1~4일 구매·충원·강화 접근 → 5~6일 복구 → 7~10일 자동 수입·방어 → 전체 25~30분. 최신 74 시간/경제 후보를 사용하고 이전 필드 QA를 새 경험 증거로 쓰지 않는다. 낮 공급 고갈·비옥 부지 접근비·첫 공격 도착, 밤의 실제 수리HP/유지 시간·가속 지출을 따로 측정한다.

Unity 자동 Play/Test Runner 실행은 이번 문서 작업에 포함하지 않는다. 후속 구현의 빌드·메타데이터·에디터 안전 규칙은 Unity AGENTS.md를 따른다.

## 기술 확인 항목 · 개발 요청 후 수행

- 대상 수가 늘어도 각 대상 속도가 나뉘지 않는다. 적의 진입/이탈과 자원 고갈/새 피해가 기존 활성·완료 규칙을 따른다.
- 건설 비용 중복 지불·환급 중복·주문 돈 중복 차감 없이 취소/파괴를 처리한다. 교역소 중복 건설 제한이 공사 중에도 적용되는지 확인한다.
- 완공 집만 생존 집으로 세고, 인구/영역 변화와 범위 감소가 반영된다. 재시작 초기화 중 일시적인 집0 상태로 잘못 패배하지 않는다.
- 생성이 끝나도 적이 남으면 웨이브가 종료되지 않는다. 적/병력의 경로 정체로 영구 진행 불가가 생기지 않는지 확인한다.
- 마지막 집 파괴와 마지막 적 처치 동시 발생 우선순위는 구현 전 설정표에서 명시해야 한다. 현재 미정 규칙을 검증 결과로 둔갑시키지 않는다.
- 픽셀 후처리와 실제 월드 클릭/타일 위치가 맞으며 UI 조작이 월드 행동을 일으키지 않는다.
- 검증 도구와 명령은 실제 개발 대상의 AGENTS와 허용 환경을 따른다. 이번 기획 요청으로 Unity 실행·테스트 권한을 추가하지 않는다.

## 증거와 판정

빌드/설정·플레이어 여부·관찰 날짜·첫 실패 시점/원인·전사2명 확보 시점·의도치 않은 판매/입력 사례·사용자 설명을 기록한다. 가능한 경우 영상/화면과 오류 로그를 연결한다. 한 명의 결과로 전체 타깃의 재미를 일반화하지 않는다.

최초 플레이 후 별도의 안내된 인구 비교 실험을 수행해 초심자 관찰과 규칙 설명의 영향을 구분한다. 시간 목표에 맞지 않으면 입력 문제·경제 병목·전투 난이도 중 원인을 먼저 분리한다.

중단 조건: 크래시·진행 불가·경제 순환 막힘은 경험 평가를 멈추고 수정 대상으로 기록한다. 완주 가능 여부와 재미는 별도 판정한다. 결과 없는 현재 상태는 모두 미검증이다.

## 공간·호버·새 씬 검증 추가 · 실행 전

- 건설 미리보기가 사각 격자에 맞고1×1과2×1 점유 타일을 정확히 차지하는지, 겹침/영역 경계에서 배치 판정과 표시가 일치하는지 확인한다.2×1은 기능 없는 개발 검증용 대상 제안이다.
- 적이 칸 중심에 묶이지 않고 대각선/임의 좌표로 이동하면서도 건물을 통과하지 않는지 확인한다.
- 큰 건물의 긴 변·짧은 변·모서리로 접근시 적이 외곽과 사거리 기준에서 멈춰 공격하는지 확인한다. 중심 진입·벽 관통·도달 불가로 공격 영구 대기가 없는지 기록한다.
- 건물 파괴 후 점유/이동 장애물이 해제되는지, 여러 적 접근시 경로 정체가 생기는지 확인한다. 다수 적의 공격 자리 배정은 후속 구현 판단이다.
- 건물·공사·자원·아군·적 각각에 호버 진입/이탈 피드백이 있고, 파괴/고갈 후 잔상이 남지 않는지 확인한다. 호버가 기존 커서 작업 위치나 행동을 바꾸지 않아야 한다.

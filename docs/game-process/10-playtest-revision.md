모든 모달은ESC/닫기 버튼 지원. UI/모달 조작 중에는 커서 기여와 카메라 이동을 중단한다. 일반 모달 동안 게임 시간/자동 공사/병력 전투는 계속된다. 새벽 정산 모달만 다음 낮 시작을 확인할 때까지 진행을 멈춘다. 클릭/드래그 선택은 교체 방식, 우클릭은 선택/배치 해제다. 기본 커서는 우클릭 이후에도 마우스를 따라 기여한다.

낮에는 자원·사슴·야생 슬라임이 주기적으로 생성된다. 야생 슬라임은 가까운 병력과 교전하며, 밤 침공 마물은 현재 공유 시야와 잔상까지 포함해 보이지 않는 지점에서 임의 방향으로 생성되어 건물을 공격한다. 밤 최소 시간이 끝나도 침공 마물이 남아 있으면 새벽 정산을 시작하지 않는다. 낮의 야생 마물은 침공 종료 카운트에서 제외한다.

채집 고갈 시 확률로 귀중품을 얻고, 맵의 귀중품 오브젝트를 커서 기여로 수집한다. 새벽에 개수×단가를 돈으로 한 번 지급한 뒤 수집 잔량을 비운다. 모달 재표시/ESC로 중복 지급하지 않는다. 에테론의 환생 전용 지급 규칙과 무관하다. 환생/영구 해금은 여전히 이 프로토타입에 없다.

## 2차 피드백 구현 결과 · M5 / 2026-09-16

이번 절이 앞선 시야·카메라·기여 주기 설정을 대체한다. 최신 Windows 빌드에 포함되어 있다.

### 시야와 조명

- 낮에는 지면만 약간 어둡게 유지하고, 시야 밖 오브젝트는 셰이더 clip으로 숨긴다. 밤에는 바깥 지면도 암흑이며 오브젝트 역시 숨긴다.
- 낮밤 모두 안쪽은 정상 표시하고 경계 0.65타일에서만 Bayer 디더링한다. 이전의 반경×0.8 전환 폭과 밤 전체 반경 감쇠를 제거했다.
- 완공 집 9타일, 커서 7타일, 각 병력 5타일의 실시간 공유 시야. 이동 병력은 마을 밖에서도 자신과 주변을 보여준다. 커서 잔상 1.4초는 유지한다.
- 집 Point Light 반경 5→1.8, 강도 3→1.1. 전용 픽셀 셰이더는 같은 위치의 좁은 따뜻한 조명 색을 별도 계산한다. 일반 URP Lit 조명을 그대로 사용하는 셰이더는 아니다.
- 프로토타입 표시 한도는 시야 소스 128개(잔상 포함), 집 조명 32개다. 대규모 군중 단계에서는 공간 분할 방식으로 확장해야 한다.

### 조작과 UI

- 카메라: 화면 네 변까지의 최소 거리로 구간을 고른다. 160px 이상 안쪽 중앙 직사각형은 정지, 85~160px 속도 4, 35~85px 속도 10, 0~35px 속도 20 월드 단위/초. 가장자리 방향 축으로 이동하여 화면 종횡비에 따른 상하/좌우 속도 차이를 없앴다. 좁은 창에서는 바깥 띠를 짧은 변의 28% 이하로 제한한다.
- PrototypeSettings에서 구간과 속도 조절 가능. 휠 클릭(가운데 버튼)으로 카메라 고정 토글. UI 상단 띠 때문에 상하 이동이 막히지 않도록 카메라와 월드 기여의 UI 차단을 분리했다.
- 커서 기본 반경 2.1→1.4, 기여 주기 3→2초. 주민은 여전히 범위와 기여량을 증가시키고, 주기는 연구로만 단축한다. 회당 기여량은 유지했으므로 초당 기여량은 기존보다 증가한다.
- 커서 아래 작은 게이지를 제거하고 지면 범위 테두리를 12시부터 시계 방향으로 채운다. 미충전 테두리 알파에 대응하는 혼합 강도 0.22, 충전 0.72, 내부 0.055로 같은 색상을 섞는다.
- 헤더 배경 제거. 목재·석재·돈 도형 아이콘과 수치, 주민/주기 표시, 상단 중앙 날짜 진행 바.
- 기존 `Assets/Legacy/Scripts/UI/Stage/DayProgress.cs`의 LocateDayImage clamp 방식 참조: 짧은 전체 길이는 그대로, 긴 경우 아이콘이 중앙까지 이동 → 내용 스크롤 → 마지막 구간에서 내용 정지 후 아이콘이 끝으로 이동. 일당 160px, 표시 폭 최대 510px.
- ESC는 모달 닫기 → 선택/건설 해제 → 아무 선택이 없으면 일시 정지 메뉴. 메뉴에서 계속하기/종료 가능.

### 연출과 환경

- 병력·마물의 모델 정면을 +Z로 정리하고 이동 방향으로 회전. 30Hz 모델 위치를 화면에서 보간한다.
- 도끼(가로 베기), 곡괭이, 망치, 칼, 쥐는 손을 기본 입체 도형으로 모델링했다. 타격 전 0.32초 준비 동작을 보이고 모델 Contributed 이벤트와 타격 포즈를 같은 틱에 연결한다. 커서를 급히 옮겨 준비 동작이 없었던 대상도 실제 기여 시점의 타격은 즉시 표시한다.
- 나무·돌·적은 흔들림, 공사·수리는 눌림/복원, 귀중품은 튀어 오르며 축소 후 소멸. 죽거나 고갈된 대상도 0.38초 반응을 보인 뒤 표시를 제거한다. 보상/피해 자체를 애니메이션 종료까지 지연하지 않는다.
- 도구는 재사용 풀, 풀 군락은 단일 합친 메시다. 실제 최종 아트가 아닌 프로토타입 모델이다.
- 지면은 연속적인 절차적 색 혼합으로 풀·흙·눈·해변·물을 연결한다. 물은 시간에 따른 파문/물결 색과 해안 거품, 풀 군락은 셰이더 정점 흔들림을 사용한다. 지형은 이번에는 시각적 환경이며 물의 통행 제한·지형별 경제 효과는 추가하지 않았다.

### 끊김 분석과 수정의 증거

실행 프로파일을 수집하지 않았으므로 아래는 코드에서 확인한 과도한 비용 및 원인 후보다. 실제 랙의 단일 원인으로 확정하거나 FPS 개선량을 주장하지 않는다.

1. 이전 UpdateFog: 128×128=16,384개 지점마다 Visibility가 전체 Bodies와 잔상을 조회했다. 오브젝트 100개라면 한 갱신의 Bodies 조회만 약 164만 회, 0.08초 간격 기준 초당 약 2,048만 회 조건 검사가 발생할 수 있었다. 이 반복을 제거하고 시야 소스 좌표만 매 프레임 GPU에 전달한다. 마을 영역 텍스처는 영역이 바뀔 때만 다시 만든다. GPU 비용은 남아 있으며 실측 비교가 필요하다.
2. 이전 경로 탐색: 유닛마다 0.85초 재탐색, 최대 5,000노드, open 목록을 선형 검색했다. 최소 힙, 검색 내 장애물 결과 캐시, 1틱당 1개 검색 예산, 650노드 상한, 1.6초 이상 분산 간격으로 바꿨다. 상한에 걸리면 가까워진 중간 경로를 사용한다. 순환 순서로 유닛 처리하여 앞 유닛만 예산을 쓰는 것을 방지한다. 복잡한 막힌 지형의 경로 품질은 직접 확인 대상이다.
3. 이전 매 프레임 Renderer/Light 배열 탐색과 전체 색상 재적용, RaycastAll 정렬 할당을 캐시/호버 변경 시 갱신/NonAlloc 레이캐스트로 줄였다. 고정 30Hz 이동의 화면 위치 보간도 추가했다.
4. F3: 평균 FPS, 최근 1초 최대 프레임 시간, 현재 프레임 모델 및 표시 CPU 시간을 표시한다. Profiler 마커 `Prototype.ModelTick`, `Prototype.ViewSync`, `Prototype.VisionUpload` 추가. GPU 시간은 F3에 포함되지 않는다.

### 3차 구현 내용

- 기존 모션은 X축 회전 때문에 칼의 날이 아닌 옆면 방향으로 움직였고, 임의 루트 위치가 타격 위치와 무관했다. 손잡이 아래끝을 로컬 원점으로 유지하고, 날의 접촉점을 지정해 타격 자세에서 대상 표면에 닿도록 손잡이 위치를 역산한다.
- 칼·곡괭이·망치는 로컬 Z축에서 -10도→-115도로 아래로 찍는다. 타격 후 같은 방향으로 약간 통과한다. 손잡이가 지면 아래로 내려가지 않도록 타격 때 날이 아래를 향하게 했다. 도끼는 도구를 눕힌 뒤 Y축에서 수평 회전한다. 대상 주변 무작위 방향은 유지한다.
- TerrainMap은 1×1 타일마다 Grass/Dirt/Sand/Water/Snow를 보관한다. 같은 배열을 물체 생성·통행·배치와 표시가 공유한다. 시작 집 주변 11×11은 풀 타일로 보장한다.

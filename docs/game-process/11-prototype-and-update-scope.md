> 최신 확장: 사용자 요청으로 첫 2일 검증을 마치고 6웨이브·환생 확장판을 구현했다. 현재 범위와 검증은 [12 확장 프로토타입](12-rebirth-prototype.md)을 우선한다. 아래 후속 제안 중 환생의 작은 검증 범위는 구현됐으며 전체 본편은 여전히 후속이다.

# 프로토타입에서 확인할 것과 이후 제작 범위

현재: **M5 플레이 검증·수정 — 10 도구 모션·타일 지형 수정**. 첫 프로토타입의 제작 범위(M3)는 정리됐지만, 본편 상세 기획(M2) 전체나 실제 플레이 검증(M5)이 끝난 상태는 아니다.

## 1. 현재 프로토타입에서 끝낼 작업

목표는 “커서로 직접 도우며 마을을 키우고 병력에 방어를 맡기는 것이 편하고 재미있는가”를 짧은 2일 플레이로 확인하는 것이다.

| 묶음 | 이번 범위 | 끝났다고 판단할 기준 |
|---|---|---|
| 조작 | 마우스 자동 기여·원형 게이지·가장자리 카메라·선택/공격 이동·ESC | 의도하지 않은 이동/기여 없이 채집과 지휘를 오갈 수 있음 |
| 피드백 | 도구 날 방향과 접촉, 흔들림/반동, 호버와 자원 변화 | 어느 대상에 언제 효과가 발생했는지 즉시 이해할 수 있음 |
| 맵과 시야 | 타일 데이터·물 생성 제한·좁은 낮밤 경계·병력 시야 | 물 위 자원/건물/병력이 없고 이동 중 아군을 잃어버리지 않음 |
| 핵심 순환 | 자원→건설→돈→병력/연구→밤 방어→새벽 정산 | 첫날과 둘째 날에 실제로 선택할 여지가 있고, 준비 시간이 지나치게 빡빡하거나 한가하지 않음 |
| 기술 안정성 | 겹침/길막·프레임 끊김·모달/정산/승패·재시작 | 플레이를 막는 오류가 없고 F3/프로파일을 통해 성능 문제를 판단할 자료가 있음 |

현재는 코드 수정과 빌드는 진행했지만, 위 기준을 모두 만족한다는 플레이 증거는 아직 없다. 수정본에서 2일 플레이를 확인하고, 불편과 막힘을 고치는 데 집중한다. 아트 완성도와 모든 콘텐츠를 이 단계에서 채우지 않는다.

## 2. 다음 검증: 환생이 들어간 작은 확장 프로토타입

첫 조작/방어 루프가 안정되면 M2·M3에서 범위를 정하고 M4·M5를 한 번 더 반복하는 것을 제안한다. 본편 전체를 만들기 전에 게임의 또 다른 핵심인 “더 진행할지, 지금 환생할지”를 검증한다.

- 제단과 정비 시간의 환생 진입, 환생 정산 에테론, 작은 환생 강화 선택 화면.
- 환생 시 웨이브/마을/일반 강화 초기화, 같은 판 내 환생 강화 유지.
- 최종 클리어/패배 시 판 데이터 초기화, 영구 해금만 분리.
- 초반 환생 반복보다 후반 도전이 유리한 시간 대비 보상·강화 비용 확인.
- 이 단계에는 선택 몇 개와 짧은 웨이브로 판단할 수 있을 만큼만 넣는다. 전체 스킬 트리와 모든 해금 콘텐츠를 만들지 않는다.

이 목록은 후속 추천 범위이며 이번 수정에서 구현하지 않았다.

## 3. 이후 본편 제작과 업데이트 준비

| 단계 | 할 작업 |
|---|---|
| M2 상세 기획 / M3 범위 갱신 | 전체 웨이브 길이·적 구성·재화/강화 곡선·건물/병종 해금·저장 흐름 결정 |
| M4 본편 구현 / M5 반복 검증 | 자동 목재·석재 생산, 목장/방어탑 등 미구현 건물, 적 종류, 전체 일반·환생 강화, 영구 해금 콘텐츠 확장 |
| M4·M5 완성도 | 최종 모델·텍스처·애니메이션·소리·UI, 타일 아트/지도 생성 다양화, 튜토리얼·설정·저장/불러오기, 장시간 성능/밸런스 |
| M6 업데이트 준비 | 기존 출시 버전과 세이브 호환/초기화 정책, 업데이트 후보 회귀 검증, 알려진 문제, 패치노트·스토어 설명 |
| M7 배포·운영 | 별도 공개 배포 승인 후 Steam 업데이트 및 이용자 오류/반응 확인 |

## 다음 순서 제안

**이번 수정본 플레이 → 모션·지형·성능/핵심 순환의 문제 정리 → 첫 프로토타입 검증 종료 안내 → 작은 환생 검증 범위 확정** 순서로 진행한다. 프로토타입 단계 완료를 빌드 성공만으로 선언하지 않는다. 전체 기획 완료와 첫 프로토타입 완료도 별도로 브리핑한다.

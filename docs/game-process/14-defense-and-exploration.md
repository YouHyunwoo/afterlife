## 방어 시설과 사격

아래 수치는 검증용 초기값이다. 공사 중이거나 이전 중인 타워는 공격하지 않는다.

| 시설 | 비용 | 공격/역할 |
|---|---|---|
| 화살 타워 | 목재 45 / 석재 25 | 반경 6, 1.6초마다 화살, 기본 피해 18 |
| 마법 타워 | 목재 35 / 석재 55 | 완공 제단 필요, 반경 7, 2.8초마다 번개, 기본 피해 34 |
| 성벽 | 석재 12 | 체력 260, 침공 적이 다른 건물보다 우선 공격 |

화살은 타워에서 표적까지 Unity Raycast와 모델의 장애물 판정을 적용한다. 건물/자원 등이 막으면 장애물 높이를 넘는 포물선으로 발사한다. 비행 방향에 맞춰 화살이 기울고 도착 시 피해를 준다. 번개는 표적에 즉시 피해를 주고 0.2초간 타워와 표적 사이에 표시된다. 마지막 일격이어도 번개가 보이도록 유지한다.

궁수·마법사와 적 원거리 병종은 사거리에 들어왔다고 바로 쏘지 않는다. 사선이 막히면 표적 주변에서 사거리에 들고 시야가 트인 위치를 찾아 이동한 뒤 공격한다. 사선 검사는 2타일 장애물 버킷을 재사용하고, 사격 위치 탐색은 약 0.8초 간격으로 제한한다. 런타임 성능 개선량을 측정한 것은 아니다.

성벽은 상하좌우로 연결하고 꺾임/분기에는 원형 기둥을 만든다. 집은 벽·지붕 연결부, 제단은 연결부와 돌길을 만든다. 인접 배치·이전·파괴에 따라 갱신한다. 성벽은 아군 이동도 막으므로 통로를 남겨야 한다. 문/자동 개폐는 이번 범위에 없다.

## 처치 전리품과 새벽 정산

처치 즉시 보관 목록에 넣고, 새벽 정산에서 한 번 돈으로 바꾼다. 장비로 착용하거나 전투 능력에 사용하지 않는다.

| 대상 | 전리품 | 개당 돈 |
|---|---|---|
| 슬라임 | 슬라임 진액 | 1 |
| 고블린 | 몽둥이 + 뼈 | 2 + 1 |
| 고블린 전사 | 갑주 | 4 |
| 고블린 주술사 | 지팡이 | 5 |
| 오크 | 팔보호대 | 6 |
| 리자드 | 리자드 꼬리 | 4 |
| 동물 | 고기 + 모피 | 2 + 2 |

자원 아래에 보관 전리품의 예상 판매액을 표시하고 새벽 창에 판매 내역을 표시한다. 기존 귀중품은 1개당 5돈으로 함께 정산한다. 최종 승패 뒤에는 기존 규칙대로 판 데이터가 초기화된다.

## 상자와 유물

육지의 빈 곳에 초기 상자 4개를 놓고, 이후 낮 시간 누적 45~80초 간격으로 추가한다. 월드에 최대 7개를 유지한다. 상자는 수평 방향이 무작위이고, 커서 기여로 연다. 기존 프로토타입의 고정 난수 시드를 사용해 새 판 초기 배치를 재현할 수 있다.

최신 상자 규칙: 일반/희귀/고대 3등급. 보상 종류는 같은 확률로 아이템/돈/목재/석재/유물 중 하나이며, 등급별 수량과 허용 목록은 아래 수정 기록을 따른다. 유물은 해당 등급 허용 목록에서 미보유인 것만 추첨한다. 해당 목록을 모두 모으면 돈으로 대체한다.

| 유물 | 효과 |
|---|---|
| 숲의 도끼 | 채집 목재 지급량 +50% |
| 광부의 부적 | 채집 석재 지급량 +30% |
| 매의 눈 | 치명타 확률 +15%p (커서 기본 0% → 15%, 기본 배율 2배) |
| 수선의 망치 | 커서 수리 능력 +30% |
| 상인의 저울 | 교역소 환전 수령액 +25% |
| 풍요의 씨앗 | 나무·바위 생성 상한 +50% |
| 순환의 모래시계 | 나무·바위 생성 간격 -30% |

소지 유물은 왼쪽 위 자원 아래에 작은 가로 배지 목록으로 표시하고 호버하면 이름과 효과를 보여준다. 7종이 날짜 HUD와 겹치지 않게 줄였다. 채집 유물은 자원 소비량을 늘리지 않고 획득량에 보너스를 준다. 커서 기여 치명타는 아래 최신 규칙을 따른다. 매의 눈은 기존 아군 병력·타워의 치명타에도 적용되지만, 새 확률/배율 강화는 커서 전용이다. 수리는 남은 체력과 보유 목재에 의해 제한된다.

**AI가 둔 초기 정책:** 유물과 미정산 전리품은 현재 생에서 유지하며 환생 시 초기화한다. 환생 화면에 이를 표시했다. 중복 유물은 쌓이지 않는다. 환생 강화·미사용 에테론의 판 내부 유지 규칙은 그대로다. 유물의 환생 보존 여부는 추후 플레이를 보고 변경 가능하다.

## 지도와 발견물

지도 반경을 30 → 45로 확대했다(타일 배열 61×61 → 91×91). 기존 숲·암석 지대와 해안/눈 지형에 탐험 여유 공간을 늘리고 풀 배치 범위도 확대했다. 집이 멀리 확장되어도 침공이 시야 밖에서 생성되도록 생성 후보 반경을 마을 규모에 맞춘다.

- 버려진 제단: (-10, 5), (-26, -16). 마을 영역 편입 시 자동 건설/이전 속도 +25%.
- 고대 유적: (9, -11), (15, 24). 편입 시 두 타워 사거리 +1.
- 발견물 중심 타일이 집들의 마을 영역 안에 들어오면 효과를 받고, 해당 영역을 잃으면 해제된다. 같은 효과는 중복되지 않는다. 발견물은 일반 건설 제단과 별개이며 환생/병종 선행 조건을 대신하지 않는다.

## 건물 이전 조작

1. 건물을 한 번 클릭해 선택한다. 선택 테두리가 표시된다.
2. 선택한 건물에서 드래그해 목적 타일에 놓는다. 유효 위치는 청록, 막힌 위치는 빨강으로 표시한다.
3. 원래 건물은 공사 역순으로 낮아지고 목적지 건물은 올라온다. 자동 작업과 양쪽 위치의 커서 기여로 진행된다.
4. 건물을 한 번 클릭하면 교역/병영/연구소/제단 관리 창을 연다. ESC/우클릭은 선택 해제다.

완공된 건물만 이전 가능하며 목적지는 빈 육지·마을 영역이어야 한다. 이전 중에는 생산/타워/연구·제단 선행 기능을 중단한다. 추가 재료는 받지 않고 작업 시간을 사용한다. 원래 집의 인구·영역·시야는 이전 완료까지 유지하며 목적지와 중복 집계하지 않는다. 마지막 집을 이전하는 것만으로 패배하지 않는다.

완료 시 생산 대기열·병력 소속을 새 건물로 이관하고 체력은 두 위치 중 더 낮은 체력을 사용한다. 원래 건물이 파괴되면 새 공사도 소멸한다. 목적지가 파괴되거나 취소되면 원래 건물이 복구된다. 이전으로 자원/체력을 복제하지 않는다.

- 프로젝트 지침에 따라 Unity 테스트/플레이 모드는 실행하지 않았다. 실제 사격/연결 외형/이전/밸런스/성능은 직접 확인해야 한다.

실행 파일: `impls/unity/Afterlife/Builds/PixelPrototypeWindows/AfterlifePrototype.exe`

직접 확인 순서:

1. 재료를 모아 화살 타워·성벽을 지은 뒤 밤을 맞는다. 성벽 우선 공격, 타워 화살, 벽/나무를 넘는 곡사를 확인한다. 제단 이후 마법 타워의 번개도 확인한다.
2. 궁수·마법사와 적 사이에 건물을 두고 관찰한다. 막힌 채 계속 발사하지 않고 옆으로 이동한 후 공격해야 한다. 완전히 막힌 성벽에는 통로를 남긴다.
3. 성벽을 ㄱ자·T자로 놓아 원형 접합부를 확인하고 집·제단을 인접 배치한다. 건물을 선택→드래그해 자동 철거/재건과 커서 지원, 집 이전 중 인구/패배 판정을 확인한다.
4. 상자를 찾아 커서로 열고 유물 목록/재화 변화를 확인한다. 동물에 기여하면 도주하고, 처치 아이템은 즉시 돈이 아니라 새벽 판매액으로 쌓여야 한다.
5. 집을 이어 발견물을 영역에 넣고 버프 표시를 확인한다. 이후 집을 잃거나 이전하여 영역에서 빠지면 버프도 해제되어야 한다.
6. F3로 동물/숲/다수 병력·타워 전투의 프레임을 확인한다. 새 전리품과 타워 때문에 이전의 웨이브 압박이 과하게 낮아지지 않는지 살펴본다.

### 최신 변경 전후와 초기 수치

이전에는 상자를 한 번 기여로 열고 같은 보상 목록을 사용했다. 이제 내구도를 깎아 열며 등급별 보상을 쓴다. 기존 미보유 추첨은 유지하되 등급 조건을 추가했다. 숫자와 확률은 AI가 둔 초기 검증값이다.

| 등급 / 등장 확률 | 내구도 | 판매 아이템 풀 | 유물 풀 | 아이템 수 / 돈·목재·석재 |
|---|---|---|---|---|
| 일반 60% | 12 | 진액·몽둥이·뼈·고기·모피 | 숲의 도끼·수선의 망치 | 2개 / 25·40·30 |
| 희귀 30% | 36 | 갑주·팔보호대·리자드 꼬리 | 일반 풀 + 광부의 부적·상인의 저울·풍요의 씨앗 | 3개 / 50·80·60 |
| 고대 10% | 72 | 지팡이·팔보호대·갑주 | 희귀 풀 + 매의 눈·순환의 모래시계 | 4개 / 100·160·120 |

보상 종류 5개의 확률은 각각 20%. 유물 보상이 정해진 시점에 **등급 허용 풀 ∩ 미보유 유물** 안에서 균등 추첨한다. 빈 목록이면 일반/희귀/고대 각각 35/70/140돈으로 대체한다. 보상은 내구도 0 도달 때 한 번만 지급한다. 갈색/파란색/보라색과 장식으로 등급을 구분하고 호버 시 등급·남은 내구도를 표시한다. 부분 작업에서는 상자가 사라지는 연출이 나오지 않는다.

커서의 기본 치명타는 **확률 0% / 배율 2배**다. 연구소 일반 강화 두 가지를 추가했다.

- 확률 강화: 단계마다 +5%p, 최대 3단계. 매의 눈을 제외하면 0→5→10→15%.
- 배율 강화: 단계마다 +0.5, 최대 3단계. 2→2.5→3→3.5배.
- 계열별 비용 30/60/90돈. 일반 강화이므로 환생/판 종료 시 초기화.
- 기여하는 대상마다 한 번씩 판정하고 채집·건설·이전·수리·공격·상자 내구도 감소에 적용한다. 치명타 때 부유 수치에 `치명타!`를 표시한다.
- 채집은 재고, 건설은 완공, 수리는 남은 체력과 목재에 의해 실제 기여량이 제한된다. 귀중품 개수와 상자 보상을 치명타로 복제하지 않는다.
- 자동 공사·자동 생산에는 커서 치명타가 적용되지 않는다. 기존 병력·타워의 공격 치명타(기본 5%, 매의 눈 보유 시 20%, 배율 2배)는 별개이며 이번 커서 강화로 올리지 않는다.

나무/바위는 낮 전용 생태 생성에서 분리했다. **낮·황혼·밤 모두 기본 12초마다 종류별 1개씩** 무작위 위치 생성을 시도한다. 물에 걸친 위치, 건물/다른 자원/유닛 점유 위치와 시작점 반경 4 안쪽은 제외한다. 빈 위치가 없거나 상한에 도달하면 추가하지 않는다. 새벽 정산·메뉴·환생에서는 시뮬레이션이 멈춘다.

기본 상한은 나무 260, 바위 160이며 초기 숲/암석 생성량이 많으면 초기 개수+30을 하한으로 잡는다. 이 값은 새 생 시작 때 고정하고 채집으로 감소시키지 않는다. 풍요의 씨앗은 종류별 상한을 1.5배로 올리고, 순환의 모래시계는 12초를 8.4초로 줄인다. 동물/마물의 낮 생성 주기는 이 두 유물의 영향을 받지 않는다.

상인의 저울은 `(목재 수량 + 석재 수량×2) ×1.25`를 내림한 돈을 지급한다. 재료 소모량은 동일하며 미리보기와 실제 교역이 같은 계산을 사용한다. 새벽 전리품 판매에는 적용하지 않는다.

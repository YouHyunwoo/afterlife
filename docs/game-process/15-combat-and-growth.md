기존 AI는 모든 병력이 마을 주변의 가까운 적을 우선 선택했다. 순찰 위치도 현재 가까운 집 주변에서 무작위로 골랐다. 구역 배정이나 적별 아군 수 제한이 없어서 같은 방향으로 교전·순찰이 몰릴 수 있었다. 이는 코드로 확인한 원인이며, 새 AI의 체감 개선이 검증됐다는 뜻은 아니다.

## 병력 행동 변경

- 자동 방어 병력은 집들의 외곽을 기준으로 동·서·북·남을 먼저 채우고 대각선 방향을 채운다. 8명을 넘으면 추가 열을 둔다. 물·정적 장애물 위는 배정하지 않는다.
- 평상시에는 자신의 방어 지점 가까이에서만 작게 순찰한다. 집이 바뀌거나 병력 수가 바뀌면 자동 배정을 갱신한다.
- 표적은 담당 지점과의 거리, 현재 병력과의 거리, 이미 붙은 아군 수를 함께 평가한다. 일반 자동 병력의 추적 범위는 담당 지점 기준 약 8타일이다.
- 적 체력에 따라 기본 1~4명의 아군을 배정한다. 바로 앞 적과 교전 중인 병력까지 강제로 공격을 멈추게 하지는 않는 완만한 제한이다.
- 근접 병력은 적 둘레의 서로 다른 접근 위치를 찾고, 원거리는 사선이 열리는 지점으로 이동한다. 표적·이동 목표가 바뀌면 오래된 경로를 갱신하고, 막힌 채 0.7초 지나면 다시 길을 찾는다.
- 수동 공격 이동은 우선 유지한다. **도착 뒤 임의의 집으로 돌아가지 않고 명령 지점을 방어**한다. 그 지점 주변에서 약 6타일 안의 적을 상대하고 교전이 끝나면 돌아온다.
- 길찾기 계산 예산은 틱당 1회에서 3회로 높였다. 큰 마을/다수 병력에서 프레임 비용과 반응성의 균형은 직접 확인해야 한다.

닫힌 성벽이나 물로 완전히 차단된 지점까지 갈 수 있도록 장애물을 통과시키지는 않았다. 통로를 확보해야 한다. 병력이 아주 적을 때 모든 방향을 동시에 막을 수는 없다.

## 타워 확인과 강화

호버하면 현재 실제 공격 범위를 원으로 표시한다. 개별 강화·연구·유적 보너스를 모두 반영한다. 완공 타워의 공유 시야도 현재 공격 범위 바깥 경계까지 갱신한다. 라이트 범위를 크게 늘리는 방식은 사용하지 않는다.

완공 건물을 **한 번 클릭하면 관리 창**을 연다. 누른 채 8px를 넘겨 드래그하면 이전으로 구분하며 모달을 열지 않는다. 사전 선택은 필요 없다.

| 방식 | 단계·비용 | 효과 |
|---|---|---|
| 타워 개별 강화 | 0~5단계, 40/80/120/160/200돈 | 해당 타워 기본 피해 +20%, 사거리 +0.35/단계 |
| 화살 타워 피해 연구 | 0~5단계 | 모든 화살 타워 기본 피해 +20%/단계 |
| 마법 타워 피해 연구 | 0~5단계 | 모든 마법 타워 기본 피해 +20%/단계 |
| 화살/마법 범위 연구 | 각각 0~5단계 | 해당 종류 타워 사거리 +0.5/단계 |
| 타워 동시 공격 | 기본 1단계=1대상, 최대 5단계=5대상 | 서로 다른 적에게 화살/번개를 동시에 발사 |

개별 피해와 연구 피해 보너스는 더해서 적용한다. 예를 들어 개별 2단계·연구 3단계라면 기본 피해 ×(1+0.4+0.6)=2배다. 다중 공격은 타워 전용이며 커서는 기존 범위 내 동시 기여를 유지한다. 개별 강화는 건물 이전 시 유지하고 환생 시 초기화한다. 공사/이전 중에는 타워를 강화하거나 공격시킬 수 없다.

## 일반 스킬 트리 확대

연구소를 요구하는 일반 연구를 세 탭으로 나눴다. 일반 연구의 최대 단계를 기존 3에서 **5**로 늘렸다. 환생 강화 3계열의 별도 3단계 규칙은 바꾸지 않았다.

| 탭 | 연구 | 현재 초기값/단계별 효과 |
|---|---|---|
| 커서·마을 | 기여 주기 | 2초 ×0.84^단계, 최소 0.75초. 5단계도 실제 이득이 있도록 고정 차감 방식 변경 |
| 커서·마을 | 집당 주민 | 기본 1명, 단계마다 +1명. 인구 상한은 별도 |
| 커서·마을 | 자동 건설 | 단계마다 기본 속도 +50% |
| 커서·마을 | 치명타 확률/배율 | 각각 +5%p / +0.5배. 커서 기본 0%, 기본 2배 |
| 방어 시설 | 성벽 체력 | 기본 260, 단계마다 +25%, 5단계 585 |
| 방어 시설 | 두 타워 피해·범위 | 위 표 참조 |
| 방어 시설 | 동시 공격 | 기본 1대상 → 최대 5대상 |
| 화상 | 발화 확률 | 기본 0%, 단계마다 +5%p, 최대 25% |
| 화상 | 발화 순간 피해 | 기본 8, 단계마다 +30% |
| 화상 | 화상 지속 피해 | 기본 초당 3, 단계마다 +40% |
| 화상 | 화상 지속 시간 | 기본 3초, 단계마다 +1초 |

일반 연구 비용은 계열별 30/60/90/120/150돈이다. 동시 공격은 처음부터 1단계이므로 2~5단계 구매가 30/60/90/120돈이다. 발화 순간 피해·지속 피해·지속 시간은 발화 확률을 먼저 한 단계 연구해야 구매 가능하다.

성벽 연구는 현재 성벽과 새로 짓는 성벽 모두에 적용된다. 이미 손상된 성벽은 남은 체력 비율을 보존하며, 강화로 손상 비율을 지우지 않는다. 모든 일반 연구는 환생/판 종료 시 초기화된다.

## 발화와 화상

커서·아군 병력·타워의 **직접 적중**이 살아 있는 적에게 피해를 주면 발화 확률을 판정한다. 발화하면 즉시 추가 불 피해를 주고 남은 적에게 지속 피해를 적용한다. 동물/자원/아군/건물에는 이 공격용 발화가 전파되지 않는다.

화상 피해는 0.5초 간격으로 경과 시간만큼 적용하며, 끝의 짧은 잔여 시간도 계산한다. 화상은 다시 발화를 일으키지 않고 치명타나 경직을 반복하지 않는다. 같은 적에게 다시 발화하면 지속 시간과 더 강한 지속 피해를 유지하며 여러 화상을 곱해서 쌓지 않는다. 화상으로 죽은 적도 처치·전리품을 한 번만 정산한다.

적 주변에 작은 불꽃을 표시하고 `발화`, `화상` 수치를 띄운다. 불꽃에도 기존 시야 셰이더를 적용한다.

## 웨이브에 비례하는 자원 내구도

- 나무 최대 내구도 = 70 × 현재 날짜, 바위 = 50 × 현재 날짜.
- 다음 낮으로 넘어갈 때 살아 있는 기존 자원도 새 최대치로 바꾸되 **남은 내구도 비율을 보존**한다. 채집 진행을 초기화하지 않는다.
- 새로 생성되는 자원도 현재 날짜의 내구도를 사용한다. 환생하면 첫날 값으로 돌아간다.
- 한 자원의 기본 목재/석재 재고는 기존 70/50을 유지한다. 깎은 내구도 비율만큼 지급하므로 후반에는 같은 자원을 캐는 데 더 많은 기여가 필요하다. 주민·치명타·기여 주기 성장과 함께 경제 압박을 검증한다.
- 호버에 내구도와 남은 기본 재고를 함께 표시한다. 채집 유물의 추가 지급은 유지한다.

## 검증과 직접 확인

관련 C# 빌드는 오류 0·경고 0. Unity 플레이/자동 테스트는 프로젝트 지침에 따라 실행하지 않았다. 아래는 사용자 직접 확인 대상이며 AI 동작 개선·장시간 프레임·재미가 확인됐다고 보고하지 않는다.

1. **병력 4~8명:** 명령 없이 마을 둘레에 분산되는지 보고, 양쪽 침공 때 가까운 담당 병력끼리 대응하는지 확인한다. 수동 공격 이동 후에는 명령 지점에 머물고 전투 뒤 돌아와야 한다. 성벽에 통로를 남긴 상태에서 확인한다.
2. **타워:** 호버 범위 확인 → 한 번 클릭 → 개별 강화 → 연구소 범위 연구. 표시 원과 실제 사격 범위가 함께 커져야 한다. 동시 공격 5단계에서 사거리 안의 서로 다른 적 최대 5명에게만 발사해야 한다.
3. **화상:** 발화 확률 연구 전에는 발생하지 않아야 한다. 연구 후에는 일부 직접 타격에서 불꽃·추가 피해가 발생하고, 시간이 지나면 꺼져야 한다. 화상만으로 적이 무한 경직되지 않아야 한다.
4. **자원:** 일부 채집한 나무를 남겨 다음 날로 넘어간다. 최대 내구도가 증가하되 남은 비율과 재고가 보존되고, 새 자원도 같은 날짜 기준을 써야 한다.
5. **건물 입력/볼 제거:** 교역소·병영·연구소·제단·두 타워를 각각 한 번 클릭하면 관리 창이 열려야 한다. 처음 누른 채 드래그하면 모달 없이 이전해야 한다. 커서 공전 볼과 연구 항목이 없어야 하며, 커서를 빠르게 왕복해도 접촉 기여가 생기지 않아야 한다.
6. **재시작/성능:** 환생하면 일반 연구·개별 타워 강화·화상이 초기화되어야 한다. F3로 다중 타워·화상·병력이 많은 후반의 끊김과 반응성을 확인한다.

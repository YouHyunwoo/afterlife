# M5 · 16 UI 폴리싱

> 확정 기획 · 2026-10-03: 채집·건설·수리·공격은 버튼을 누르고 있는 동안 작업 주기에 맞춰 반복하고, 강화는 작업 1회당 작업량을 높인다. 자동 수입은 농장 건설·생산 강화로 확장한다. 본편 상호작용 필드·슬롯·충전·호버 자동 작업은 폐기한다. [새 규칙·사용법·검증](71-click-work-and-farm-automation.md). 새 규칙은 게임 코드·에셋에 아직 적용하지 않았다. 이전 규칙·수치·QA는 당시 기록으로 보존한다.




상태: 이번 UI 구현·QA 완료. 남색/황동/청록의 단순한 16-bit 픽셀 아트, 1920×1080, 폴리싱 전 대비 HUD 80%, 카메라 가장자리 각 축 25%, 관리 창 시간 진행·ESC 메뉴 정지를 적용했다. 커서 기여 주기는 월드 표시로 확인하며 HUD에 중복 표시하지 않는다. 미정산 전리품은 왼쪽 아이콘 버튼에서 여는 모달로 확인한다. 마을 건설은 같은 왼쪽 사이드 메뉴의 아이콘이며, 목록은 사이드 메뉴를 가리지 않도록 바로 오른쪽에 열린다. [QA 결과와 실제 화면](16-ui-qa.md)에 최종 57장 캡처·11개 자동 확인·실제 입력 검증을 기록했다. M5 전체 게임 검증은 계속 진행한다.

## 확정 요청

- 하단 푸터 제거, 모든 UI의 잘리는 텍스트 수정.
- 상단 정보 HUD 때문에 월드 선택이 막히지 않게 수정.
- 시야 디더링을 부드러운 투명도 전환으로 교체. 기존 시야 정보 규칙은 보존: 범위 내부는 선명, 바깥 오브젝트는 숨김, 경계만 부드럽게 전환. 낮 지면은 약하게 어둡고 밤 시야 밖 지면은 어둡게 유지.
- HUD를 현재보다 조금 축소, 카메라 가장자리 이동 구간 확대.
- UI 디자인 규칙을 먼저 작성하고 모든 창에 일관되게 적용.
- imagegen으로 프로젝트용 스프라이트 제작, 공식 참고 게임은 Slotbound Demo.
- 사용자 답변을 모두 받은 후 자율 진행하고 완료 결과·검증 한계를 기록.

## 수정 전 확인한 문제

- OverUi가 상단 108 논리 px와 하단 93 px 전체를 차단한다. 실제 컨트롤 사각형 기반 판정으로 교체한다.
- 고정 높이 Label/버튼/모달에 긴 한글 설명을 넣어 잘림 위험이 있다. 폰트 측정 기반 높이·줄바꿈·스크롤로 해결한다.
- 카메라 이동 기본 구간은 가장자리 160px다. 해상도 비율 기반 구간과 단계 속도를 조정한다.
- PixelSurface는 오브젝트 clip과 지면 조명에 디더를 사용한다. 투명도 처리 시 물·풀·수면·그림자·정렬까지 함께 검토한다.

## 디자인 규칙 — 사용자 답변 반영

1. 어두운 남색 패널, 절제된 황동 프레임, 아이보리 본문, 청록 선택 상태. 경고는 주황/빨강. 색에만 의미를 의존하지 않는다.
2. Mona12 한국어 텍스트 전용 폰트. 제목/본문/보조/수치 계층을 고정하고 긴 내용을 맞추기 위해 글자만 작게 줄이지 않는다.
3. 모든 창은 동일한 제목 영역·본문 여백·닫기 위치·행동 버튼 구조를 사용한다. 내용이 길면 본문만 스크롤하고 제목과 닫기는 유지한다.
4. 공통 간격 단위 8, 내부 여백 16~24 논리 px. 텍스트 높이를 측정하고 버튼 설명/비용을 필요한 경우 별도 줄로 분리한다.
5. 기본/호버/눌림/선택/비활성/잠금 상태를 통일한다. 재화 부족과 해금 조건을 구분한다.
6. 정보 HUD와 빈 공간은 월드 입력을 통과시킨다. 조작 버튼·열린 패널·모달은 해당 영역에만 입력을 차단한다. 메뉴/모달이 열려 있을 때의 게임 시간은 사용자 선택을 반영한다.
7. 생성 이미지에는 글자·숫자를 넣지 않는다. 복잡한 묘사 대신 16-bit 픽셀 아트로 통일한다. 프레임은 늘려도 모서리가 찌그러지지 않게 분리하고 아이콘은 같은 시점·광원·외곽선 굵기를 유지한다. 메뉴·카메라 고정도 아이콘 버튼이며 Kenney의 공식 픽셀 ESC/마우스 가운데 버튼을 함께 표시한다. [자산과 프롬프트 기록](ui-assets.md)을 따른다.
8. 상시 애니메이션·번쩍임을 줄이고 호버/선택/획득 순간에 짧은 피드백을 준다. 월드 시야는 디더 패턴 없이 부드러운 경계로 처리한다.
9. 기본 HUD는 폴리싱 전 대비 약 80%로 확정하며 설정으로 조정한다. 최소 검토 해상도 1280×720, 기준 1920×1080, 2560×1440/울트라와이드 추가 점검. 가장자리 이동 구간은 각 축 25%, 메뉴 설정에서 15~35% 조절한다.

## 질문 기록 — 전부 답변 완료

미술 방향은 남색/황동/청록으로 유지한다. 아래는 재질문한 선택지 이력이며 최신 확정 내용은 문서 상단을 따른다.

1. 상시 정보 밀도: 자원·주민/상한·유물·날짜/낮밤 진행·남은 적·메뉴/카메라 고정의 기본 구성, 기여 주기/미정산 전리품 추가, 최소 구성 중 선택.
2. 건설 메뉴: 좌측 접이식 기본 닫힘(추천), 좌측 기본 열림, 하단 버튼에서 팝업 목록 중 선택.
3. 주 사용 모니터 해상도: 자유 입력. 모를 경우 모름으로 답변 가능.
4. HUD/카메라 기본값: 현재 대비 HUD 80%·가장자리 이동 구간 25%(추천), HUD 90%·구간 25%, HUD 80%·구간 35% 중 선택. 두 값은 설정에서 조절 가능하도록 제안.
5. 관리 모달 시간: 계속 진행(추천), 정지, 느리게 진행 중 선택. ESC 메뉴는 일시정지 제안.

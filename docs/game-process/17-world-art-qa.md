별도 `Logs/WorldQA/live01` 플레이어를 사용자에게 보이는 창으로 실행하고 Win32 마우스/키 입력을 전달했다. 게임 로직에 명령을 직접 주입한 확인과 구분한다.

## 수정과 재검증

초기 실행의 환경 메시 읽기 설정, 상자 회전, 검 준비 동작, 어두운 색 양자화 문제를 수정했다. 리자드의 원거리 공격과 활 모델을 일치시켰다. QA 수동 배치의 연결 갱신 누락, 카메라 재설정에 따른 빈 자원·도구 캡처도 수정하고 최종 화면으로 교체했다. 초기 실패·중간 출력은 `Logs/WorldQA/pass01`~`pass04`에 남아 있으며 최종 통과 증거로 세지 않았다.

## 한계와 후속

- AI가 실제 화면을 확인한 기술·시각 QA다. 시중 게임 수준에 대한 사람들의 평가나 장기 플레이의 재미를 입증하지 않는다.
- 관절 애니메이션은 Blender 원본의 관절을 게임의 타격 시간에 맞춰 절차적으로 구동한다. 상자/보행/공격의 편집용 타임라인 예시는 `.blend`에 저장했고 FBX 애니메이션 클립 재생 방식은 사용하지 않는다.
- 전투 촬영은 긴 낮과 배치된 적을 사용한 연출 확인이다. 웨이브 전체의 난이도·환생 동기 검증은 별도다.
- 이번 확인 해상도는 1920×1080. UI 16에서 했던 다른 해상도 검증을 이번 월드의 추가 검증으로 세지 않는다.
- 새 C# 예외·셰이더 오류·자산 누락·메시 결합 오류는 최종 로그에 없었다. 기존 종료 시 `ComputeBuffer` 정리 경고는 여전히 발생하며 별도 렌더 자원 수명 관리 후속 항목이다.
- Unity Editor Test Runner/PlayMode는 실행하지 않았다. 사용자 요청에 따라 독립 Windows 플레이어에서 화면과 입력을 검증했다. QA 창은 종료했다.

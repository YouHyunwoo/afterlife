## 목표와 변경 전

기존 건물·병력·자원 대부분은 Unity 기본 도형 조합이다. 건물 간 형태 차이가 작고 슬라임 이동은 작은 상하 이동, 상자는 열리지 않고 축소되어 사라진다. 지면은 타일 종류를 공유하지만 대부분 색 차이로 표현된다.

Blender에서 편집할 수 있는 원본과 Unity용 FBX를 제작한다. 작은 게임 화면에서도 용도를 알 수 있도록 실루엣·재질·장비를 구분한다. 건축은 회벽·목재·석재, 병력은 청록/남색, 마물은 종별 피부와 장비로 통일한다. 디테일을 작은 입방체로 무작정 늘리지 않고 면 색상과 큰 형태에 집중한다.

## 확인 기준

- 기본 카메라에서 집·병영·교역소·연구소·제단·타워와 전사/궁수/마법사/기사, 마물 종류가 구분된다.
- 이동은 +Z를 향하고 발 디딤·팔·장비가 함께 움직인다. 공격 준비→타격→회복이 모델의 피해 시점과 맞는다.
- 상자는 경첩을 중심으로 열리고 내용물이 보인 뒤 사라진다. 슬라임은 준비 압축→도약→착지 복원이 보인다.
- 지형 표현은 실제 타일 데이터와 일치하고 물 위 자원 제한, 건설·이동 규칙이 유지된다.
- 정상 게임 카메라·근접 화면·낮/밤·전투 화면을 실제 빌드에서 캡처하여 확인한다. 모델 파일 생성만으로 완료 처리하지 않는다.
- 공개 배포나 인간의 재미·출시 품질 검증 완료를 뜻하지 않는다.

커서 기여 주기는 월드 링에서 확인, 전리품은 왼쪽 메뉴 모달, 건설 목록은 왼쪽 메뉴 오른쪽, 기준 1920×1080. HUD 80%·가장자리 이동 25%, 관리창 시간 진행·ESC 메뉴 정지로 유지한다.

## 제작 결과

- 새 FBX 49종: 건물 12, 연결 성벽/건물 모듈 5, 나무·바위 8, 상자 3, 병력·마물 10, 귀중품 1, 기여 도구 5, 환경 소품 5.
- 기존 Blender 동물 4종: 얼굴·귀·뿔을 머리 관절로 묶고 꼬리 관절을 추가했다.
- 원본: `res/art-source/world/AfterlifeWorld.blend`, `res/art-source/animals/AfterlifeAnimals.blend`.
- 재현 도구: `tools/art/build_world.py`, `tools/art/build_animals.py`. Blender 5.0으로 실행하며 `.meta`는 Unity에서 생성한다.
- 원본 타임라인: 1~25 걷기/슬라임 도약, 30~45 공격 자세, 상자 1~28 개봉 예시. 실제 게임은 같은 관절을 C#에서 모델의 준비·타격·회복 시간에 맞춰 구동한다.
- 지면 종류/건설 격자는 기존 `TerrainMap`을 유지한다. 물결과 지면 색 경계를 다듬고 숲의 고사리·쓰러진 통나무, 해안 갈대, 암석 지대 자갈, 초원 야생화를 추가했다. 장식은 8×8 타일별 메시로 묶으며 게임 자원이나 이동 장애물로 취급하지 않는다.

## 화면 QA에서 수정한 문제

1. 런타임 메시 결합에 필요한 환경 소품의 읽기 설정 누락 → 전용 임포터에서 해당 5종만 Read/Write 활성화.
2. 상자 경첩의 회전 방향 반대 → 뒤로 105도 개봉, 짧은 반동, 내용물 상승 후 1.4초 내 정리.
3. 준비 자세에서 검이 아래를 향함 → 어깨와 손목을 분리해 들어 올림→전방 타격→회복으로 수정.
4. 선형 공간 색 양자화로 어두운 목재가 붉고 평평하게 보임 → 화면 색 공간에서 32단계 양자화.
5. 리자드는 기존 규칙상 원거리 병종 → 모델도 활·화살통으로 일치시킴.
6. 성벽 갤러리의 수동 배치가 지형 변경 번호를 갱신하지 않음 → QA 배치 함수를 수정하고 실제 연결 메시 확인 추가. 일반 건설은 기존 갱신 규칙을 유지한다.

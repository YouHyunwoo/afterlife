## 관찰과 수정

첫 캡처에서 프레임이 외곽에 놓이고 본문 패딩이 유지되는 것을 확인했다. 작게 표시한 태양이 마름모처럼 보여 햇살을 분리하고 재빌드했다. 혼합 낮밤 유물 아이콘은 옆 칸의 성벽 픽셀이 포함돼 경계를 다시 지정했다. 최종 화면에서 자원·주민·유물·건설/방어·상단 버튼 아이콘, 교역소 프레임, 결과창의 영문 제거를 확인했다.

## 검증 범위와 한계

개발용 독립 실행 시나리오로 적의 우선 대상/시야 밖 제외, 돈과 아이템 동시 획득, 중복 지급 차단, UI 주변 카메라 정지/바깥 이동/월드 클릭 통과를 확인했다. Unity 에디터 PlayMode나 Test Runner는 사용하지 않았다. UI 접근은 좌표를 넣어 카메라 함수를 호출한 확인이며 사람의 장시간 조작감 검증은 아니다. 실제 클릭 회귀는 앞선 16·17 증거를 이번 변경의 증거로 재사용하지 않는다.

새로운 실행 예외는 없었다. 종료 시 기존 ComputeBuffer 정리 경고가 재현됐으며 이번 변경에서 해결한 것으로 보지 않는다. 전체 판의 난이도·환생 효용·경제 밸런스는 M5의 후속 검증이다.

직접 확인할 때는 왼쪽 메뉴와 유물에 마우스를 접근시켜 카메라가 멈추는지, UI에서 떨어진 가장자리에서 다시 이동하는지 확인한다. 밤에는 병력/타워/성벽이 적 시야에 함께 들어왔을 때 가까운 우선 대상을 공격하고, 처치 직후 돈 및 전리품 목록이 증가해야 한다.

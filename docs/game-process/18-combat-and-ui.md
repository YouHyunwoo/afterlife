초기 구현 가설: 적 시야 8타일(원거리 10), 같은 우선순위에서는 표면 거리 기준. 습격자는 목표가 시야 밖이면 마을 방향으로 접근한 후 탐색한다. 처치 돈은 종별 정수 보상, 아이템은 기존 새벽 정산 유지.
## 변경 내용

- 적: 기존의 전역 성벽 추적을 제거했다. 자신의 시야(근접 8 / 원거리 10타일) 안에서 병력·화살/마법 타워·성벽을 같은 높은 우선순위로 놓고 가까운 대상을 고른다. 다른 건물은 차순위다. 시야 밖의 습격자는 마을로 접근한 뒤 대상을 획득한다. 적 시야는 플레이어 시야를 넓히지 않는다.
- 처치: 슬라임 2, 고블린 3, 전사 고블린 5, 주술사/리자드 4, 오크 8원을 즉시 지급한다. 기존 종류별 아이템도 동시에 보관하며 새벽에 판매한다. 중복 사망 보상은 차단된다. 수치는 밸런스 초기값이다.
- 창: 첨부 이미지와 같은 기존 PanelFrame16의 투명 바깥 여백을 UV에서 제외하고 9분할로 외곽에 배치했다. 남색 배경은 안쪽에만 채운다. 본문/스크롤 패딩은 유지했다. 모달과 결과창의 AFTERLIFE 영문 장식을 제거했다.
- 아이콘: 아틀라스 칸 중심 대신 실제 그림의 경계와 종횡비로 가운데 맞췄다. 낮에는 태양, 황혼/밤에는 초승달을 일차와 진행 마커에 표시한다.
- 마을: 건설 가능 영역 데이터를 타일당 1픽셀의 Point 텍스처로 전달하고 해당 타일 바닥에 청록 경계와 약한 채색을 표시한다. 시야의 부드러운 투명도는 유지한다.
- 카메라: 왼쪽 메뉴/유물 주변 32 HUD 단위, 오른쪽 버튼 주변 28, 열린 건설창 주변 24의 여유 영역에서 이동을 즉시 멈춘다. 1920×1080 기본값에서 약 51/45/38px다. 영역을 벗어나면 가장자리 이동이 다시 작동한다. 카메라 제어만 정지하며 정보 HUD의 월드 클릭 통과를 유지한다.

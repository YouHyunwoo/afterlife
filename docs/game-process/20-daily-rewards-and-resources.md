## 확인한 원인
기존 채집은 `Stock × 기여 피해 / 현재 Health`였다. 날짜가 오를 때 체력만 증가하고 Stock은 고정되어, 실질 채집량이 일차에 반비례했다. uGUI 툴팁은 체력과 Stock을 동시에 표시했고 유적 편입 효과 분기가 누락됐다.

## 적용 방향
자원 Health는 실제 잔량, MaxHealth는 생성 시 총량으로 통일한다. 기여량(주민·환생·치명타·채집 유물 포함)을 잔량에서 직접 차감한다. 기존 자원은 날짜 전환으로 다시 채우지 않고, 새로 생성되는 자원만 현재 일차 총량을 사용한다.

하루 보상은 결산 확인 뒤 선택한다. 미보유 유물을 우선하여 서로 다른 3종을 추첨하며 부족한 후보는 보유 유물 강화로 채운다. 유물 강화는 해당 효과를 누적한다. 상자는 기존 미보유 추첨을 유지한다. 마지막 날에도 선택 후 결과를 표시한다. 이 수치와 누적 방식은 밸런스 가설이며 플레이 경험 검증은 별도다.

## 환전 제안 — 아직 미적용
추천은 나무·돌을 채집하면 즉시 골드로 지급하고 건설·수리·병력·연구 비용을 골드로 통일하는 방식이다. 채집 대상은 숲/바위로 유지하고 재고만 단순화한다. 돌의 가치와 채집 속도, 접근 거리 차이로 선택 이유를 남긴다. 기존 교역소는 자동 수입 증가 건물로 바꾸거나 제거한다. 전리품 새벽 정산은 하루 결산의 의미를 위해 유지한다.

대안은 건설용 목재·석재를 일정량 비축하고 초과분만 자동 판매하는 방식이다. 자원 구분의 전략은 유지되지만 비축 기준 설정이 필요하다. 최소 변경은 25%/50%/전량 즉시 환전 버튼이며 반복 환전 자체는 남는다.

단일 골드 채택 시 모든 건설/취소 환급/수리/환생 재화 보너스/상자/유물/교역소를 함께 변환해야 하므로 이번 버그 수정과 분리한다.

## 변경 결과
- 유적: 마을 편입 시 타워 사거리 +1, 버려진 제단: 자동 건설 +25%. 현재 효과 적용 여부와 중첩 불가 표시.
- HUD 유물 툴팁이 뒤쪽 월드 오브젝트 설명으로 덮어써지던 우선순위도 수정.
- 생존 보상: 결산 확인 → 3개 중 선택 → 획득 확인/다음 날 또는 환생. 선택 전 ESC/닫기는 선택 화면으로 연결하고, 선택 중에는 건너뛰지 않는다. 모델도 보상 대기 중 다음 날/환생을 거부한다. 더블클릭으로 중복 지급되지 않는다.
- 총 7종 유물. 미보유 후보가 3개 미만이면 보유 유물 강화 후보로 채우며 매번 서로 다른 3종을 제시한다. 상자는 미보유 유물만 지급. 환생/판 종료 시 유물 단계와 보상 상태 초기화.
- 자원은 Health=잔량, MaxHealth=생성 당시 총량. Stock은 기존 QA 코드 호환용 동일 값 접근자이며 별도 저장값이 아니다.
- 날짜에 따라 기존 자원 체력이 불어나던 코드 제거. 신규 나무는 70×일차, 신규 바위는 50×일차의 총량. 더 오래 채집할 수 있지만 단위 기여당 지급량은 감소하지 않는다.
- 표시: `남은 자원 현재 / 총량`. 월드 기여 숫자는 잔량에서 실제 차감한 양(소수 1자리), 인벤토리는 기존 정수 지급과 소수 누적 이월 방식 유지. 마지막 채집은 잔량으로 제한한다.
- 유물 도끼/부적은 잔량 소진 뒤 보너스를 덧붙이던 방식에서 실제 채집 기여 배율로 변경해 오브젝트 총량과 지급 자원의 관계를 맞췄다.
- 보상 버튼은 씬에 저장. 설치 도구는 기존 UI 위치·스타일을 보존하고 누락된 보상 그룹과 바인딩만 추가한다. 런타임 생성 없음.

## 직접 확인 절차와 기대 결과
1. 최신 Windows 실행 파일로 시작한다. 나무/바위에 마우스를 올리면 체력 줄 없이 잔량/총량만 보인다. 채집 숫자만큼 잔량이 줄고, 소수는 이월된다.
2. 첫 밤 생존 후 결산의 생존 보상 선택을 누른다. 이름과 효과가 있는 서로 다른 3개 버튼이 보여야 한다. ESC로 다음 날이 시작되면 안 된다.
3. 하나를 고르면 HUD에 해당 유물이 나타나고 나머지 선택지는 닫힌다. 이후 다음 날을 시작한다. 다음 밤에는 새 선택을 한 번만 제공한다.
4. 주민 수·환생 작업 효율·채집 유물을 올린 상태에서 같은 종류의 충분한 잔량 자원을 비교한다. 주기당 기여량은 증가하고, 기여 주기 연구는 시간당 채집 횟수를 늘린다. 일차 상승으로 주기당 채집량이 줄면 안 된다.
5. 유적과 버려진 제단에 마우스를 올려 편입 효과 설명을 확인한다. 마을 편입 후 적용 상태를 확인한다.
6. 반복 생존/상자로 미보유 유물이 3개 미만인 경우 기존 유물 강화 후보가 표시되는지 확인한다. 환생 뒤 단계/목록이 비워지고 첫날 보상이 다시 제공되어야 한다.

현재 완료는 요청 기능 구현·컴파일·빌드 범위이며 M5 전체 한 판 경험 검증이나 M6 출시 준비 완료가 아니다.

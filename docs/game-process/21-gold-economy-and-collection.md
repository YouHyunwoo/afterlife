## 채택된 방향과 초기 수치
사용자가 채집 즉시 골드 통일 및 교역소 제거를 요청했다. 나무는 목재 아이콘, 바위는 석재 아이콘으로 채집 출처를 구분한다. 모델은 즉시 골드를 지급하고 아이콘 이동/표시 금액은 뷰에서 처리한다. 연출이 지급이나 게임 진행을 지연시키지 않는다.

기존 환전 가치인 목재 1=골드 1, 석재 1=골드 2를 기준으로 기존 건설비를 합산한다. 수리는 체력 10당 골드 1, 전리품 새벽 결산은 유지한다. 상인의 저울은 채집 골드 보너스로 변경한다. 수치의 실제 경제 밸런스는 별도 확인 대상이다.


## 변경 전후
- 이전: 목재·석재 재고를 쌓아 건설/수리에 사용하고 교역소에서 골드로 수동 환전했다. 이후: 채집 즉시 골드 획득, 일반 소비는 골드만 사용한다. 특수 재화 에테론은 기존 환생 전용으로 유지한다.
- 교역소 건설 버튼/관리창/환전 함수/슬라이더를 제거했다. Kind.Market 열거형 번호와 과거 월드 아트 분기는 기존 직렬화 번호 보존용으로 남겼으며 건설 모델이 이를 거부한다. QA 시드에서도 생성하지 않는다.
- 골드 건설비: 집 20, 농장 30, 병영 80, 연구소 110, 제단 120, 화살 타워 95, 마법 타워 145, 성벽 24. 완공 전 취소는 미진행 비율의 골드를 내림 환급한다. 건물 이전은 기존처럼 무료다.
- 수리: 체력 10당 골드 1. 병력 생산/연구/타워 강화는 기존 골드 비용 유지.
- 상자 목재·석재 보상은 기존 가치로 즉시 골드 지급. 상자/처치 보상과 새벽 전리품 결산 금액은 HUD에서 부드럽게 증가하되, 채집 전용 아이콘은 실제 채집에서만 발생한다.
- 상인의 저울: 단계마다 채집 골드 +25%. 도끼/부적의 채집 기여 증가와 구분한다. 환생 잔여 재화 보너스는 골드만 집계한다.
- 소수 골드는 공통 누적 잔여값으로 보관하고 다음 채집에 이월한다. 환생/새 판/판 종료 시 초기화한다.

## 채집 연출 구조
- 모델의 HarvestGold 이벤트는 채집 위치·자원 종류·실제 지급한 정수 골드를 전달한다. 순수 C# 모델은 Unity UI를 참조하지 않는다.
- 실제 잔고는 이벤트 전에 증가한다. 화면 표시만 아이콘 도착까지 미루므로 연출 중 건설/연구가 가능하다. HUD 골드 툴팁에서는 실제 잔고를 확인할 수 있다.
- 1회 3~6개 아이콘(지급액이 적으면 그 이하). 목재/석재 기존 Sprite를 사용한다. 짧은 튕김 0.25초 → 곡선 흡입 0.55초, 조각별 지연. 도착 시 골드 아이콘이 작게 반응하고 숫자가 누적된다.
- 화면 밖 채집 또는 96개 풀 초과분도 지급은 손실되지 않는다. 금액 표시 목표에 즉시 합류한다. 아이콘 금액 분할 합계가 원 지급액과 같으며 아이콘 수만큼 중복 지급하지 않는다.
- 환생/새 판/판 종료에서 진행 중 아이콘·미도착 표시 금액을 초기화한다. 연출은 비스케일 시간 기준이므로 메뉴에서도 마무리된다.
- Canvas 아래 Collection Feedback/Harvest Icon 0~95는 씬에 저장된다. 런타임 UI 생성 없음. 모든 Image의 Raycast Target은 false. HUD 위/모달 아래에서 재생한다.
- WorldDisplay의 실제 RectTransform에서 시작 좌표를 얻고 실제 GoldTarget의 중심으로 이동한다. UI 배율/해상도 변경에도 현재 목표 좌표를 다시 계산한다.
- Inspector: Canvas의 PrototypeCanvas → 채집 골드 연출. CollectionBurstSeconds, CollectionFlightSeconds, CollectionSpread, CollectionArc, GoldCountSpeed 및 Sprite/슬롯 참조를 조정한다. 설치 메뉴를 다시 실행해도 설치된 연출 설정을 덮어쓰지 않는다.

## 직접 확인 절차와 기대 결과
1. 최신 Windows 실행 파일에서 나무/바위에 커서를 둔다. 해당 재료 아이콘이 채집 위치에서 튀어나와 왼쪽 골드 아이콘으로 모이고, 도착에 맞춰 숫자가 올라가야 한다. 잔량/총량과 단위 골드 가치만 표시되어야 한다.
2. 골드 20 이상에서 집을 배치한다. 골드 20이 차감되어야 하며 목재·석재 요구나 교역소 버튼이 없어야 한다. 공사 중 취소하면 미진행 비율만 환급된다.
3. 여러 자원을 동시에 채집하고 UI 배율을 바꾼다. 아이콘 목적지가 골드 아이콘 중심을 유지하고 연출 중에도 건설/메뉴 조작을 막지 않아야 한다.
4. 상인의 저울 획득 전후 같은 채집 기여량을 비교한다. 단계당 골드 +25%가 적용되고 소수는 다음 지급으로 이월되어야 한다.
5. 밤 결산의 기존 유물 3택1과 다음 날 흐름을 확인한다. 환생/새 판에는 이전 아이콘이나 이전 골드 표시가 남지 않아야 한다.

이번 완료 범위는 기능 구현·씬 저장·빌드다. M5 전체 한 판의 경제 밸런스와 실제 연출 감각은 플레이 확인이 필요하다.

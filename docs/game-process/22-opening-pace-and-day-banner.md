## 조정 가설
골드 통일 후 초반 복수 자원 동시 채집이 빠른 성장으로 이어진다는 사용자 피드백이다. 집값 20골드를 유지하면서 범위와 단위 기여를 낮춘다. 같은 기본 자원 1개를 계속 채집하면 기본 주기 2초당 골드 6 → 2, 집값까지 연속 수입 기준 약 6.7 → 20초. 실제 횟수로는 기존 4회/약 8초 → 10회/약 20초이며 첫 기여 시점에 따라 달라진다. 복수 대상·성장·치명타·처치 보상은 별도다.

반경은 약 54% 감소, 순수 원 면적은 약 78% 감소한다. 실제 대상 판정은 오브젝트 표면 거리이므로 면적 비율이 곧 채집 대상 수 감소율은 아니다. 주민 수의 범위/효율 성장률과 집값은 유지한다.

하루 시간은 약 42% 단축. 밤의 기존 그룹 출현 시점(초반 0/12/24초, 이후 0/10/20/30초)은 35초 안에 들어가므로 유지한다. 밤 시간이 끝나도 적이 남으면 전멸까지 결산을 기다린다. 기여량과 준비 시간이 함께 줄어 첫날 방어 난이도는 실제 확인 대상이다.


## 구현 결과
- Balance 기본값, PrototypeSettings 기본값, 실제 Resources/AfterlifePrototype/Settings.asset을 같은 수치로 변경.
- ContributionPower 설정을 추가하고 기존 하드코딩 3배 대신 사용한다. 채집·건설·이전·수리·상자와 커서 공격의 기본 기여가 모두 1/3. 기본 기여 주기 2초, 주민별 효율/반경 성장, 일반 강화 가격, 집값은 유지했다. 커서 시야 반경도 유지했다.
- 빌드 도구 CreateAssets가 매번 CursorRadius를 1.4로 덮어쓰던 문제 제거. 기존 설정 에셋은 Inspector 값을 보존하고 새 에셋만 클래스 기본값을 사용한다.
- DaySequence는 새 시도와 다음 날 전환 때 증가한다. 뷰는 실제 낮 시작 시 새 번호를 확인하여 한 번 표시한다. 새 판은 1일차, 결산/유물 선택 완료 뒤 다음 날, 환생 강화 완료 뒤 1일차가 표시된다. 환생 강화창에서는 먼저 표시되지 않는다.
- Canvas/Day Start Banner: 화면 중앙 가로 전체 폭, 높이 88(UI 기준), 검정 불투명도 65%, 가운데 N일차 글자 34. 1초 후 숨김. 이미지/텍스트 Raycast Target false, HUD 위/모달 아래. 게임은 멈추지 않는다.
- 배너는 씬에 저장하고 누락 시에만 Install Scene UI에서 추가한다. Inspector에서 위치/색/폰트 편집 가능. PrototypeCanvas.DayBannerSeconds 기본값 1, 실제 비스케일 시간 기준. 메뉴로 일시정지해도 표시 시간 자체는 흐른다.

## 직접 확인 절차
1. 최신 Windows 빌드로 새 판을 시작한다. 중앙 검은 가로 배너에 1일차가 나오고 약 1초 뒤 사라져야 한다. 표시 중에도 월드 입력은 통과한다.
2. 나무 하나만 범위에 넣는다. 기본 주민 1명, 유물/환생 강화 없음에서 2초마다 채집 2, 골드 2가 지급된다. 바위는 채집 1, 골드 2. 집은 여전히 골드 20이다.
3. 낮 약 35초, 황혼 5초 후 밤이 시작된다. 밤은 최소 35초이며 남은 적이 있으면 추가 전투한다. 결산/유물 선택 후 다음 낮 시작을 눌렀을 때 2일차 배너가 한 번 표시되어야 한다.
4. 환생 강화창에 머무는 동안 배너가 먼저 재생되지 않고 첫날부터 재건을 누르면 1일차가 표시되는지 확인한다. 승리/패배 뒤 새 판도 같다.
5. 첫날 방어 준비가 가능한지와 다음 2~3일 성장 속도를 확인한다. 준비 시간과 커서 공격도 감소해 기존보다 어려워질 수 있으므로 최종 난이도 확정 수치로 보지 않는다.

M5 이번 기능 구현·빌드 범위 완료. 전체 경제/방어 난이도 검증과 출시 준비는 미완료.

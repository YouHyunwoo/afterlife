# 23 타격·지형·적 이동·메뉴·UI 편집

현재: M5 플레이 검증·수정 / 구현·씬 저장·Windows 빌드 완료.

## 작업 목록
- [x] 도끼의 실제 날 위치를 기준으로 타격 방향/접촉점 보정
- [x] 적 근접/원거리 공격의 실제 피해량 텍스트 표시
- [x] 유닛 점유를 고려한 경로 비용과 측면 회피 개선
- [x] 지형 반복 사인파/격자 점을 불규칙한 저대비 무늬로 변경
- [x] 메뉴 다시 도전하기 버튼, 새 판 초기화 연결
- [x] 편집할 씬/설정/폰트/셰이더 안내
- [x] 컴파일·씬 저장·Windows 빌드·진행 문서 갱신

기존 지형은 PixelSurface 커스텀 URP 셰이더의 타일 색 보간·사인파 얼룩·격자 점과 별도 풀/자갈 장식 메시의 조합이다. 길찾기는 정적 지형/건물만 고려하고 유닛 충돌은 이동 직전에 막아, 다른 유닛 뒤에서 같은 경로를 재선택하는 문제가 있다. 이번 수정은 혼잡 비용과 전방 외 방향 회피를 추가하며 벽/물/유닛 충돌은 유지한다.


## 수정 내용
- 도끼: FBX는 날/손잡이가 하나의 메시로 병합된다. 전방 정렬 후 MeshFilter.bounds의 8개 모서리를 도구 피벗 좌표로 변환하고, 손잡이에서 더 멀리 돌출된 X축 쪽을 날 방향으로 판정한다. 그 부호로 가로 휘두르기 방향을 결정하고 메시 폭/높이에서 근사한 날 접촉점이 나무 표면에 닿도록 손잡이 위치를 역산한다. 프리미티브 모델도 같은 경계 계산을 사용한다. FBX를 새로 내보낼 필요가 없다.
- 적 피해: EnemyHit에서 유효 대상/양수 피해를 확인하고 남은 체력으로 제한한 실효 피해량을 빨간 텍스트로 표시한다. 근접 공격 적중과 적 투사체 명중에서 호출하며 빗나간/막힌 투사체에는 표시하지 않는다. PrototypeCanvas.EnemyDamageColor로 색 편집 가능.
- 이동: 경로 탐색 시 다른 살아 있는 유닛의 위치를 스냅샷으로 읽어 점유 반경 0.68, 혼잡 반경 1.25에 비용을 준다. 직선도 혼잡을 검사해 필요하면 A*로 우회한다. 동적 점유를 완전 금지하지 않아 외길에서 경로 자체가 사라지지 않게 한다. 이동 직전 실제 유닛/정적 장애물 충돌은 유지한다.
- 회피: 전방 ±80도만 보던 방식에서 ±149도까지 측면/후방 후보를 확인. 유닛 ID별 선호 방향으로 선택 편향을 분산한다. 목표 방향 진행이 0.4초 이상 부족하면 움직이고 있어도 경로를 재탐색한다. 목표 근처에서는 안전한 실제 목표 좌표로 마지막 구간을 연결한다.
- 지형: 반복 사인파 얼룩과 격자 점을 제거하고 부드러운 해시 노이즈의 큰 군집/중간 얼룩/작은 결을 낮은 대비로 혼합한다. 좌표를 다른 저주파 노이즈로 휘어 반복을 줄인다. 물 타일/충돌 경계/마을 영역 테두리는 유지한다. 장식 식물과 자갈은 군집 밀도와 빈 공간을 두고 위치 흔들림을 늘린다.
- 메뉴: 다시 도전하기 · 새 판 시작 버튼을 게임 종료 위에 추가하는 설치 코드를 제공한다. Reset 후 마을 뷰/기여 효과/골드 흡입을 초기화한다. 기존 결과창의 새 판 시작과 같은 경로다. 판 내부 성장/유물/에테론은 초기화하고 영구 해금과 UI 설정은 유지한다.

## 에디터에서 수정할 대상
Unity 프로젝트: `impls/unity/Afterlife`.

| 편집 대상 | 프로젝트 안의 위치 |
|---|---|
| 실제 게임 UI 씬 | Assets/_AfterlifePrototype/Scenes/Afterlife_PixelPrototype.unity |
| 자원/골드/일차/건설 버튼 | 씬 Canvas/HUD |
| 게임 메뉴/연구/결산 등 | 씬 Canvas/ModalLayer/Menu, Research, Settlement 등 |
| 시작 N일차 배너 | 씬 Canvas/Day Start Banner |
| 채집 아이콘 풀 | 씬 Canvas/Collection Feedback |
| 툴팁 | 씬 Canvas/Tooltip |
| 폰트 | Assets/_AfterlifePrototype/Resources/Fonts/Mona12TextKR.ttf |
| 프레임/아이콘 Sprite | Assets/_AfterlifePrototype/Resources/UI/SceneSprites |
| 게임 밸런스 | Assets/_AfterlifePrototype/Resources/AfterlifePrototype/Settings.asset |
| 지형/월드 셰이더 | Assets/_AfterlifePrototype/Shaders/PixelSurface.shader |
| 씬 UI 생성/추가 도구 | Assets/_AfterlifePrototype/Editor/PrototypeUiInstaller.cs |

1. 씬을 열고 Canvas 아래 대상을 선택한다. RectTransform은 위치/크기, Text는 글꼴/크기/정렬, Image는 배경/색/Sprite다. TMP가 아닌 Unity UI Text/Font를 사용한다.
2. 비활성 창은 ModalLayer와 해당 창을 활성화해 편집하고 다시 원래 비활성 상태로 저장한다. 본문은 Body/Viewport/Content이며 세로 스크롤은 ScrollRect와 Content 높이로 조절한다.
3. PrototypeCanvas에서 기여 숫자 색/크기, 적 피해 색, 채집 연출 속도/폭, 일차 배너 시간을 편집한다.
4. Bindings의 ID와 연결 참조는 유지한다. GameObject 이름은 변경 가능하다. 골드 수치/일차/유물 효과처럼 동적 Text 내용은 런타임 데이터가 갱신한다.
5. UI는 씬 저장 구조다. 기본 편집에는 C# 생성기 수정이 필요 없다. 누락된 이번 다시 도전하기 버튼은 Tools > Afterlife > Install Scene UI 메뉴로 추가한다. 이미 설치된 UI는 재생성하지 않는다.

## 직접 확인할 항목
- 나무 채집 전조부터 타격 순간까지 도끼 날이 선행하고 줄기에 닿는지 확인.
- 적 근접/원거리 공격이 아군 병력/건물에 맞으면 빨간 실효 피해 숫자가 나오는지 확인. 막힌 투사체는 숫자가 없어야 한다.
- 옆길이 있는 길목에 여러 적이 모였을 때 퍼져 우회하는지 확인. 외길에서는 여전히 앞 유닛을 기다릴 수 있으며 벽/물을 통과하면 안 된다.
- 낮의 잔디/흙/숲 경계에서 반복 줄무늬와 점이 줄었는지, 장식 군집이 자연스러운지 확인.
- 메뉴 아래쪽의 다시 도전하기로 집 하나/골드 0/1일차부터 시작하며 이전 아이콘/병력/유물이 남지 않는지 확인.

현재 구현의 실제 타격 화면·적 군집 성능·지형 미감은 플레이 관찰 전이다. 전체 M5와 M6는 미완료다.

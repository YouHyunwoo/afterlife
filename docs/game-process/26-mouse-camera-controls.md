## 검증 및 남은 확인

C# 컴파일 성공: 오류 0, 경고 0. 카메라 잠금 런타임 상태와 토글 참조 제거 확인. Unity가 열려 있어 Windows 빌드 및 에디터 플레이 조작은 하지 않았다. 실제 입력과 회전 체감은 아직 미검증이다.

기존 씬의 고정 버튼 제거는 편집 모드에서 일회 보정한다. 현재 플레이 중이면 플레이를 종료하고 스크립트 컴파일을 마친 뒤 적용된다. 수동 실행 메뉴는 `Tools > Afterlife > Apply Mouse Camera Controls`. 사용자 씬 편집을 보존하고 자동 저장하지 않는다. 적용 후 씬을 저장해야 한다. 이번 확인에서는 보정 적용 로그를 확인하지 못했으므로 씬 적용/저장 완료로 간주하지 않는다.

플레이 확인: 빈 지면 클릭 시 선택 해제, 오른쪽 누름/해제 시 가장자리 이동/즉시 정지, 가운데 수평 드래그 시 화면 중앙 지면 축 회전. 회전 후 화면 방향으로 이동하는지, UI와 모달에서 카메라 입력이 차단되는지 확인한다. 건설 배치 중 왼쪽 클릭은 배치이며 ESC로 취소한다.

회전 감도는 PrototypeInteraction의 `_orbitDegreesPerPixel` 직렬화 필드로 조절한다(기본 0.2도/픽셀). 회전 후 새 생/재시작 시 초기 카메라 위치와 방향을 복원한다. 이전 카메라 잠금 관련 문서/QA 결과는 과거 동작 기록이다.

## 변경 및 검증

이전: 빈 곳 클릭은 선택 해제만 수행. 변경: 선택 해제 후 클릭한 지점 위에 기존 건물 8종을 가로 목록으로 표시. 건물 선택 시 원래 클릭한 타일에 바로 공사를 시작한다. 물/마을 영역/겹침/골드/해금 검사는 기존 PlacementError와 Place를 사용한다. 배치 실패 시 알림을 표시하고 목록을 유지한다.

씬의 기존 BuildPanel을 재사용하며 런타임 UI 오브젝트를 만들지 않는다. 메뉴를 닫으면 사용자가 편집한 기존 RectTransform 배치를 복원한다. 좌측 건설 버튼은 기존 세로 메뉴/배치 방식 유지. 화면 가장자리 보정, 가로 공간 부족 시 휠 또는 드래그 스크롤 지원. ESC, 다른 월드 대상 클릭, 카메라 조작, 모달/정산/종료 시 닫는다.

C# 컴파일 오류·경고 0. Windows 빌드 및 Unity 에디터 테스트는 하지 않았다.

수동 확인: Unity 컴파일 완료 후 플레이 → 빈 타일 클릭 → 마우스 위 가로 목록 확인 → 집 선택 → 최초 클릭 타일에 공사 시작 확인. 물/영역 밖/골드 부족에서는 공사와 비용 차감 없이 알림 확인. 화면 네 모서리와 UI 배율 변경에서 잘림/스크롤 확인. ESC/오른쪽 누름으로 닫힌 뒤 왼쪽 건설 버튼의 원래 레이아웃 복원 확인. 실제 화면과 입력 체감은 아직 미검증.

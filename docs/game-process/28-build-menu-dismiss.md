# 28 건설 메뉴 크기·닫기 개선

> 최신 규칙: 초반의 모든 커서 작업은 대상 직접 클릭 1회로 실행하며, 자동화 강화 후에만 호버 주기 작업이 열린다. 아래의 시작부터 자동 기여 설명/과거 QA는 변경 전 기록이다. [최신 규칙·구현·검증](46-click-work-and-automation.md).


M5 · 조작 개선

- [x] 배경 클릭을 닫기 전용으로 소비
- [x] 작은 세로 프레임과 세로 목록·스크롤 통일
- [x] 컴파일 확인 및 문서 갱신


이전에는 배경 클릭이 다른 타일의 메뉴를 다시 열었으며 가로 목록에 기존 세로 프레임 크기가 남아 있었다. 이제 메뉴가 열려 있는 동안 월드 입력/커서 기여를 차단하고, 바깥 클릭은 닫기에만 사용한다. 같은 클릭으로 다른 타일 메뉴를 열거나 건물을 선택하지 않는다.

팝업은 UI 기준 300×300의 작은 세로형으로 통일했다. 프레임과 배경 크기도 함께 조정하고, 기존 251×74 건물 행을 세로로 나열해 약 3개씩 보며 세로 스크롤한다. 화면 높이가 부족하면 높이를 제한한다. 닫으면 기존 사이드 메뉴 레이아웃을 복원한다. 새 UI 오브젝트/씬 재설치는 필요 없다.

검증: C# 컴파일 오류·경고 0. Unity 플레이 테스트 및 Windows 빌드는 하지 않았다.
수동 확인: 빈 타일 클릭 → 작은 세로 메뉴·프레임 확인 → 휠로 마지막 건물까지 확인 → 배경 클릭 시 닫히고 새 메뉴/선택이 생기지 않는지 확인 → 다시 열어 건물 선택 시 원래 타일에 건설되는지 확인. 좌측 건설 메뉴 복원도 확인한다.

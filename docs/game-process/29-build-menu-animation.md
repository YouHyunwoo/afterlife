# 29 타일 선택·건설 메뉴 연출

M5 · 조작 연출

- [x] 타일 중앙의 아래 방향 회전 사각뿔
- [x] 사각뿔 상승/페이드 후 메뉴 상승/페이드 인
- [x] 취소 시 현재 진행 지점부터 역재생
- [x] 입력 차단·리셋·리소스 정리 및 컴파일 확인

메뉴 열기의 “페이드 아웃”은 메뉴가 나타나는 흐름에 맞춰 페이드 인으로 해석했다.


## 구현

- 이전: 작은 세로 메뉴가 즉시 나타나고 즉시 닫힘.
- 변경: 최초 클릭을 반올림한 타일 중앙에 아래 방향 황금색 사각뿔을 표시한다. 0.22초 동안 위로 이동하며 알파가 증가하고, 이어 0.20초 동안 메뉴가 18 UI 단위 상승하며 나타난다. 완료 후 사각뿔은 초당 100도로 계속 회전한다.
- 하나의 연출 시간값을 사용한다. 배경 클릭/ESC로 취소하면 현재 시간값부터 감소시켜 메뉴 → 사각뿔 순으로 역재생한다. 회전 방향도 반대로 바뀐다. 도중 취소를 위해 처음이나 끝으로 점프하지 않는다.
- 보이지 않는 메뉴 영역도 배경으로 취급해 사각뿔 등장 중 즉시 취소 가능. 닫는 동안 월드 입력을 계속 차단하며 연속 클릭으로 건설하거나 메뉴를 재생성하지 않는다. 메뉴 연출 완료 전 및 닫는 중 건설 버튼은 비활성화한다.
- 타일 표시자에는 콜라이더가 없다. 메시를 재사용하고 종료 시 해제한다. 메뉴는 기존 씬 uGUI를 재사용하고 CanvasGroup으로 알파/입력을 제어한다. 닫힌 뒤 기존 사이드 메뉴의 레이아웃과 CanvasGroup 상태를 복원한다.
- 모달/정산/게임 종료/리셋은 즉시 정리해 표시자가 남지 않게 한다. 작은 300×300 세로 목록과 스크롤 유지. 메뉴 위치는 타일 중앙의 월드 투영 좌표를 기준으로 화면 경계를 보정한다.

## 검증과 남은 확인

C# 컴파일 오류·경고 0. Unity 에디터 플레이 테스트 및 Windows 빌드 미실시.

사용자 확인 순서: 빈 타일 클릭 → 사각뿔이 해당 타일 정중앙에서 상승·회전·페이드 인 → 직후 메뉴가 상승·페이드 인. 사각뿔 등장 중, 메뉴 등장 중, 완전히 열린 뒤 각각 배경 클릭하여 현재 지점부터 부드럽게 역재생되는지 확인한다. 닫는 중 연속 클릭에 월드 선택/건설이 발생하지 않아야 한다. 다시 열어 건물 선택과 세로 스크롤이 동작하는지, 화면 모서리에서 잘리지 않는지도 확인한다. 실제 연출 체감은 아직 미검증이다.

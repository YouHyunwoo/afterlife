# 30 빈 타일 호버 표시

M5 · 조작 피드백

- [x] 오브젝트가 아닌 타일에 사각 테두리 표시
- [x] UI/모달/카메라 조작/드래그 시 숨김, 기존 배치 표시와 중복 방지
- [x] C# 컴파일 및 진행 문서 갱신


이전에는 오브젝트에만 호버 테두리가 있었다. 이제 오브젝트를 가리키지 않을 때 마우스 아래 타일 중심에 0.98×0.98 사각 테두리를 표시한다. 기존 금색 호버 LineRenderer를 재사용해 오브젝트 호버와 스타일을 맞췄다. 물이나 건설 불가 타일도 가리킨 타일을 표시한다. 건설 가능 여부를 뜻하는 표시는 아니다.

UI/모달/건설 메뉴/카메라 조작/드래그/맵 밖에서는 숨긴다. 건설 배치 모드는 기존 유효성 색상 미리보기를 유지하며 중복 테두리를 추가하지 않는다.

검증: C# 컴파일 오류·경고 0. Unity 플레이 테스트와 Windows 빌드 미실시.
사용자 확인: 빈 지면 위로 마우스 이동 → 타일별 사각 테두리 이동 확인. 나무/건물 위로 이동 → 기존 오브젝트 호버로 전환 확인. UI 위/건설 메뉴/가운데 드래그에서는 빈 타일 표시가 사라지는지 확인. 실제 화면 표시는 미검증.

# 31 건설 가능한 타일의 메뉴 표시

> 최신 규칙: 초반의 모든 커서 작업은 대상 직접 클릭 1회로 실행하며, 자동화 강화 후에만 호버 주기 작업이 열린다. 아래의 시작부터 자동 기여 설명/과거 QA는 변경 전 기록이다. [최신 규칙·구현·검증](46-click-work-and-automation.md).

이전에는 빈 타일이면 물/영역 밖에서도 메뉴를 열었다. 이제 마을 영역 안의 물이 아닌 타일이며 다른 살아 있는 오브젝트와 겹치지 않을 때만 메뉴와 사각뿔 연출을 시작한다. VillageModel.BuildTileError를 추출해 실제 PlacementError와 같은 위치 조건을 공유한다. 현 목록은 모두 1×1 건물이며 기존 다중 타일 배치 검증도 유지한다.

골드와 개별 건물 해금은 타일 조건과 분리하여 기존 선택/건설 시 검사를 유지한다. 메뉴가 열린 후 이동 유닛이 진입하는 등 상황이 바뀌어도 Place가 다시 검증하므로 불법 배치하지 않는다. 불가 타일 클릭도 기존 선택 해제는 유지한다. 호버 사각 테두리는 가리킨 타일 표시이므로 유지한다.

검증: C# 컴파일 오류·경고 0. Unity 플레이 테스트와 Windows 빌드 미실시.
수동 확인: 마을 영역 내 빈 육지 클릭 시 메뉴/사각뿔 표시. 물, 마을 밖, 오브젝트와 겹친 위치는 메뉴/연출 미표시. 골드가 부족해도 유효한 타일에서 메뉴는 열리고 실제 건설 시 비용 검사. 실제 플레이 확인은 남아 있다.

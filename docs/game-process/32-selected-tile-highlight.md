이전에는 메뉴가 열리면 타일 호버 사각 테두리가 숨겨졌다. 이제 메뉴가 열려 있는 동안 저장된 _buildTile을 기준으로 사각 테두리를 유지한다. 마우스 이동/UI 호버에 영향받지 않고 등장·취소 역재생 중에도 유지하며 닫기 완료 때 즉시 해제한다. 회전 사각뿔 연출은 기존대로 유지한다.

C# 컴파일 오류·경고 0. Unity 플레이 테스트/Windows 빌드 미실시. 사용자 확인: 건설 가능 타일 클릭 → 메뉴 위로 마우스를 옮겨도 원래 타일 테두리 유지 → 배경 클릭 후 닫기 연출 완료 시 고정 표시 해제. 이후 일반 타일 호버로 복귀해야 한다.

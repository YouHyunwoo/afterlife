> 최신 규칙: 초반의 모든 커서 작업은 대상 직접 클릭 1회로 실행하며, 자동화 강화 후에만 호버 주기 작업이 열린다. 아래의 시작부터 자동 기여 설명/과거 QA는 변경 전 기록이다. [최신 규칙·구현·검증](46-click-work-and-automation.md).


M5 · 조작 피드백

- [x] 메뉴 표시 중 저장된 선택 타일 테두리 유지
- [x] 닫기 완료 시 표시 해제
- [x] C# 컴파일 확인

이전에는 메뉴가 열리면 타일 호버 사각 테두리가 숨겨졌다. 이제 메뉴가 열려 있는 동안 저장된 _buildTile을 기준으로 사각 테두리를 유지한다. 마우스 이동/UI 호버에 영향받지 않고 등장·취소 역재생 중에도 유지하며 닫기 완료 때 즉시 해제한다. 회전 사각뿔 연출은 기존대로 유지한다.

C# 컴파일 오류·경고 0. Unity 플레이 테스트/Windows 빌드 미실시. 사용자 확인: 건설 가능 타일 클릭 → 메뉴 위로 마우스를 옮겨도 원래 타일 테두리 유지 → 배경 클릭 후 닫기 연출 완료 시 고정 표시 해제. 이후 일반 타일 호버로 복귀해야 한다.

## 후속 요청 · 메뉴 연출 속도

- [x] 사각뿔 0.22→0.13초, 메뉴 0.20→0.12초로 단축
- [x] 컴파일 확인

전체 등장/완전히 열린 상태의 닫기 시간을 0.42초에서 0.25초로 줄였다. 도중 취소는 현재 진행 시간만큼 역재생한다. 컴파일 오류·경고 0. 실제 플레이는 미실시: 빈 타일 클릭/배경 취소 시 더 빠른 등장·닫기와 타일 표시 유지 확인 필요.

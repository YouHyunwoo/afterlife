# 34 건설 메뉴 배경 어둡게 하기

M5 · UI 연출

- [x] 메뉴 연출 진행도에 따라 월드 배경 밝기 변경
- [x] 도중 취소·즉시 닫기 시 원래 색 복원
- [x] 컴파일 확인 및 인계 기록

기존 WorldDisplay RawImage 색을 조절해 월드 배경만 어둡게 한다. UI 메뉴/HUD는 밝기를 유지한다. 전체 연출 0.25초 진행도에 SmoothStep을 적용해 기본 45% 어둡게 하며 닫기 때 같은 진행도를 역으로 따라간다. 도중 취소해도 밝기가 튀지 않는다. 메뉴 열기 전 색/알파를 보존하고 즉시 닫기/리셋/종료 시 복원한다. 추가 UI 오브젝트/카메라/씬 설치 없음. PrototypeView의 Build Background Dim에서 강도 조절 가능. 월드에 렌더링된 사각뿔/타일 테두리도 배경과 함께 어두워지지만 기존 표시 유지.

C# 컴파일 오류·경고 0. Unity 플레이 테스트/Windows 빌드 미실시. 확인 절차: 건설 가능 타일 클릭 → 배경이 서서히 어두워지고 메뉴는 원래 밝기 유지 → 배경 클릭 취소 → 닫히면서 원래 밝기로 복귀. 등장 중 취소, 반복 열기/닫기에서도 밝기가 누적되지 않아야 한다.

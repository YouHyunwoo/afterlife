# 35 인게임 건설 메뉴 통합

M5 · UI 정리

- [x] HUD.Build 생성/입력 제거
- [x] 건설 메뉴 표시·주문은 타일 메뉴에서만 허용
- [x] 기존 씬 버튼/바인딩/가드 제거 도구
- [x] 컴파일 및 인계 기록

이전: 왼쪽 건설 버튼과 타일 메뉴 병행. 변경: HUD.Build 생성/클릭/활성화 경로 제거, 메뉴 표시 조건을 _tileBuildMenu로 통일. 타일 메뉴 밖의 건물 버튼 클릭으로 배치 모드에 진입하는 경로 제거. 기존 BuildPanel은 타일 메뉴에 필요하므로 유지한다.

기존 씬은 PrototypeWorldBuildOnlyMigration으로 HUD.Build 오브젝트와 관련 바인딩/카메라 가드를 제거한다. 편집 모드 리로드 또는 플레이 종료 후 적용, Undo 지원/자동 저장 없음. 수동 메뉴 Tools > Afterlife > Remove HUD Build Button. 씬 보정 전에도 런타임에서 기존 버튼을 숨긴다. 다른 UI 위치는 유지한다.

C# 오류·경고 0. 씬 보정 적용/저장과 실제 플레이는 미확인. Unity 컴파일 후 편집 모드에서 버튼 제거 확인 및 씬 저장. 플레이 시 HUD 건설 버튼이 없고 건설 가능한 타일 클릭으로 메뉴/연출/건설이 동작하는지 확인한다. Windows 빌드 미실시.

## 선택 적용

| 용도 | 적용 ID | 재생 시점 |
|---|---|---|
| 나무 채집 | 01B + 01C | 실제 채집 기여 때 각각 50% 확률로 하나 재생. 동시 중첩 합성이 아님 |
| 자원 소진 | 03A | 나무/돌 잔량이 0이 된 순간 |
| 골드 | 04A | 채집 아이콘이 HUD에 도착, 처치 골드, 상자 골드, 새벽 정산 |
| 건물 배치/이전 시작 | 05A | 성공한 배치/이전 |
| 공사/수리 지원 | 06B | 커서의 실제 공사·이전·수리 기여 |
| 완공/병력 생산 완료 | 07A | 자동/수동 공사 완료, 이전 완료, 병력 생성 성공 |
| 커서/근접 적중 | 09C | 일반 커서 공격, 아군/적 근접 공격 적중 |
| 마법 발사 | 12B | 마법사/주술사 발사, 마법탑 공격 시작 |
| 적 처치 | 14A | 적의 체력이 0 이하가 된 순간 |
| 치명타 | 15A | 커서 치명타 기여, 아군 근접 치명타 |
| 건물 피격/파괴 | 16B | 피격 시 낮은 음량, 파괴 시 높은 음량 |
| 상자 개봉 | 17B | 개봉 작업 완료 때 한 번 |
| 유물/유적 | 18A | 상자 유물, 일일 유물 선택/강화, 유적·제단 첫 편입 |
| 선택/명령 | 19A | 병력 선택/이동 명령, 모집/기억 구매 UI |
| 취소/닫기 | 20A | 공사/모집 취소, 메뉴·건설 메뉴 닫기 |
| 열기/탭 | 21C | 관리창/설정/건설 메뉴 열기, 연구·설정 탭, 보상 선택지 열기 |
| 행동 불가 | 22A | 배치/이전/명령 실패, 비활성 버튼 누름 |
| 황혼/밤 | 23C | 황혼 및 밤 시작 |
| 하루 시작/완료 | 24C | 최초 시작, 새 판, 다음 날, 웨이브 결산 |
| 결과 | 25B | 승리·패배 공통 |
| 환생 | 26C | 환생 확정, 환생 상점에서 재출발 |

보류: **02 돌 채집 / 08 연구·타워 강화 / 10 무기 휘두르기 / 11 화살 / 13 마법 명중·발화**. 해당 동작 전용음은 추가하지 않았다. 다른 선택 항목에 해당하는 골드·치명타·처치·자원 소진음은 별도로 발생한다.

나무 두 음원의 무작위 선택은 게임의 전투/보상 난수와 별도 난수를 사용한다. 임의 피치/속도 변경은 없다. 승패 각각의 배정은 JSON에 없으므로 25B를 공통 결과음으로 사용한다.

## 구조와 재생 제한

- 모델은 순수 C# `SoundRequested` 이벤트만 발행한다. AudioSource/AudioClip은 `PrototypeAudio`에서만 관리한다.
- PrototypeView 초기화 시 오디오를 연결한다. 씬에 활성 AudioListener가 없을 때만 카메라에 하나 추가한다. 별도의 씬 설치나 Tools 메뉴가 필요 없다.
- 선택 당시 청음용 WAV를 그대로 사용한다. 원본 피크를 -6 dBFS 목표로 조절했던 파일이며 별도 추가 편집은 없다.
- 같은 프레임·같은 효과음은 하나로 합친다. 효과별 0.06~0.75초 재생 간격을 적용한다.
- 월드 재생 8채널, 알림/UI 4채널. 월드 효과는 프레임당 최대 4개 시작, 같은 음원군 최대 2개 동시 재생.
- 위치 기반 효과는 화면 밖/안개 속에서 재생하지 않는다. 건물 위험·진행 알림은 화면 밖에서도 들린다. 화면 좌우에 따라 약한 패닝을 적용한다.
- 재시작/환생 때 이전 재생과 대기열을 비운다. 컴포넌트 종료 때 구독과 소스를 정리한다.
- `PrototypeSettings.SoundVolume` 기본 0.7. Settings 에셋 Inspector에서 전체 효과음 음량 조정 가능. 인게임 음량 메뉴는 이번 범위에 포함하지 않았다.

## 파일

- 선택 기록: `res/audio/kenney-review/approved-selections.json` (처음 읽은 사용자 파일에서 선택/메모를 보존한 기록)
- 실행 음원: `impls/unity/Afterlife/Assets/_AfterlifePrototype/Resources/AfterlifePrototype/Audio/`
- 출처·변환 게인·SHA-256: 같은 폴더의 `provenance.json`
- CC0 라이선스: 같은 폴더의 `Licenses/` (7개 사용 팩)
- `.meta`는 직접 생성/수정하지 않았으며 Unity 임포트가 생성한다.

## 변경 전후와 검증

이전: 청음/선택 자료만 존재하고 프로토타입 게임 내 효과음 연결은 없었다.
이후: 선택한 음원과 라이선스를 실행 리소스로 가져오고, 게임 이벤트 및 UI에 연결했다. 기존 밸런스/보상 난수/건설 조건은 유지했다.

`Tools/AfterlifePrototype/Build-Prototype.ps1`의 `dotnet build --no-restore`: **오류 0, 경고 0**. Unity 에디터 테스트, 플레이 모드, Windows 빌드는 실행하지 않았다.

사용자가 Unity에서 임포트가 끝난 뒤 기존 `Afterlife_PixelPrototype` 씬을 재생해 확인할 항목:

1. 나무 채집을 여러 번 반복: 01B/01C가 섞여 나오고, 골드는 아이콘 도착 시 들린다. 돌에는 채광 타격음이 없다.
2. 건설 배치 → 커서 지원 → 완공 → 이전/수리: 작업 성공 시점에 맞춰 소리가 나고 취소를 파괴로 처리하지 않는다.
3. 메뉴/설정/건설창 열기·닫기, 탭 전환, 자금 부족 버튼: 선택한 열기·닫기·거절 소리가 난다. 화면 이동/호버만으로 반복 재생되지 않는다.
4. 병력 생산/선택/명령, 근접/마법 전투: 완료·명령·적중·마법 발사음이 나오고 화살/휘두름/발화 전용음은 없다. 적이 많아도 효과음이 무제한 겹치지 않는다.
5. 상자/유물, 황혼/밤/결산, 환생/재출발, 승패: 선택 파일과 일치하며 재시작 후 이전 효과음이 남지 않는다.
6. Console에 음원 누락/AudioListener 중복 경고가 없는지 확인한다. 실제 밸런스·청감 조정은 이 청음 후 진행한다.

# 44 단계형 튜토리얼과 본 게임 전환

> 현재 조작(2026-09-24): 영력을 써서 위치에 8초 유지되는 필드를 설치한다. 필드는 커서와 무관하게 범위 안 대상을 주기적으로 처리한다. 대상 클릭·빈 타일 Shift+클릭이 설치 입력이며 R8은 작업 간격을 줄인다. 아래의 과거 입력·QA 기록은 당시 버전 설명이다. [현재 구현·검증](47-divine-interaction-fields.md).


- 작성일: 2026-09-19
- 상태: 사용자 채택 기획. 구현·플레이 검증 전.
- 요청 범위: 문서 정리. 게임 코드·씬·에셋 변경 및 빌드 제외.
- 핵심 요약: 작은 마을에서 영력 필드로 채집·건설 지원·방어를 배우고, 주민 성장·정산·유물을 익힌 뒤 마을을 유지하며 본 게임 Day 1로 전환한다. 이후 튜토리얼 없는 새 게임은 집 한 채로 시작한다. 기존 호버 작업 대사는 [47 영력 필드](47-divine-interaction-fields.md) 규칙으로 대체한다.

## 1. 시작 방식과 상태 계승

| 진입 방식 | 시작 상태 |
| --- | --- |
| 튜토리얼 시작 | 9×9 맵, 중앙의 완공된 집 1채, 돈 0원, 영력 100/100, 튜토리얼용 자원 |
| 튜토리얼 완료 직후 같은 판 계속 | 기존 마을·남은 돈·정산 보상·선택한 유물을 유지하고 맵 확장 후 본 게임 Day 1 시작 |
| 이후 튜토리얼 없이 새 게임 시작 | 일반 맵과 일반 시작 규칙 적용, 집은 1채. 이전 튜토리얼의 추가 집·농장·돈·유물은 계승하지 않음 |

튜토리얼은 일반 일차와 별도 단계로 관리한다. 연습용 밤을 본 게임 Day 1 소모나 웨이브 진행으로 계산하지 않는다. 성공 시 보통 집 2채와 농장 1채가 남지만, 전투에서 일부 건물이 파괴됐다면 실제 생존 상태를 유지한다. 모든 집을 잃은 경우에는 아래 재시도 규칙을 적용한다.

튜토리얼 완료 기록과 이번 판의 마을 상태는 구분한다. 완료 기록이 이후 새 게임의 초기 건물을 늘리는 효과를 가져서는 안 된다. 최초 자동 진입 여부, 다시 보기 버튼 위치, 중도 종료 시 단계 저장·재개 방식은 별도 결정 사항이다.

## 2. 공통 진행 규칙

- 학습 순서: 환영 → 채집 → 농장 → 집 → 낮과 밤 → 방어 → 정산 → 유물 → 맵 확장 → 본 게임.
- 각 단계는 실제 획득·착공·완공·처치·보상 선택 이벤트로 완료를 판단한다. 설명을 넘기는 것만으로 행동 목표를 완료하지 않는다.
- 도움말 대화 상자는 모달이며 `PauseGameplay = true`로 설정한다. 대화 중 시간, 채집, 건설, 적 이동·공격·피해 처리를 멈춘다.
- UI 대화 전환과 애니메이션은 정지 중에도 동작한다. 모달이 겹치면 남은 정지 요청을 존중한다.
- 대화를 닫는 입력은 소비하여 뒤쪽 월드의 건설·선택으로 전달하지 않는다.
- 모달을 닫은 뒤에는 작은 현재 목표 문구를 유지한다. 이는 학습 안내이며 잠긴 일반 HUD를 미리 노출하지 않는다.
- 기능과 HUD는 아래 단계에서 순서대로 연다. 숨김과 입력 제한을 함께 적용해 단축키 등으로 단계를 우회하지 못하게 한다.
- 단계 진입·보너스 지급·정산·유물 획득·본 게임 전환은 각각 한 번만 실행한다.

## 3. 작은 맵과 자원 배치

9×9 맵의 중앙에 완공된 집 1채를 배치한다. 나무와 바위 위치는 랜덤으로 정하되 다음 조건을 만족해야 한다.

- 시작 위치에서 자원에 필드를 설치할 수 있다.
- 집 근처에 농장과 추가 집을 지을 유효한 빈 타일이 보장된다.
- 슬라임 출현 지점부터 집까지 이동 경로가 확보된다.
- 배치된 자원을 모두 채집했을 때 총 수입이 정확히 10원이다. 나무·바위별 환산 단위를 고려해 수량을 구성한다.
- 학습 구간에서는 자원 재생성이나 다른 수입원이 10원 목표와 건설 예산을 바꾸지 않는다.

랜덤 배치 검증에 실패하면 조건을 만족하는 배치를 다시 생성한다. 자원별 개수와 슬라임 출현 위치의 세부 값은 구현 시 조정한다.

## 4. 단계별 진행과 대화 초안

대사 문장은 편집 가능한 초안이며, 단계별 기능과 완료 조건이 채택 명세다.

### A. 환영과 영력 필드 안내

1. HUD와 Day Start Banner를 모두 숨긴다. 월드 시간은 고정한다.
2. 커서 이동과 오브젝트 호버 표시만 허용한다. 필드 설치, 빈 타일 표시, 건설은 잠근다. 모달 위에서는 월드 입력·호버를 차단한다.
3. 환영 모달: “환영해요! 이 작은 마을에서 자원을 모으고, 건물을 짓고, 밤을 버티는 방법을 배워봐요.”
4. 다음 대화: “나무를 클릭해 영력 30을 투자해 보세요. 설치한 필드는 8초 동안 그 자리에서 주변 자원을 자동으로 채집해요.”
5. 설명을 닫으면 자원 대상 필드 설치와 영력·돈 HUD를 활성화한다. 호버만으로는 채집되지 않는다.

### B. 10원 채집과 지원금

1. 실제로 첫 돈을 얻으면 일시정지 모달: “잘했어요! 자원을 모아 10원까지 벌어보세요.”
2. 대화를 닫으면 목표 `자원에서 돈 벌기 N/10`을 표시한다.
3. 현재 잔액 대신 튜토리얼 채집 누적 수입으로 목표를 판정한다. 동시 채집·보상 처리에도 총 수입은 10원을 초과하지 않는다.
   10원에 도달한 뒤 남은 필드 펄스가 수입을 더 지급하지 않게 해야 한다. 도움말 모달 동안 필드 수명과 영력 회복도 정지한다.
4. 10원 달성 시 모달: “잘했어요! 건물을 지을 수 있도록 40원을 더 드릴게요.” 지원금은 이 단계에서 정확히 한 번 지급한다.
5. 돈 HUD에서 총 50원을 확인할 수 있다.

### C. 농장 건설

1. 모달: “빈 땅을 클릭하면 건설 메뉴가 열려요. 30원으로 농장을 지어보세요.”
2. 닫으면 빈 타일 표시와 건설 입력을 활성화한다. 기존 오브젝트 표시는 유지한다.
3. 건설 메뉴에는 농장만 표시한다. 유효한 타일에서 농장 1채만 착공할 수 있다.
4. 착공 시 30원을 차감하고 남은 돈은 20원이다. 착공 직후 모달: “건물은 자동으로 완성돼요. 영력을 투자해 공사 위치에 필드를 설치하면 더 빨리 완성할 수 있어요.”
5. 대화를 닫으면 공사를 재개한다. 목표 `농장 완공하기`를 표시하며 자동 공사와 영력 필드 지원을 모두 허용한다. 영력이 부족해도 자동 공사로 진행할 수 있다.
6. 농장 완공 이벤트로 다음 단계에 진입한다.

### D. 주민과 집 건설

1. 농장이 완공되면 주민 HUD를 표시하고 `현재 주민 / 최대 주민`을 강조한다.
2. 모달: “농장은 최대 주민 수를 3명 늘려요. 집은 주민을 1명 늘려요. 주민이 많아지면 영력 필드의 작업과 전투 효율도 좋아져요.”
3. 다음 대화: “남은 20원으로 집을 한 채 더 지어보세요.”
4. 닫으면 건설 메뉴에 집만 표시하고 1채만 착공할 수 있게 한다. 20원을 차감하여 잔액은 0원이 된다.
5. 집은 자동 건설되며 영력 필드로 도울 수 있다. 목표는 `집 완공하기`이다.
6. 집 완공과 현재 주민 증가를 보여준 뒤 다음 단계로 진행한다. 착공만으로 진행하지 않는다.

농장은 현재 주민을 직접 3명 늘리는 건물이 아니다. 건설 단계의 추가 구매·철거 등으로 예산이나 필수 건물이 사라지는 경로는 제한한다.

### E. 낮과 밤

1. 집 완공까지 고정했던 시간을 유지한 채 타임라인 HUD를 표시한다.
2. 모달: “이곳에는 낮과 밤이 있어요. 타임라인에서 남은 시간을 확인할 수 있어요.”
3. 닫은 순간부터 튜토리얼 낮 5초를 진행하고, 짧은 황혼을 거쳐 밤으로 전환한다. 황혼 길이는 시각적 전환을 알아볼 수 있도록 구현 시 조정한다.
4. 밤에 진입하는 순간 모달: “밤에는 적이 쳐들어와요. 낮에 자원을 모아 돈을 벌고 마을을 준비해야 해요.”
5. 설명을 닫으면 슬라임 1마리를 생성한다. 이어 전투 안내 모달을 표시하고, 이 모달 동안 슬라임은 움직이거나 공격하지 않는다.
6. 전투 안내: “슬라임이 지나갈 곳에 영력 필드를 설치해 자동으로 공격해 보세요. 다친 건물에도 필드를 설치해 수리를 도울 수 있어요.”
7. 닫으면 슬라임이 접근하고 플레이어 행동을 기다린다. 필드는 이동하는 슬라임을 따라가지 않으므로 이동 경로와 8초 수명을 고려해 설치해야 한다. 방어 시작 시 영력이 30 미만이면 적 이동을 시작하기 전에 회복을 기다리게 한다. 밤은 시간 경과만으로 종료되지 않는다.

### F. 방어와 재시도

- 슬라임 처치는 필수 학습이다. 수리는 튜토리얼에서 무료이며 돈 0원에서도 가능해야 한다. 현재 프로토타입의 일반 수리에는 골드가 필요하므로 튜토리얼 구현 시 별도 규칙을 연결해야 한다.
- 건물이 손상된 경우 수리 안내를 강조한다. 피해 없이 슬라임을 처치했다면 수리를 강제로 수행시키지 않는다.
- 초보자가 필드를 설치하고 효과를 관찰할 여유가 있도록 슬라임 이동·공격을 조정한다. 세부 수치와 적정 난이도는 플레이 검증 대상으로 둔다.
- 집 한 채가 파괴돼도 다른 집이 남아 있으면 계속 진행한다. 모든 집이 파괴돼야 실패한다. 농장 파괴만으로 실패하지 않는다.
- 마지막 집이 파괴되면 일반 패배 화면으로 빠지기 전에 튜토리얼 실패 모달을 표시한다: “모든 집을 잃으면 게임 오버예요. 마을을 복구해 드릴 테니 다시 지켜보세요.”
- 설명을 닫으면 전투 직전 상태로 복원한다. 집 2채·농장·주민·최대 주민·건물 체력·돈·전리품 상태를 복원하고 기존 슬라임과 이번 시도의 드롭을 제거한다.
- 새 슬라임 1마리로 방어를 다시 시작한다. 재시도로 수입이나 보상이 누적되지 않는다.
- 슬라임이 처치되고 집이 1채 이상 남아 있으면 성공한다. 마지막 집 파괴와 처치가 같은 처리 구간에 발생하면 생존 집 수를 확인하여 실패를 우선한다.
- 성공 모달: “잘했어요! 마을을 지켜냈어요.”

### G. 전리품 정산과 유물

1. 슬라임은 정산 가능한 전리품을 반드시 드롭한다. 획득 처리를 완료한 뒤 정산 학습을 시작한다.
2. 모달: “하루 동안 모은 전리품과 환전 가능한 아이템은 밤이 끝나면 돈으로 바꿀 수 있어요.” 유물까지 환전 대상으로 오해하지 않게 구분한다.
3. 설명을 닫으면 연습용 밤을 종료하고 정산 모달을 연다. 전리품 내역, 환전 금액, 반영된 잔액을 확인하게 한다.
4. 정산은 정확히 한 번 처리한다. 다른 전리품 창 열기나 모달 재개방으로 반복 지급하지 않는다.
5. 이어 “하루를 마치면 유물 보상을 하나 선택할 수 있어요”라고 안내한다.
6. 기존 일일 유물 선택 방식으로 선택지를 제시하고, 선택한 유물 1개를 실제 획득·적용한 뒤 진행한다. 단순 모달 닫기로 보상 선택을 우회하지 않는다.

## 5. HUD와 기능 개방 요약

| 시점 | 일반 HUD | 영력·월드 기능 |
| --- | --- | --- |
| 환영·채집 설명 | 모두 숨김 | 오브젝트 호버만, 필드 설치·건설 잠금 |
| 채집 설명 닫힘 | 돈·영력 | 자원 대상 필드 설치 활성화 |
| 농장 건설 안내 닫힘 | 돈·영력 | 오브젝트·빈 타일 표시, 농장 1채 건설, 필드 공사 지원 |
| 농장 완공 | 돈·영력·주민 | 집 안내 후 집 1채 건설 |
| 낮밤 설명 | 돈·영력·주민·타임라인 | 설명 종료 후 시간 진행 |
| 방어 | 돈·영력·주민·타임라인 | 필드 공격·튜토리얼 무료 수리, 임의 추가 건설 제한 |
| 정산·유물 | 기존 공개 HUD와 해당 모달 | 월드 입력 차단 |
| 본 게임 전환 | 모든 HUD | 확장 연출·배너 종료 후 일반 기능 개방 |

모든 단계에서 도움말 모달이 열리면 월드 입력을 차단하고 게임을 정지한다. 단계별 활성 기능보다 모달 차단이 우선한다.

## 6. 맵 확장 연출과 Day 1

유물 선택 완료 후 모든 HUD를 표시한다. 기존 중앙 마을을 유지하며 외곽을 일반 맵 크기로 확장한다. 새 영역의 지형과 자원 오브젝트는 일반 생성 규칙에 따라 랜덤 배치한다.

1. 월드 입력과 시뮬레이션을 잠근다. 적·채집·공사·하루 타이머가 연출 중 진행되지 않는다.
2. 내부적으로 전체 확장 데이터를 먼저 완성하고 건설·이동 가능한 연결을 확인한다. 기존 중앙 타일과 생존 건물을 덮어쓰지 않는다.
3. 새 타일은 목표 높이 아래, 투명도 0에서 대기한다.
4. 중심에서 가까운 새 타일부터 바깥쪽으로 순차적으로 목표 높이까지 상승하며 페이드 인한다. 기존 타일을 재생성하거나 다시 숨기지 않는다.
5. 모든 지형 표시가 끝나면 새 오브젝트를 순차적으로 시각 생성한다. 각 오브젝트는 스케일 0에서 원래 스케일의 1배까지 트위닝한다.
6. 타일끼리, 오브젝트끼리는 짧은 시작 간격으로 겹쳐 재생한다. 하나의 애니메이션 완료를 기다린 뒤 다음 것을 시작하는 직렬 방식으로 전체 대기 시간이 과도하게 늘어나지 않게 한다.
7. 모든 오브젝트 표시가 끝나면 Day Start Banner로 Day 1을 표시한다.
8. 배너 종료 후 일반 게임 입력·기능·하루 타이머·웨이브 진행을 시작한다. 튜토리얼용 가격 제한·건설 목록 필터·수입 제한·시간 및 적 생성 제어를 해제한다.

튜토리얼의 5초 낮과 연습 슬라임은 일반 낮 길이·일차·웨이브 설정을 덮어쓰지 않는다. 본 게임 전환 보상과 유물 효과는 재적용하지 않는다.

## 7. 구현 시 확인할 항목

아래 항목은 검증 계획이며 아직 실행하지 않았다.

- 여러 랜덤 배치에서 채집 접근성, 필수 건설 공간, 슬라임 경로가 확보된다.
- 환영 때 HUD·일차 배너·필드 설치가 없고, 설명을 닫은 뒤에만 해당 기능이 열린다.
- 첫 수입 안내는 한 번만 나오고 수입 10원 + 지원금 40원 = 50원, 농장·집 건설 후 0원이 된다.
- 한 필드의 여러 대상 채집, 연속 설치 시도, 모달 재개방에도 초과 수입·중복 건설·중복 보상이 없다.
- 필드 설치에만 영력 30을 소비하고, 부족·중복 거부에서는 소비하지 않는다. 모달 중 필드 수명·영력 회복·작업이 멈춘다.
- 자동 건설과 필드 공사 지원이 모두 가능하고 모달 중에는 멈춘다.
- 주민 HUD가 농장 완공 후 나타나고 현재 주민과 최대 주민 증가를 구분한다.
- 낮밤 설명 종료 후 정확히 낮 5초가 진행되고 방어 대기 중 밤이 자동 종료되지 않는다.
- 돈 0원에서 건물 수리가 가능하다.
- 집 한 채 생존은 계속 진행, 모든 집 파괴는 복원 재시도이다. 반복 실패로 드롭·돈·주민 상태가 누적되거나 손실되지 않는다.
- 전리품 획득 → 정산 1회 → 유물 1회 획득 순서를 지킨다.
- 맵 확장 중 중앙 마을을 유지하고 타일 → 오브젝트 → 배너 → 시뮬레이션 순서를 지킨다.
- 같은 판 본 게임에서는 튜토리얼 성과가 유지되며, 이후 튜토리얼 없는 새 게임에서는 집 1채와 일반 시작 상태로 초기화된다.

## 8. 남은 조정 항목

황혼 길이, 슬라임 체력·이동·공격 수치, 연출 간격·높이·시간, 대화의 최종 문구는 구현 및 플레이 확인으로 조정한다. 튜토리얼 진입 UI와 중도 저장·재개 정책은 별도 확정한다. 이 문서는 구현 완료나 사용성 검증의 증거가 아니다.

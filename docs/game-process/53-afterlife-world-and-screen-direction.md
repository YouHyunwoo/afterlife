# 53 사후세계 설정과 타이틀·로비 연출 방향

> 최신 설정·구현: [56 인트로](56-threshold-intro-and-camera.md). 신의 대리자가 무작위로 영웅 시험 후보를 선발한다. 기존 출생 시 운명 설정과 연결해 출생 시 후보 선발로 구성한다. 로비는 대리자의 설명 후 시험으로 자동 진입하는 스킵 가능한 인트로로 대체했다.

> 최신 수정: [55 웅덩이·현실의 창](55-threshold-surface-refinement.md). 내부 균열선 제거, 외곽 잉크 번짐과 Day01 After, 0.95초 왕복 전환, 현장 유지 결과 화면을 적용한다. 아래 초기 구현 기록보다 55를 우선한다.

- 작성일: 2026-09-26
- 핵심 요약: 몸 없는 영웅 후보가 사후세계에서 영력으로 마을을 재건·방어하는 시험을 치른다. 어두운 사후세계와 선명한 UI, 물속에서 깨어나는 듯한 전환을 화면 공통 언어로 삼는다.
- 상태: 세계관과 사용자가 지정한 연출 방향은 채택. 최초 제안 이력은 아래 보존하며, 후속 확정과 독립 구현은 [54 화면 흐름 테스트 씬](54-threshold-screen-lab.md)을 우선한다. 시각·플레이 경험은 미검증.
- 최초 범위: 조사와 문서화. 후속 사용자 요청으로 별도 테스트 씬 구현이 승인되어 54 문서에 기록했다. 기존 프로토타입에는 아직 적용하지 않았다.

## 1. 세계관 원본 · 사용자 확정

원래 세계는 마물이 존재하는 중세 판타지 세계다. 아이가 태어날 때 영웅의 운명이 정해진다. 영웅이 될 운명을 가진 아이는 성인이 될 때 잠에 들고 사후세계에서 깨어나, 영웅이 될 자격을 증명하는 시험을 받는다. 주인공은 플레이어 자신이며 사후세계에서는 몸체가 없고 영력이 주어진다. 사후세계에 왔다는 이유로 주인공이 이미 사망했다고 해석하지 않는다.

시험의 목표는 원래 세계의 특정 지역에 있는 마을을 마물로부터 되살리는 것이다. 주인공은 영력을 사용하여 마을 건설을 돕고, 밤마다 침공하는 마물을 처치해 마을이 일정 기간 생존하도록 만든다. 시험을 통과하면 원래 세계로 돌아간다. 이후 영웅으로서 마물을 물리치고 마왕인 드래곤을 처치하는 이야기로 이어진다.

현재 게임에서 다룰 플레이는 사후세계의 시험, 마을 재건과 생존 지원, 원래 세계로의 귀환까지다. 귀환 후 드래곤 토벌 서사는 배경상 후속 이야기이며 이번 요청으로 전투 콘텐츠나 개발 범위에 추가하지 않는다. 시험 기간의 구체 수치는 이번 설정으로 확정하지 않는다.

### 설정상 구분과 미정 사항

- 사후세계 로비 → 시험 대상 지역으로 진입하는 것과 시험 통과 후 원래 몸·삶으로 귀환하는 것은 서로 다르다. 시험 중에도 플레이어는 몸 없는 영력의 주체다.
- 시험 대상 마을은 실제 원래 세계의 마을이다(2026-09-26 후속 사용자 확정). 사후세계에 재현된 가상 마을이 아니다. 주인공은 영력으로 실제 마을에 개입하며, 시험 진입과 본래 몸으로의 귀환은 구별한다.
- 기존 같은 판 안의 시스템 '환생'은 시험 통과 후 '현실 귀환'과 동일하지 않다. 명칭·서사 관계, 시험 실패의 대가, 재도전의 세계관상 이유는 미정이다. 기존 초기화·강화 유지 규칙을 이번 문서로 바꾸지 않는다.
- 시험의 주관자, 신의 정체, 영웅 후보를 정하는 존재·원리, 마을 주민이 주인공을 인식하는지는 미정이다.

## 2. 화면 방향 · 사용자 지정

- 타이틀 배경: 칠흑 같은 공간의 바닥에 웅덩이와 드문 얇은 동심원이 있다. 강한 빛의 흔적만 보여 윤곽과 실루엣을 유추한다.
- UI: 어두운 배경에 대비되어 읽기 쉬움. Hollow Knight에서는 가독성의 원리만 참고하며 장식 문양·로고·프레임 스타일은 모방하지 않는다.
- 게임 시작 후 사후세계가 로비가 된다. 로비에서 시험에 진입한다.
- 시험 진입: 어둠이 화면 중앙에서 걷혀 가장자리로 물러나고, 물속 같은 소리와 함께 흐릿했던 화면이 선명해진다.
- 모달: 화면 가장자리에 어둠이 남아 천천히 움직인다. 전체 화면 전환이 가장자리에서 멈춘 듯한 인상이다.
- 새 게임을 선택하면 메뉴 UI가 페이드 아웃되고 같은 공간에서 카메라 이동으로 로비까지 자연스럽게 이어진다.
- 로비 정면의 균열에는 실제 세계의 마을이 물처럼 일렁이며 보인다. 이번 테스트는 깨진 유리 같은 균열로 구현한다. 장기적으로 덧댄 듯한 외곽 표현을 조사·검토한다.

## 4. 최초 추천 이력 · 검은 경계 너머의 마을 (AI 제안)

> 후속 결정: 마을 잔상 단독 배치 대신 정면 균열 너머로 마을을 바라보는 구도로 구체화했다. 타이틀→로비의 동일 공간 카메라 이동은 채택됐으며 54의 독립 테스트 씬으로 구현했다. 아래는 최초 제안의 맥락이다.

하나의 사후세계 배경을 타이틀과 로비에서 이어 쓴다. 타이틀은 아직 지각하지 못하는 공간, 로비는 시험 대상이 드러난 공간으로 차이를 준다. 검은 우주에 별을 많이 뿌리면 우주 배경으로, 안개·해골·망령을 과하게 넣으면 공포물로 읽힐 수 있으므로 물성과 존재의 흔적을 최소화한다.

### 타이틀에 표시할 것

1. 화면 대부분을 차지하는 먹빛·아주 어두운 남청색 공간. 지평선·벽·바닥 경계는 분명히 그리지 않는다.
2. 하단에 드물게 번지는 흐릿한 파문 또는 희미한 빛의 반사. 실제 호수라는 설정은 확정하지 않는다.
3. 선명한 로고와 세로 메뉴: '시작하기 / 설정 / 종료'. 실제 저장 지원 전에는 '이어하기'를 제공하지 않는다.
4. 구석에 플레이테스트 표기·빌드 버전·피드백 링크.

첫 화면의 마을은 기본적으로 숨긴다. 시작을 선택하면 파문과 빛이 반응하면서 로비에서 마을의 잔상이 처음 드러나도록 한다. 몸 있는 캐릭터나 왕좌를 중심에 놓지 않아 플레이어의 정체와 충돌하지 않게 한다.

### 로비에 표시할 것

- 중심 오브젝트 하나: 어둠 속에 희미하게 맺힌 '시험 대상 마을의 잔상'. 낮은 시점의 집 실루엣이나 작은 지형 조각이 물 위 반사처럼 보인다. 수집품 진열장이나 자유 이동 허브 대신 고정 구도로 시작한다.
- 마을 안의 작은 따뜻한 불빛: 보호해야 할 생명의 표식. 사후세계의 차가운 색과 대비시킨다. 실제 NPC·대사 시스템을 추가하지 않고도 목적을 보여준다.
- 주인공의 존재: 인물 모델 대신 선택·클릭에 반응하는 작은 빛과 파문. 커서가 곧 영혼 그 자체라는 추가 설정은 미정으로 둔다.
- 필요한 정보만: 시험 이름/지역, 목표 생존 기간(실제 규칙 값), 실패 조건, '시험 시작'. 기록 기능이 존재할 때만 지난 시험 기록을 보조로 보여준다.
- 첫 방문에만 짧은 설정 안내 제안: '육신은 잠들어 있다. / 너에게 남은 것은 영력뿐. / 마을을 지켜, 돌아갈 자격을 증명하라.' 문구는 미채택.

대안은 '틈 사이로 마을이 보이는 수직 균열' 또는 '영력의 불씨 하나'다. 균열은 입구임이 명확하지만 판타지 포털의 관습적 인상이 강하다. 불씨는 가장 저렴하지만 건설·방어 게임임을 설명하기 어렵다. 마을 잔상은 재건 목표를 바로 연결한다는 이유로 추천한다.

## 5. 전환과 UI 공통 언어 · 구체 구현은 제안

### 권장 흐름

타이틀 → 사후세계 로비 → 시험 진입 전환 → 마을 건설·생존 → 시험 실패 / 시험 통과.

- 실패 후: 마을의 빛이 잦아들고 어둠이 중앙으로 모임 → 실패 결과 → 재도전 또는 로비. 패배를 주인공의 죽음으로 단정하지 않는다.
- 통과 후: 마을의 생활색과 소리가 충분히 남는 성공 장면 → 기록 → 현실 귀환을 암시하는 마무리. 현재 공개 분량이 전체 시험의 일부라면 '시험 통과' 대신 '플레이테스트 완료'를 써야 한다.
- 결과 이후 재도전·로비 복귀 규칙은 제안이며 현재 코드 동작을 바꾼 것으로 기록하지 않는다.

### 시험 진입 시청각 순서

1. 시험 시작 입력을 한 번만 수락하고 로비 UI가 사라진다. 마을 잔상에 시선이 집중된다.
2. 중앙의 작은 영역부터 시험 월드가 나타난다. 부드럽고 불규칙한 경계의 어둠이 가장자리로 물러난다. 뚜렷한 원형 와이프나 검은 연기 촉수보다 물속 먹물이 옅어지는 움직임을 지향한다.
3. 배경의 흐림·굴절이 줄고 색과 디테일이 돌아온다. 물속처럼 먹먹한 음색에서 마을 환경음이 선명해진다. 신체가 없으므로 거친 숨·물에서 발을 딛는 소리는 기본으로 넣지 않는다.
4. 전환이 끝나고 HUD가 읽히면 월드 입력과 시험 시간을 시작한다. 연출 중 밤·공격이 먼저 진행되는 불이익을 막는 설계 제안이다.

첫 진입 1.5~2.5초, 반복 진입 0.5~1초를 출발점으로 제안한다. 이는 조사 작품의 실측값이나 확정 수치가 아니다. 실제 로딩이 길면 진행 표시를 제공한다.

### 모달·HUD·버튼

- 월드 → 흐림/감광 → 가장자리 어둠 → 선명한 모달·텍스트·입력 표시 순으로 시각 계층을 둔다. 글자와 포커스는 왜곡하거나 흐리지 않는다.
- 모달 가장자리 어둠은 진입 전환과 같은 재질·움직임을 사용하되 외곽에서 멈춰 느리게 흐른다. 화면 중앙과 버튼 가까이까지 출렁이지 않게 한다.
- 겹친 모달마다 어둠을 중복 누적하지 않고 공통 배경 하나를 유지한다. 닫으면 가장자리 효과가 약해지며 기존 월드로 돌아온다.
- 게임 진행 중 HUD에는 지속적인 물결 왜곡을 적용하지 않는다. 영력은 은백·연청색, 마을의 삶은 따뜻한 금빛, 실패 경고는 별도의 명확한 색과 아이콘으로 구분하는 안이다.
- Hollow Knight에서 참고할 것은 높은 명도 대비, 넉넉한 여백, 배경과 메뉴의 시각적 분리, 분명한 선택 상태다. 자체 로고·최소 선·파문을 쓰고 기존 장식 양식을 복제하지 않는다.
- 본문은 읽기 쉬운 한글 글꼴, 장식성은 로고에 제한. 선택은 밝기뿐 아니라 작은 표식/밑줄도 병행한다. 실제 키보드·패드 지원 범위는 별도 구현 확인이 필요하다.
- 긴 모달의 반복 움직임·굴절은 줄이거나 끌 수 있게 하는 안을 검토한다. 기존 모달별 시간 정지 정책은 연출만으로 변경하지 않는다.

## 6. 기존 문서와 구현에 대한 영향

- 02 핵심 경험의 주인공 정체를 구체화한다. 플레이어는 신으로 확정하지 않으며 영웅 후보의 의식이다.
- 06 플레이 흐름의 화면 방향을 보완한다. 45의 구현 기록 `Title → Intro → Playing → Clear / GameOver → Title`은 그대로 보존한다. 로비와 새 전환은 54의 독립 테스트 씬으로 작성했으며 기존 프로토타입에는 적용하지 않았다.
- 기존 ui-design-rules.md의 프리팹·입력·모달 스택·시간 정책은 유지한다. 시각 테마의 후속 방향만 추가한다.
- 이후 구현 시 전환의 순수 상태/입력 제어와 Unity 시청각 표현을 분리하고, 공통 배경·모달·결과 화면 구성은 프리팹으로 재사용한다. 씬은 연결·조합만 담당한다.

## 7. 후속 검토와 검증 계획

- 먼저 타이틀/로비/모달의 정지 화면 시안을 동일한 배경으로 비교한다. 신규 상점·NPC·자유 이동 로비는 첫 범위에 넣지 않는 안을 추천한다.
- 가장 어두운 배경과 가장 밝은 시험 장면 위에서 메뉴·본문·선택 상태가 읽히는지 확인한다.
- 첫 플레이어가 '나는 몸 없는 영웅 후보', '마을을 지키는 시험', '통과하면 돌아감'을 짧은 안내만으로 이해하는지 관찰한다.
- 반복 전환 대기감, 긴 모달의 시각 피로, 먹먹한 음향에서 버튼 확인음의 식별성을 확인한다.
- 실패/통과 때 결과가 읽히기 전에 입력이 넘어가지 않고 전환 중 시험이 진행되지 않는지 검증한다.
- 이번 작업의 검증은 문서 링크와 대시보드 생성 확인까지다. 게임 화면·음향·플레이 경험은 검증하지 않았다.

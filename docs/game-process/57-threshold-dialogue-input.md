# 단일 파문과 입력 대기 인트로

> 최신 표면 방식은 [58 메쉬와 조명](58-threshold-lit-surfaces.md)을 따른다. 흰 선 파문과 랜덤 흰빛은 실제 표면 변형·광원 반사로 대체했다.

2026-09-26. 타이틀의 세로 반사광과 웅덩이 가장자리 반짝임을 제거했다. 검정 바탕에 흰색 단일 실선 파문만 표시하며 이중 보조선을 제거했다. 파문별 최대 반경은 7에서 2.2 월드 단위로 줄였고 기존 웅덩이 클리핑은 유지한다.

인트로는 자동 시간 진행을 제거했다. 마우스 왼쪽 클릭 또는 Enter/숫자패드 Enter를 누르면 한 문장 진행하며 마지막 문장에서 다시 누르면 균열 진입으로 이어진다. Esc는 설명 전체를 건너뛰되 진입 연출은 유지한다. 인트로에서 Esc로 설정 모달이 열리지 않도록 Host 입력을 분리했다. 첫 진입 프레임의 클릭은 문장 진행에 사용하지 않는다.

대화 왼쪽 아래에 전체 문장 수만큼 사각형을 표시한다. 현재 문장까지 흰색으로 채우고 이후 문장은 검정 속의 흰 테두리로 남긴다. 5문장이라면 1/5부터 5/5까지 표시된다. 사각형은 폰트 문자 대신 UI Image로 구성해 폰트 누락에 영향을 받지 않는다. 기존 건너뛰기 버튼 위치인 오른쪽 아래에는 `클릭 / Enter 다음 · Esc 건너뛰기` 안내를 둔다.

`ThresholdIntroTimeline`은 순수 입력 진행 로직이고 `ThresholdIntro`는 입력·자막·음성 중단·진행도를 연결한다. VoiceClips 연결은 유지하지만 녹음이 끝나도 자동 진행하지 않는다. 총 문장 수는 Lines 배열을 따른다.

관련 4개 어셈블리 `dotnet build --no-restore`: 오류 0·경고 0. Unity 플레이와 Test Runner는 프로젝트 지침에 따라 실행하지 않는다.

직접 확인: 테스트 씬에서 8초 이상 파문을 관찰해 세로 줄/이중선 없이 흰 실선이 짧게 퍼지는지 확인한다. 새 게임 후 기다려도 문장이 넘어가지 않아야 한다. 클릭과 Enter로 한 문장씩 진행하고 왼쪽 사각형이 하나씩 채워지는지, Esc가 모달 대신 균열 진입을 실행하는지 확인한다.

## 후속 수정 · 무작위 파문 위치

동심원의 고정 중심 두 곳을 제거하고 생성 번호를 시드로 하는 의사 난수 위치로 변경했다. 중심은 웅덩이 경계 안에 들어오는 내부 타원에서 선택하며, 생성 후에는 움직이지 않는다. 생성 간격은 기존 평균 4초(3.6/4.4초 교대)에서 3.2초로 줄였다. 파문 수명 8초·최대 반경 2.2·흰 단일 실선·외곽 클리핑은 유지한다. 살아 있는 최근 3개 파문만 계산하므로 시간에 따라 연산량이 늘지 않는다.

셰이더 변경으로 C# 변경은 없다. 플레이/셰이더 실행 검증은 수행하지 않았다. 테스트 씬 타이틀에서 20초 정도 관찰해 약 3.2초마다 다른 위치에서 파문이 생기고, 개별 중심은 고정된 채 퍼지는지 확인한다.

## 후속 수정 · 640×320 월드 출력

`ThresholdVeil`의 화면 크기 비례 캡처를 고정 640×320 RenderTexture로 바꿨다. Point 필터로 확대하며 MSAA와 밉맵은 사용하지 않는다. 타이틀·인트로·빈 인게임 등 메인 월드 카메라 출력 전체가 대상이고 Overlay Canvas의 글자·버튼·진행도는 화면 해상도를 유지한다. 마을 전용 포털 카메라의 텍스처는 유지하지만 최종 장면 출력은 640×320을 통과한다.

화면을 채워 확대하되 카메라 투영 비율은 실제 화면 비율로 보정해 지오메트리가 가로/세로로 늘어나지 않도록 한다. 비활성화 시 원래 타깃과 화면 비율을 복원한다. 창 크기가 바뀌어도 캡처 해상도는 유지한다.

관련 C# 4개 어셈블리 빌드로 검증하며 실제 플레이는 미실행이다. 테스트 씬 재생 시 WorldCamera의 Target Texture가 `Threshold World Capture 640x320`인지, 월드만 저해상도로 표시되고 대화 UI는 선명한지 확인한다.

## 후속 수정 · 움직이는 균열 외곽과 얇은 파문

VillageGlass의 외곽에 저주파 노이즈 변위를 추가해 윤곽 자체가 느리게 꾸물거리도록 했다. 이 변위는 영상 클리핑·어두워지는 구간·반짝임에 함께 적용된다. 외곽 영상 밝기는 거의 검정에서 시작해 안쪽 0.28 정규화 거리까지 부드럽게 원래 색으로 돌아온다. 기존 청회색 고정 테두리는 제거했다.

2.7초 구간마다 의사 난수로 선택한 짧은 외곽 구간에서만 작은 흰빛이 약 0.8초 이내로 나타났다 사라지며, 일부 구간은 건너뛴다. 전체 테두리나 화면을 번쩍이게 하지 않는다. 움직임 줄이기 옵션은 외곽 움직임과 반짝임을 멈춘다.

동심원의 화면 미분 두께 계수를 1.35에서 0.75로, 최소 폭을 0.028에서 0.014로 줄였다. 640×320 출력에서 선이 완전히 사라지지 않도록 화면 미분 기반 보정은 유지한다. 무작위 위치·3.2초 주기·최대 반경 2.2는 그대로다.

이번 수정은 셰이더만 변경했으며 플레이·셰이더 실행 검증은 하지 않았다. 타이틀에서 가늘어진 파문을, 인트로 첫 문장에 대기한 상태에서 15초 이상 외곽 움직임·짙은 가장자리·간헐적인 국소 흰빛을 확인한다.

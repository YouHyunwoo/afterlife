## 변경 전후와 사용법

기존 영력 100/설치 30/초당 회복 3에서, 본편은 준비된 슬롯 1개로 시작한다. 설치 성공 즉시 왼쪽 준비 슬롯을 소비하고 각각 10초 충전한다. 필드는 8초 유지되며 내부 작업은 기본 1초마다 진행한다. 충전된 슬롯은 기존 필드가 살아 있어도 사용할 수 있다. 설치 불가/중복 위치는 슬롯을 소비하지 않는다.

기본 커서 반경은 0.65→0.50, 추가 주민당 반경은 4%→8%다. 필드 반경은 `CursorRadius × (1 + 주민 보너스 × max(0, 주민−1)) × (1 + 연구 반경 + 일일 반경) × 1.8`이다. 표시와 판정이 같은 반경을 사용하고 설치된 필드는 설치 당시 반경을 유지한다. 단위당 채집량·판매 단가·적 수는 변경하지 않았다.

슬롯 HUD는 기존 영력 표시 위치의 흰색 가로 바다. 바 48×6, 사이 간격 10(Canvas 기준 단위), 사용 시 배경 15% 불투명도, 충전에 따라 왼쪽에서 채움, 완료 시 0.1초 간격으로 두 번 점멸한다. 점멸은 입력을 막지 않는다. 재사용하면 점멸을 취소한다.

연구소에 기존 연구 10개와 제단 10개, 신규 슬롯 연구 2개를 모았다. 마법 계열은 제단이 있어야 구매할 수 있으며 기존 마법사·마법탑 제단 조건은 유지한다. 제단 우클릭은 연구소에서 강화하라는 안내를 표시한다. 기존 트리 에셋과 ID는 보존한다.

| 신규 연구 | 가격 | 효과 |
|---|---|---|
| 추가 필드 슬롯 R11 | 100G, 1단계 | 슬롯 +1 |
| 슬롯 재충전 R12 | 60/120/180G | 충전 시간 −10/20/30%, R2 1단계 선행 |

기존 R8은 내부 작업 간격 감소를 유지하고 이름을 ‘필드 작업 속도’로 바꿨다. 충전과 작업 속도는 별개다. 새 슬롯은 준비 상태이며 충전 감소 구매 시 기존 슬롯의 완료 비율을 보존한다.

## 자동 스킬과 일일 보상

Q/W/E·스킬 버튼 수동 시전을 본편에서 제거했다. 기존 HUD는 [자동], 미해금, 발동 중, 쿨타임, 제단 필요, 준비를 표시한다. 연구 구매로 해금한 스킬만 기존 쿨타임·지속 시간으로 작동하며 슬롯은 소비하지 않는다.

- 낙뢰/의식은 마을 영역 안의 적 중 완공된 집과 가장 가까운 적을 우선한다. 동률은 ID 순서다. 연쇄도 마을 영역 밖을 공격하지 않는다.
- 풍요는 활성 필드 안에 살아 있는 나무/바위가 있을 때 발동한다.
- 조건이 없으면 준비 상태로 기다린다. 제단 파괴는 새 시전만 막고 이미 시작한 지속 효과와 쿨타임은 정상 진행한다.
- 의식은 후속 펄스마다 대상을 다시 고른다. 마을 안 적이 없으면 해당 펄스를 생략한다.

| 일일 보상 | 효과 | 상한 |
|---|---|---|
| 넓어지는 손길 | 반경 +15%씩 | 3단계 |
| 빠른 재충전 | 충전 −10%p씩 | 3단계, 연구 합산 최대 50% |
| 추가 필드 슬롯 | +1 | 한 번, 연구 포함 최대 3슬롯 |

기존 3개 중 1개 선택과 미보유 우선 규칙을 유지한다. 상한 또는 효과 없는 후보는 제외하며 신규 보상은 상자 풀에 넣지 않는다. 신규 보상 아이콘은 기존 반경·작업·충전 관련 연구 아이콘을 재사용한다.

자원 최대 개수 보상은 단계당 +50%→+100%, 생성 간격은 단계당 ×0.7→×0.5다. 생성 간격 최소 1초를 유지하고 더 줄어들지 않으면 속도 보상을 제외한다. 상한 증가는 자원을 즉시 생성하지 않는다.

## 진행과 편집 위치

낮은 1일차 90초, 2일차 60초, 이후 45초다. 황혼 10초·밤 최소 35초이며 침공 적이 남으면 밤이 연장된다. 타이머 합계 10분, 실제 첫 체험 목표 10~15분. 6일 방어 후 보상 선택 없이 클리어한다. 본편 환생 진입·버튼·결과 안내는 숨기고 기존 환생 코드는 유지한다.

Unity 프로젝트 기준:

- `Assets/_AfterlifePrototype/Resources/AfterlifePrototype/SettingsData/System.asset`: MvpSlots, 슬롯 수·충전·일차별 시간·기본 반경.
- 같은 폴더 `Economy.asset`: 주민 반경 증가율. `Relics.asset`: 신규 보상 효과·상한과 자원 계수.
- `Resources/AfterlifePrototype/MvpProgression.asset`와 `ProgressionData/MvpResearch.asset`: 본편 통합 트리. 기존 강화 에디터는 통합 카탈로그를 우선 열며 기존 카탈로그도 선택 가능하다.
- `Resources/AfterlifePrototype/FieldSlotsHud.prefab`: 슬롯 HUD. 본편 씬의 PrototypeView에 연결한다.

`MvpSlots=false`인 소비자는 기존 영력·두 트리·수동 시전·환생 흐름을 사용한다. Devlog의 독립 필드 소비자는 `TryPlace`의 기본 영력 경로를 그대로 사용한다. 본편의 통합 트리를 원본 legacy Progression에 덮어쓰지 않는다.

에디터 설치 API `PrototypeMvpSetup.Apply()`는 본편 수치를 승인된 초기값으로 설정하고 없는 신규 에셋만 생성한다. 반복 호출은 본편 수치를 초기값으로 되돌리므로 이후 밸런싱에는 Inspector를 사용한다. `ConnectSceneHud()`는 본편 씬이 열려 있고 미저장 변경이 없을 때 프리팹 인스턴스와 참조를 저장한다. 새 Tools 메뉴는 추가하지 않는다. `.meta`는 Unity가 생성한다.

## 모듈 경계와 수명

`Afterlife.RechargeSlots`는 Unity 참조가 없는 독립 코어다. `RechargeSlotService`는 읽기 전용 슬롯 목록, 소비, Tick, Configure, Reset, Changed/Recharged 이벤트만 제공한다. 필드 수명과 작업은 기존 DivineFields가 소유한다. PrototypeDivineFields 어댑터가 설치 성공과 슬롯 소비를 연결한다.

`Afterlife.RechargeSlots.Unity`의 `RechargeSlotsHud`는 게임 모델을 모른다. 프리팹 하나를 Canvas 아래 배치하고 게임 어댑터가 `Bind(service)`만 호출한다. 자식 Fill 참조는 자동 탐색한다. 비활성화·파괴·재바인딩 시 구독을 해제한다. 분리하려면 어댑터 참조와 프리팹 인스턴스를 제거한다. 본편에서 슬롯 모드를 유지할 때는 HUD 참조가 필수다.

자동 시전 허용 정책은 Skills 코어의 `AutomaticSkillPolicy`에 콜백으로 주입한다. 마을 좌표·자원·표적 선정은 PrototypeAutomaticSkills 어댑터에 둔다. 일시정지와 정산에는 모델 Tick이 실행되지 않아 충전과 지속 시간도 멈춘다. 새 판/환생 초기화에는 능력·보상 초기화 후 슬롯 용량과 충전을 초기화한다.

## 검증 절차

기술 검증: 프로젝트 루트에서 `powershell -NoProfile -ExecutionPolicy Bypass -File impls/unity/Afterlife/Tools/AfterlifePrototype/Build-ScriptableData.ps1`. Unity 생성 참조를 이용한 검증 csproj로 `dotnet build --no-restore`만 실행한다. 슬롯 코어/Unity·DivineFields·Skills·데이터·Progression·Prototype·Editor·Day01/02 소비자를 포함한다. Unity Play/Test Runner는 실행하지 않는다.

실행 결과: 12개 어셈블리 모두 오류 0개. Progression.Unity 22개·Prototype 30개의 CS0649 직렬화 참조 필드 경고가 있으며 나머지는 경고 0개다. 로그는 작업 공간 `Temp/mvp-build-final.log`에 남겼다. 에디터에서 통합 카탈로그 1개 트리/22개 노드/제단 요구 10개와 검증 오류 없음, HUD 3개 자식 및 48×6·58 간격 배치, 본편 씬의 직렬화된 `_fieldSlotsHud` 참조를 확인했다. 신규 `.meta`는 Unity가 생성했다. 이 결과는 사람 플레이 검증이 아니다.

사용자 직접 확인:

1. 본편 새 게임: 흰색 슬롯 1개, 첫 낮 90초, 작은 필드 미리보기. 유효 위치에 설치하면 하나 소모되고 10초 충전, 필드는 8초 후 사라져야 한다. 겹친 곳/물/시야 밖 실패는 소비하지 않아야 한다.
2. 주민 증가와 R3/반경 보상: 새 필드 범위가 커지고, 이미 설치한 필드의 크기는 유지되어야 한다.
3. R11/슬롯 보상: 2·3개로 늘고 새 슬롯은 즉시 사용 가능. 서로 다른 시각에 사용하면 각자 충전해야 한다. 완료 시 두 번 점멸, 점멸 중 사용 즉시 취소.
4. 충전 도중 R12/충전 보상: 완료 비율 보존, 최대 감소 50%. 정산/일시정지에서는 진행 중지. 새 판은 보상·강화 없이 1개 준비 상태.
5. 연구소에서 마법 구역 확인: 제단 없이 구매 불가, 건설 후 가능. 제단 우클릭은 연구소 안내. Q/W/E와 표시 버튼은 시전하지 않아야 한다.
6. 마을 안/밖 적과 낙뢰·의식 확인: 내부만 자동 공격, 빈 영역은 준비 유지. 채집 가능한 필드가 생기면 풍요 자동 발동. 제단 파괴 후 새 발동 중지, 진행 효과는 정상 만료.
7. 일일 보상 상한 도달 시 후보 제외, 슬롯은 총 3개. 기존 상자에서 신규 세 보상이 나오지 않아야 한다. 자원 최대 수와 재생 효과가 툴팁과 일치해야 한다.
8. 2일차 낮 60초·3~6일차 45초, 마지막 침공 처치 후 클리어. 환생 버튼/안내 없음. 패배와 재시작도 정상 동작.

고정 시드에서 첫 90초 골드·첫 방어 완성 시점·일차별 골드/주민/병력·무행동 시간·자원 부족·전체 소요 시간을 기록한다. 이 작업에서는 실제 수입 감소나 10~15분 달성을 측정했다고 주장하지 않는다.

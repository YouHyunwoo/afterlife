# 밤 종료 후 잔여 적 처리

## 변경 전후

기존에는 밤 시간이 끝나도 모든 침공 적이 죽기까지 기다렸다. 침공 적은 마을로 접근하지만 시야 밖 목표를 잡지 못하며, 지형에 갇힌 적을 안내·복구하지 않았다.

이제 밤 시간이 0이 되면 침공 적에 한해 시야 거리 제한 없이 아군·건물을 목표로 삼는다. 이 게임은 직접 이동하는 플레이어 캐릭터가 없으므로 플레이어의 병력·마을로 접근한다. 자연 발생 슬라임 등 비침공 적에는 적용하지 않는다.

| 밤 종료 후 경과 | 동작 |
| --- | --- |
| 즉시 | 침공 적 목표 탐색 시야 제한 해제 |
| 20초 | 화면 안 적 위 방향 표시, 화면 밖 적은 가장자리 방향 표시 |
| 40초 | 방향 표시 유지, 2초 주기로 0.65초 빛기둥 점멸 |
| 60초 | 방향 표시와 빛기둥 지속 표시 |

시간은 모델 시뮬레이션 기준이며 일시정지 중에는 누적하지 않는다. 표시만 추가하며 주변 안개나 공격 사거리는 변경하지 않는다. 밤 종료 후 생성 대기 적은 어둠 조건을 해제하여 밝은 지형만 남아도 출현할 수 있다. 지도 경계·육지·장애물·유닛 겹침 검사는 유지한다.

## 접근 불가 복구

5초마다 살아 있는 침공 적 한 마리를 순환 검사한다. 기절·공격 준비 중인 적은 건너뛴다. 현재 좌표가 이동 불가능하거나, 이동 가능한 격자 전체를 확인해도 어떤 아군·건물에도 공격 가능한 위치로 갈 수 없을 때만 복구한다. 유닛 혼잡은 영구 장애물로 판정하지 않는다.

복구는 집 주변의 이동 가능하고 유닛과 겹치지 않는 위치를 탐색한다. 해당 위치에서 집까지 완결된 경로가 확인되면 이동하고 경로·사격 위치 캐시를 초기화한다. 체력은 보존한다. 모든 후보가 실패하면 퇴각시키며 처치·경험치·전리품 보상을 주지 않는다. 기존 전멸 판정으로 다음 틱에 정산한다.

탐색은 0.5 단위 격자와 대각선 모서리 차단을 사용한다. 4096칸 탐색 한도에 도달하면 `Unknown`으로 처리하고 이동·퇴각시키지 않는다. 좁은 연속 좌표 통로, 대규모 분리 영역, 다수 적의 검사 지연은 수동 검증 대상이다. 지도 전체에 생성 가능한 칸 자체가 없는 경우의 생성 대기는 별도 한계로 남는다.

## 모듈과 적용

- `Assets/Afterlife/Modules/NightCleanup`: Unity 참조 없는 시간 단계와 격자 접근성 판정. 게임 모델·전역 서비스 참조 없음.
- `Assets/Afterlife/Modules/NightCleanup.Unity`: `RemainingEnemyMarkers` 컴포넌트와 전용 URP 표시 셰이더. 월드 좌표·ID·카메라만 전달받는다. 조명·안개에 묻히지 않는 표시 전용 선을 사용한다.
- `PrototypeNightCleanup.cs`: 게임 상태·침공 적·지형·복구 위치를 공용 규칙에 연결하는 어댑터.
- `PrototypeNightCleanupView.cs`: 게임 카메라와 지면 높이를 연결하는 얇은 표시 어댑터.

기존 Prototype 씬은 실행 시 표시 컴포넌트를 자동 연결하므로 씬·프리팹 재설정이 필요 없다. 다른 소비자는 오브젝트에 `RemainingEnemyMarkers` 하나를 추가하고 `Present(camera, targets, showDirection, showBeacon)`를 호출한다. 필수 외부 값은 카메라와 대상 좌표 목록뿐이다. 내부 선·재질은 자동 생성한다. 사용 종료 시 `Clear()` 호출 또는 컴포넌트 비활성화/제거로 표시를 해제한다. 오브젝트 삭제 시 재질도 정리한다.

판 재시작·환생의 `ResetAttempt`, 새 밤, 정산, 승리·패배에서 시계를 초기화한다. 사망/퇴각 대상은 다음 표시 갱신에서 제거한다. 타이틀 복귀의 세션 종료 시 전체 표시를 제거한다. 이벤트 구독은 없다. `.meta`는 Unity 에디터가 생성한다.

## 검증

저장소 루트 PowerShell:

```powershell
& impls/unity/Afterlife/Tools/AfterlifePrototype/Build-ScriptableData.ps1 -Modules @('Afterlife.NightCleanup','Afterlife.NightCleanup.Unity','Afterlife.Prototype')
```

스크립트는 관련 어셈블리에 `dotnet build --no-restore`만 수행한다. Unity Test Runner/EditMode/PlayMode와 플레이 스모크 테스트는 실행하지 않는다. 셰이더 표시 결과는 C# 빌드로 검증되지 않는다.

2026-09-29 검증 결과: 코어·Unity 표시·Prototype 3개 어셈블리 모두 빌드 오류 0개. 신규 2개 모듈 경고 0개, Prototype은 기존 Inspector 연결 필드 CS0649 경고 30개. 로그: `Temp/night-cleanup-build.log`. Unity Assets/Refresh로 신규 메타데이터를 생성했다. 실제 플레이·셰이더 시각 결과는 미검증이다.

사람이 Unity에서 확인할 절차:

1. Prototype 씬에서 밤이 끝날 때까지 침공 적 한 마리를 남긴다. 밤 시간이 0이 된 뒤 적이 병력·마을을 향해 접근하는지 확인한다. F4의 밤 건너뛰기는 적을 지우므로 사용하지 않는다.
2. 잔여 적을 화면 밖에 둔다. 종료 후 20초에 가장자리 방향 표시, 40초에 점멸, 60초에 지속 빛기둥이 나타나는지 확인한다. 카메라 회전·확대·축소·화면 비율 변경에도 방향이 맞아야 한다.
3. 게임을 정지하는 모달을 열고 기다린다. 닫은 뒤 정지 전 단계부터 이어져야 한다.
4. 격리된 지형/이동 불가 위치의 침공 적은 검사 후 집 주변의 유효 위치로 옮겨지고 체력이 유지되어야 한다. 복구 위치가 전혀 없으면 보상 없이 퇴각해야 한다. 경로가 정상인 적, 전투 중인 적, 자연 발생 적은 이동·퇴각하면 안 된다.
5. 마지막 적 처치/퇴각 후 정산과 함께 표시가 사라져야 한다. 타이틀 복귀·재시작·다음 밤에 이전 표시와 경과 시간이 남지 않아야 한다.
6. 밝은 지형만 남은 상황에서 밤 종료 후 생성 대기 수가 실제 출현으로 감소하는지 확인한다.

## 2. 연결 계산의 새 계약

일차 말 잔고 = 이전 잔고 + 실제 버튼 유지 채집 + 농장 생산 + 처치/정산 등 기타 지급 − 착공/강화 등 해당 재화 지출 − 실제 수리비 − 시간 가속비.

골드·에테론을 각각 이월하고 주문/생산/정산 지급 시각을 구분한다. 낮 동안의 구매 가능성을 하루 전체 수입으로 판단하지 않는다. 공사에 클릭을 쓸 때 직접 채집은 줄지만 농장·자동 공사·군사 충원은 병렬로 진행한다.

농장은 완공 후 실제 회차만 지급한다. 직접 작업량 강화와 농장 생산량/주기 강화의 효과를 별도 기록한다. 충전 대기·필드 작업 횟수·동시 필드 수·반경 배율은 새 계산 입력에서 제외한다.

## 4. 강화와 농장 경로

첫 농장은 기존 골드 건설로 자동 수입을 시작한다. 제단/성소와 에테론 강화 접근은 유지하는 기본 연결 후보다. 농장 강화가 열린 뒤 생산량/주기와 작업 1회당 효과 중 선택하도록 비용·선행을 설계한다. 특정 노드 ID·가격·배율은 미정이다.

R8의 −20% 필드 작업 간격, R11 슬롯+1, R12 충전 감소와 그 구매 예산/선행 경로는 본편 계획에서 폐기한다. R2 등 작업량 계열도 기존 효과가 유효 작업 1회에 어떻게 적용되는지 확인한 뒤 재산정한다. 풍요는 새 조건/효과가 확정되기 전 수입 증가로 계산하지 않는다.

## 5. 새 예산표에 필요한 측정

각 날 시작/종료 잔고, 채집 유효 작업 횟수·버튼 유지 시간·회당 실제 수입·채집 시간, 농장 수·완공/가동 시간·배치 보너스·생산 강화·실제 지급 회차, 시설/강화 구매·완공·충원/이동 시각, 수리/가속 지출을 기록한다. 병력 손실과 농장 파괴에 따른 이후 일차 수입도 이월한다.

기본 첫 판·생산 중심·직접 효율 중심·방어 중심 경로를 비교한다. 재도전 병종 해금은 별도 제안 상태로 구분한다. 농장만 반복하거나 장시간 직접 작업 유지만 하는 경로가 유일한 정답이 되지 않는지 본다.

## 1. 돈과 시간을 연결하는 방법

초안의 초기 필드는 충전10초·수명8초·간격1초를 계산용 출발점으로 사용한다. 세 값은 고정 규칙이 아니며 변경하면 예산을 다시 계산한다.

단일 나무·충분한 잔량·강화0이면 설치당8회×1개×1G=8G, 장기 평균 **0.8G/초**다. 바위는 기존1개×2G를 우선 유지하므로 같은 조건의 계산값은1.6G/초다. 이전69의 ‘나무도1.6G/초’는 이번 설계에 적용하지 않는다.

- 시설 가격55G는 초기 단일 나무 채집 약68.75초의 가치다.
- 무료 전사 충원10초는 초기 채집8G분의 시간과 비교할 수 있지만 실제8G가 차감되지는 않는다.
- 자동 충원은 채집과 동시에 진행된다. 생산10초를 매번 채집10초 손실로 빼지 않는다.
- 채집용 필드를 건설/수리로 전환한 시간은 직접 채집의 기회비용이다.
- 가속은 현재 회차의 남은 시간을 돈으로 줄이는 실제 지출이다.

시설은 가격·완공 시간·정원·충원 속도를 같이 평가한다. 군사 시설이 늘면 살아 있는 정원뿐 아니라 동시에 손실을 보충할 회차 수도 늘어난다.

## 2. 추천 시작 수치와 가격

시작 골드20G는 첫 농장25G에 조금 못 미치는 금액이다. 첫 채집 성과로 빠르게 첫 투자를 하게 하고, 나무 작업량 감소로 첫 구매가 지나치게 늦어지는 문제를 줄이는 후보안이다. 시작 주택은 기존처럼 완공 상태다.

|---|---:|---:|---:|---|
| 주택 | 20G | 15G | 18.75초 | 연결·부지·건설 효율 |

기본 가격은 판 동안 유지한다. 각 날마다 가격을 새로 올리지 않고 시설·병력·필드 성장이 다음 날의 구매 부담을 줄이게 한다.

농장은 기본1G/5초를 추천한다(현행3초).25G 회수까지 완공 후125초이며 인접/비옥 보너스는 유지하는 후보안이다. 초기 가격을 내리면서 기존3초 생산까지 유지하면 생산 투자만 반복하는 경로가 지나치게 빠르게 커질 수 있어서 함께 조정한다. 아래 예산은 인접/비옥 보너스를 제외했다.

전사·궁수10초, 기사18초, 마법사15초의 회차는 우선 유지한다. 정원3명이 모두 비어 있으면 시설당 최대30/54/45초가 필요하다. 여러 시설은 동시에 생산한다. 군사 가속은1초당1G를 추천하며 현행5G/초에서 변경이 필요하다. 제단/성소 가속은 이번 대표 경로의 필수 수단으로 사용하지 않고 현행 비용을 변경하지 않는다.

건설을 필드로 도울 때 기본 시설의 목표 완공 시간은 약10~15초다. 자동 건설만 기다린 실제 시간과 구분한다. 현행 건설 계산으로 목표가 맞는지는 직접 확인한다.

## 9. 검증과 미결정

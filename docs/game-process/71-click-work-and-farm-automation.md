# 버튼 유지 상호작용과 농장 자동 생산 · 확정 규칙

- 결정일: 2026-10-03 · 클릭 1회 작업을 버튼 유지 반복 작업으로 수정
- 상태: 사용자 채택 · 2026-10-09 본편 유지 입력/내부 게이지 구현 · 사용자 플레이 검증 전
- 초기 요청 범위(2026-10-03): 기획·사용법·설계·검증 문서와 대시보드 갱신. 후속 구현 요청으로 본편 입력 코드를 변경했다. [현재 사용법·설계·검증](73-hold-interaction-gauge.md).
- 핵심 요약: 작업 대상에서 버튼을 누르고 있는 동안 채집·공사·수리·공격을 작업 주기에 맞춰 반복하고, 놓으면 중단한다. 농장은 입력 없이 지속 생산한다.

## 1. 채택된 방향과 유지 범위

상호작용마다 다시 클릭하지 않는다. 유효한 작업 대상에 작업 버튼을 누른 뒤 유지하면 작업 주기에 따라 반복한다. 버튼을 놓으면 이후 반복 작업을 중단한다. 강화는 작업 1회당 효과를 높이고 농장 건설·생산 강화가 입력과 독립된 자동 수입을 확대한다.

| 항목 | 확정 방향 |
|---|---|
| 채집 | 버튼 유지 중 자원에 주기 작업, 실제 채집량만큼 골드. 나무 기본 작업량 1은 작업 1회당 양으로 유지 |
| 건설 | 버튼 유지 중 공사에 주기별 진행량 기여. 기존 기본 자동 공사는 유지 |
| 수리 | 버튼 유지 중 손상 건물에 주기별 복구량 기여. 기존 일반 수리비·최대 체력 적용 |
| 공격 | 버튼 유지 중 유효 적에 주기별 공격. 병력·타워 자동 전투를 보조 |
| 농장 | 완공 후 버튼·커서와 무관한 보리→골드 생산. 생산량·주기 강화로 성장 |
| 강화 | 직접 작업 1회당 채집량·공사량·수리량·피해와 농장 생산 효율을 각각 강화 |

본편 입력의 필드 설치·범위 다중 작업과 필드/슬롯 HUD는 제거했다. **필드 슬롯 충전**을 제거하는 것과 새 **단일 작업 내부 게이지**는 구분한다. 작업 게이지는 버튼을 놓아도 충전하지만 완충만으로 작업하지 않는다. 버튼을 누르지 않는 호버·토글 자동 작업·광역 클릭 강화는 도입하지 않는다.

영력 세계관·제단/성소 에테론 접근, 농장 기존 인접/비옥 보너스, 주택 연결·마을 건설 배율·합체·주민/인구 제거, 군사 무료 정원 충원·골드 가속과 독립 자동 전투는 [64 건물 경제](64-building-economy.md)의 기존 규칙을 유지한다.

## 2. 시작·반복·중단과 조작 안내

> 후속 사용자 지시 · 2026-10-09: 본편은 **현재 마우스 위치의 단일 대상**, 기본 **1초**, 판 시작 **100%**다. 실행하면 0%부터 충전하며 버튼을 놓으면 100%에서 대기한다. 완충 재누르기는 즉시 1회 실행한다. 대상 전환/재입력은 충전량을 유지하고 유효 작업 때만 소비한다. 좌버튼 드래그는 제거한다. UI·모달·포커스 차단 후에는 새 누르기가 필요하다. 촬영용 0.7초·회당 1/3과 별개다.

| 입력·상태 | 결과 |
|---|---|
| 유효 자원에서 작업 버튼 누르기 유지 | 작업 주기에 맞춰 채집 반복, 회당 수입과 잔량 표시 |
| 공사/손상 건물에서 작업 버튼 유지 | 공사/수리 반복, 실제 진행량·회복량·수리비 표시 |
| 유효 적에서 작업 버튼 유지 | 공격 반복, 회당 피해 표시 |
| 버튼 놓기 | 직접 작업 중단. 내부 게이지는 100%까지 충전 후 대기. 완료한 작업/지급은 되돌리지 않음 |
| 버튼을 누르지 않은 호버 | 선택 미리보기만, 작업 없음 |
| UI·모달·일시정지·포커스 상실·판 종료 | 직접 반복 중단, 해당 입력으로 월드 작업 중복 실행 없음 |
| 대상 고갈·파괴·사망·완공·최대 체력 | 해당 작업 종료, 초과 지급/복구/피해 없음 |
| 수리비 등 작업 조건 부족 | 해당 회차 미실행·게이지/비용 소비 없음. 유지 중 조건이 충족되면 현재 충전량으로 재개 |
| 빈 타일 일반 클릭 | 작업/필드 없음. Ctrl/Shift 건설 모드의 기존 클릭 배치는 유지 |
| 병력 선택·관리·이전 드래그 | 좌버튼 드래그 선택/이전/공격 이동 제거. 우클릭 정보·관리 경로 유지 |
| 농장 생산 | 직접 작업 버튼을 놓거나 다른 조작을 해도 지속. 정산·일시정지는 기존 생산 정지 정책 |

현재 커서의 단일 유효 대상만 작업하며 대상 전환은 게이지를 초기화하지 않는다. 첫 작업은 시작 100%를 사용해 즉시 실행한다. 게임 시간으로 1초씩 충전하고 빠른 재누르기로 주기를 우회하지 않는다. 작업이 실행된 뒤의 표현은 끝날 수 있지만 해제 후 새로운 작업/지급을 예약하지 않는다. 주기 단축 강화 노드는 새로 채택하지 않았다.

좌버튼은 작업 전용이고 이전/병력 드래그 입력은 제거했다. 공사/수리와 우클릭 정보·관리 입력을 분리한다. UI·모달·포커스 상실 후에는 버튼을 놓고 다시 눌러 재개한다. 새 단축키는 추가하지 않았다.

상자·귀중품도 같은 단일 작업 게이지를 사용하고 기존 고갈/완료 규칙을 유지한다. 도움말은 ‘작업 대상을 좌클릭으로 누르고 있으면 계속 작업합니다’로 안내한다. 내부 주기·게이지는 HUD에 노출하지 않으며 슬롯/필드 HUD도 숨긴다.

## 3. 사용자 경험·강화·보상

버튼 유지 채집 → 첫 농장 건설 → 다른 조작 중 자동 수입 → 생산 확대/강화 → 병력·방어 투자 → 중요한 대상에 유지 작업 개입으로 이어진다. 연타 부담을 줄이되 마을 생산이 성장하면 직접 채집에 붙잡히는 시간도 줄어드는 경험을 목표로 한다.

직접 강화는 ‘클릭당’ 대신 **작업 1회당 채집량·공사량·수리량·피해**로 정의한다. 농장 생산량·주기 강화 방향은 유지한다. 작업 주기는 반복 입력의 기본 규칙이며 주기 단축 강화를 새로 도입할지는 별도 결정이다.

기존 R8 필드 간격·R11/R12 슬롯·반경 계열과 일일 보상은 본편에서 폐기·재설계한다. 이름만 바꿔 작업 주기 또는 농장 효과에 승계하지 않는다. 기존 노드 ID·가격·효과·선행/호환과 새 보상 상한은 구현 전 정의한다. 제단/성소 에테론 강화 접근은 기본 연결 후보이며 첫 농장은 강화 없이 생산한다.

풍요의 활성 필드 조건·후속 회복/보호·재사용 시간 효과는 재설계 대상으로 유지한다. 농장 생산 지원으로 연결하는 것은 추천안이며 정확한 조건/배율은 미정이다. 독립 낙뢰 등 자동 스킬·일일 3택1 구조는 유지한다.

## 4. 경제·시간·일차별 영향

2026-10-04 수치 후속: [72 경제 밸런싱1차](72-hold-economy-balance.md)에 추천 가격·농장 성장·구매 마감·6개 경로 산술 결과를 기록했다. 2026-10-09 기본 1초만 채택했다. 첫 실행은 해당 계산의 1초 대기와 달리 시작 100% 즉시 실행이다. 나머지 경제 수치와 강화는 미채택이다.

**직접 수입 = 대상별 완료된 유효 작업 횟수 × 회당 실제 채집량 × 단가.** 작업 횟수는 버튼 유지 유효 시간·작업 주기·첫 실행/대상 전환 정책·잔량/비용에 따라 달라진다. 클릭 횟수나 사람의 연타 빈도를 수입 기준으로 사용하지 않는다.

단순 지속 작업률은 ‘회당 채집량×단가/1초’이며 실제 수입에는 시작 완충·유효 유지 시간·중단·대상 변경·이동·자원 고갈을 반영한다. 실제 본편 회당 작업량/경제 재조정은 별도다. 나무 기본량1의 기획은 회당 양이고 과거 필드0.8/1.6G/초를 승계하지 않는다.

농장 수입은 완료 생산 회차×회당 골드이며 인접/비옥/강화와 실제 가동 시간을 반영한다. 직접 공사·수리·공격 중 농장/자동 공사/군사 충원은 병렬 진행한다. 직접 채집에 사용하지 않은 시간은 채집 기회비용이지만 농장 수입 손실로 중복 차감하지 않는다.

10일·25~30분 목표와 [68 시간표](68-ten-day-content-plan.md)의 26:30 후보는 유지한다. [69 경제 기준](69-harvest-economy-baseline.md)·[70 연결 경제](70-connected-ten-day-economy.md)에서 작업 횟수·유지 시간·주기와 농장 생산을 따로 측정한다. 이전 필드/매회 클릭 모델의 예산·구매 시각·이월을 새 규칙의 결과로 쓰지 않는다.

## 5. 구현 경계·적용 상태

순수 직접 작업 계산·반복 시간·시작/중단/대상 유효성과 Unity 버튼 상태·대상 선택·도구/타격 표현을 분리한다. 농장 생산은 기존 Buildings 코어와 게임 어댑터가 연결한다. Interaction의 표면 선택 기능과 기존 표현은 재사용한다.

`Afterlife.HoldInteraction` 순수 코어와 `PrototypeManualWork` 어댑터를 기존 `PrototypeView`에 연결했다. 본편 씬에는 추가 설치/직렬화 참조가 없다. [적용·해제·검증](73-hold-interaction-gauge.md)과 [모듈 적용 기준](../architecture/module-application-guideline.md)을 따른다.

본편 필드 생성 입력·HUD·기본 안내를 유지 작업으로 전환했다. 필드 전용 강화·풍요·보상의 새 효과 설계는 별도이며 노드 ID/값을 임의 승계하지 않았다. DivineFields/RechargeSlots는 기존 촬영 소비자·GUID/직렬화 참조와 함께 보존한다. 파일명 `71-click-work-and-farm-automation.md`는 기존 링크를 위해 유지한다.

## 6. 검증 계획·미정 사항

| 질문 | 확인 방법 |
|---|---|
| 유지 중 반복/해제 후 중단되는가 | 네 작업 대상에서 같은 시간 누르기·놓기, 회당 결과/주기 확인 |
| 호버만으로 작업하지 않는가 | 버튼을 놓고 대상 호버·커서 이동, 추가 직접 작업 없음 |
| 중단 조건이 안전한가 | UI/모달·정지·포커스 상실·판 종료·대상 고갈/파괴·자금 부족, 중복 비용/초과 작업 없음 |
| 반복 주기가 프레임/연타에 좌우되지 않는가 | 서로 다른 프레임 속도·빠른 재누르기·긴 유지, 시작/전환 정책에 맞는 같은 작업량 |
| 대상/관리/드래그와 충돌하지 않는가 | 현재 커서 단일 대상 전환·우클릭 관리·좌버튼 드래그 제거를 검증 |
| 작업량 강화가 정확한가 | 같은 유효 작업 횟수에서 실제 수입/공사/복구/피해와 표시 비교 |
| 농장이 입력과 독립인가 | 버튼 해제·다른 조작 중 생산 지속, 정지/파괴/이전·보너스/강화/초기화 확인 |
| 입력 부담과 운영 시간이 개선되는가 | 일차별 누르기 시작/해제·유지 시간·작업 횟수·중단 이유·농장 수입 비중·피로감 측정 |
| 경제와 방어 목표가 성립하는가 | 첫 시설 구매/완공/충원, 중반 복구, 후반 자동 수입/중요 대상 개입, 전체 시간 재측정 |

입력·게이지 규칙은 위 후속 결정으로 확정/구현했다. 미정: 회당 작업량/수리비 재조정, 농장 강화·풍요·노드/보상·새 경제 수치. 이전 클릭/호버/필드 QA를 유지 입력의 검증으로 재사용하지 않는다. [현재 수동 검증 절차](73-hold-interaction-gauge.md)를 사용한다.

## 7. 문서 상태

버튼 유지 규칙과 본편 입력 구현을 현재 문서에 반영했다. 기존 결정과 역사 시연은 보존한다. 대시보드 재생성·링크/문서 정합성 확인과 C# 컴파일은 Unity 실제 조작·사람 경험 검증과 별개다. 농장/강화 재설계는 여전히 후속 작업이다.

# 제작 절차와 마일스톤

- 최신 상태: M5 — 영력 필드 핵심 조작 구현, C# 컴파일 완료·Unity 임포트/직접 플레이 확인 대기. M1 완료, M2 상세 수치 보완, M3 첫 범위 채택, M4 첫 프로토타입 완료. 전체 판 검증과 M6 업데이트 준비는 별도다.
- M2 전체 수치를 끝내기 전에 핵심 프로토타입의 범위를 정한다. M3 문서 작성은 게임 구현 허가가 아니다.

## 첫 프로토타입과 본편의 구분

[08 제작 범위](08-gdd-mvp.md)의2웨이브는 핵심 행동 검증용이며15웨이브 본편을 대체하지 않는다. 기존 첫 구현에 환생까지 포함하던 계획은 작은 첫 검증과 후속 환생 확장으로 나누는 제안이다. 첫 프로토타입의 완료가 환생의 재미·전체 기획·업데이트 준비 완료를 뜻하지 않는다.

[07 검증 계획](07-validation.md)은 실행 전이다. 일정은 재사용/3D 자산 조사 전 미산정. M3 검토가 끝나도 명시적 개발 요청 전 코드·셰이더·장면 제작이나 게임 테스트를 시작하지 않는다.

## 현재 확정된 유지 규칙

마지막 완공 집 파괴 시 패배. 환생은 정비 중 제단 조건으로 가능하고 그때만 에테론 정산 지급. 환생 시 기존 환생 강화·미사용 에테론 유지. 최종 클리어/패배는 영구 해금 판정 후 판 내부 데이터를 초기화하고 영구 해금만 다음 판에 유지한다.

현재 초점은 M5 영력 필드 조작 검증이다. 과거 Player 빌드와 플레이 결과는 영력 필드 버전의 증거가 아니며, Unity 임포트와 직접 플레이 확인이 남았다.


최신 범위 구분과 종료 기준은 [11 프로토타입·후속 범위](11-prototype-and-update-scope.md)를 따른다. M5 완료 선언은 아직 하지 않았다.


## 확장 전환 · 2026-09-16

사용자가 현재 프로토타입을 충분히 괜찮다고 평가하고 다음 웨이브와 확장을 요청했다. 첫 검증 사이클을 종료하고 M4 확장 구현 후 M5·12 환생 검증으로 전환했다. M5는 반복 단계이며 본편 상세 기획/출시 검증 완료를 의미하지 않는다.


## 현재 M5 · 13 웨이브 압박 검증

6일 환생판에서 위협이 부족하다는 사용자 피드백을 반영했다. 콘텐츠와 위협 구성을 확장했고 빌드 완료, 혼성 전투와 환생 선택의 플레이 검증을 진행한다. 공개 업데이트 준비 단계는 아직 아니다.


## 현재 M5 · 14 방어·탐험 검증

타워/성벽·탐험 보상·지도·발견물·이전·Blender 동물과 사선 이동을 구현하고 Windows 빌드를 완료했다. 14에 초기 수치/검증 한계/직접 확인 순서를 기록했다. M5 전체 종료가 아니며 다음은 새로운 방어/경제 선택이 기존 웨이브 압박과 환생 동기를 살리는지 확인한다.


## 현재 M5 · 15 전투·성장 개선

병력 AI·타워/성벽/화상 강화·단일 클릭 모달·자원 내구도 피드백을 반영했다. 공전 에너지 볼은 제거했다. 15의 확인 절차와 UI 폴리싱 시점을 기준으로 이어간다. 지금은 기능/정보 전달 UI를 정리하고, 주요 기능과 화면이 안정되는 M5 후반부터 M6에서 시각 체계를 통일한다.

## 현재 M5 · 16 UI 폴리싱 완료

확정한 사이드 메뉴·전리품 모달·16-bit 시각 체계·카메라/시야·입력 개선 구현과 이번 UI 범위 QA를 완료했다. 실제 화면 57장, 자동 확인 11/11, 실제 입력 검증 증거는 16-ui-qa.md에 있다. 다음은 최신 UI를 포함한 전체 플레이 흐름·경제·방어 경험 검증이며 M5 전체와 M6 업데이트 준비는 미완료다.

## 진행 방식

에이전트가 아이디어에 맞는 구체적 추천안과 이유를 먼저 작성한다. 사용자는 중요한 방향을 선택하거나 수정하며, 그 결과를 문서에 반영한다. 단계는 제작 작업 구분이며 교육 과정이 아니다. 필요한 부분은 합치거나 앞당긴다. 구현이 필요한 검증은 개발 요청까지 보류한다. 이후 개발·피드백·업데이트 준비로 이어가며, 이전 구현을 새 기획의 재미 검증 근거로 사용하지 않는다.

### 단계 브리핑 · 사용자 요청

- 연관된 결정은 묶어서 한 번에 제안한다. 단일 예외를 매 답변마다 하나씩 확인하지 않는다. 주제별로 추천 정책·이유·미정 사항을 함께 제시하고, 사용자는 묶음 채택 또는 필요한 부분만 수정할 수 있다. 채택된 내용과 새 제안은 구분한다.

- 브리핑에는 마일스톤 ID와 이름, 기획 문서 번호와 이름, 상태를 함께 표시한다. 형식: “현재: M1 핵심 기획 — 05 성장·경제 / 진행 중”. 마일스톤과 문서 번호는 다른 분류임을 유지한다.
- 여러 단계가 겹치면 현재 작업과 미완료를 명시한다. 현재 M1 완료, M2·06 초기 콘텐츠와 플레이 흐름 진행 중. 전체 기획 완료는 아직 아니며 M3 최소 개발 범위·검증 계획까지 정리한다.
- 매 답변에서 현재 큰 절차와 실제 작업 주제를 짧게 밝힌다. 예: “M2 콘텐츠·플레이 흐름 — 06 초기 콘텐츠 구성 / 진행 중”. 번호만으로 진행 상태를 전달하지 않는다.
- 의미 있는 진척이 있으면 이번에 완료·확정한 내용과 다음 작업을 알린다. 단순 질문에는 짧은 현재 위치 표시만으로 충분하다.
- 개별 규칙 묶음 완료, 마일스톤 완료, 전체 기획 완료를 구분한다. 문서 생성이나 사용자 결정 하나를 전체 완료로 과장하지 않는다.
- 단계 완료 시 “○○ 단계 완료 → 다음은 ○○”를 명시한다. 전체 기획은 핵심 명세·초기 콘텐츠·최소 개발 범위·검증 계획이 정리된 시점에 완료 여부를 판단한다. 미정 사항은 개발 전 필수 결정과 추후 검증 항목으로 구분한다.
- 기획 완료 시에도 개발을 자동 시작하지 않는다. 사용자의 명시적인 개발 요청을 기다린다.
- 현재 브리핑: M1 핵심 기획 완료, M2 콘텐츠·플레이 흐름 진행 중. 문서 05 경제·밸런스에서 시작 재화 0과 첫 수치 기준 채택. 전체 기획은 아직 완료되지 않음.

## 전체 제작 흐름과 현재 위치

현재는 **M2 콘텐츠·플레이 흐름 설계** 단계다. M1 핵심 기획은 사용자 방향 확정으로 완료했다. 문서 단계 번호는 주제별 분류이며 완료 순서나 개발 진행률이 아니다. 05·06을 논의했다고 01~04가 모두 끝난 것은 아니다.

|---|---|---|
| 게임 방향·타깃·경험 | M1 타깃·경험 확정 완료 | 최신 주민 수 방식에 맞는 짧은 방향 문서 |

### 다음 기획 우선순위

1. 완료: 모든 집 파괴 패배, 정비 시간 환생으로 기본 경계 확정.
2. 완료: 마을·인구·병력·일반 재화·일반 강화 초기화, 환생 강화·특수 재화 유지. 판 종료 시 특수 재화는 미정.
3. 주민 증가·병력 순찰·건물 고도화와 처음 사용할 콘텐츠 묶음을 정한다.
4. 웨이브 수·시간·보상·비용의 임시 값을 잡고 최소 개발 범위 및 검증 계획을 작성한다. 수치는 실제 검증 후 수정한다.

작은 입력 예외를 모두 확정할 때까지 큰 설계를 미루지 않는다. 기본 흐름에 필요한 예외만 먼저 처리한다. 구현은 명시적인 개발 요청 이후에만 시작한다. 공개 배포 권한은 별도 확인하며 이번 절차 정리는 일정이나 출시 완료 약속이 아니다.

- 최신 경계 결정: 모든 집 파괴 시 다른 건물과 무관하게 패배. 웨이브 종료 후 정비 시간에 환생. 시작 상태로 초기화하되 환생 강화·미사용 특수 재화·영구 해금 유지.

- M1 상태: 완료. 타깃·핵심 경험·기본 규칙 연결. 세부 예외·잔액 처리는 후속 작업으로 이관.
- M2 상태: 진행 중. 중세 판타지·건물 9종·병력 4종·마물 목록은 사용자 지정. 세부 역할·해금·스킬·소개 순서는 제안 검토.

- 최신 콘텐츠 결정: 중세 판타지·마물 침공. 집, 목재·돌 자동 수급 건물, 인구 상한 농장, 병영, 연구소, 제단, 화살·마법 방어탑. 전사·궁수·마법사·기사. 슬라임·고블린·고블린 전사/주술사·오크·리자드 등.

- 최신 배치 결정: 새 집은 기존 마을 영역 안에 배치, 완공 시 영역 확장. 영역 밖 신규 집 불가.

- 최신 영역 축소 결정: 남은 집으로 영역 재계산. 영역 밖 기존 건물은 존속·정상 작동. 신규 건설은 현재 영역 안으로 제한.

- 최신 인구 결정: 건물·영역 변화 시 주민·상한 즉시 재계산, 커서 범위·효율 갱신. 줄어든 범위의 남은 작업 유지. 재건 시 회복, 변화 원인 표시.

- 최근 완료 묶음: 건설·파괴·복구 처리 확정. M2 전체는 진행 중이며 자동 수급·생산·순찰은 새 제안이다.

- 최근 운영 결정: 자동 수급·주문 선불·순차 생산·미진행 생산비 환급·병영 집결점·순찰·추격 제한·집결점 변경 시 기존 병력 재배치 채택. M2 마물·웨이브 구성은 새 제안.

## 판 종료와 에테론 지급 · 사용자 확정

- 에테론은 환생할 때 이번 진행 성과를 정산해 지급한다. 웨이브 클리어 또는 최종 클리어·패배 시에는 지급하지 않는다.
- 환생은 같은 판 안의 재시작이므로 기존 환생 강화와 미사용 에테론을 유지하며, 새 정산분으로 환생 강화를 구매할 수 있다. 마을·주민·병력·일반 재화·일반 강화는 시작 상태로 초기화한다.
- 최종 클리어·패배하면 해당 판은 종료된다. 에테론 잔액·환생 강화·일반 강화·재화·마을·병력 등 모든 판 내부 진행 데이터는 다음 판에 이월하지 않는다.
- 판 종료 성과로 영구 해금 조건을 판정하고 해금 결과를 보존한 뒤 판 데이터를 초기화한다. 영구 해금만 다음 판에도 유지하며, 새 판은 정의된 시작 상태로 시작한다.
- 이는 게임 진행 데이터의 유지 규칙이다. 환경설정 등 비플레이 데이터 삭제를 뜻하지 않는다. 이전 문서의 판 종료 에테론 잔액 미정·종료 시 지급 검토는 이 결정으로 대체한다.
- 돈·교역소 및 구체 환산 계수는 여전히 제안 상태다. 이번 결정으로 함께 채택하지 않는다.

- 현재 다음 행동: 에테론 지급·판 종료 유지 범위 확정 완료. 돈·교역소 도입안을 정리한 뒤 초반 비용/시간과 환생 정산식을 연결한다. M2 — 05 경제·밸런스 진행 중이며 전체 기획은 미완료.

- 최신 제안 v0.5: 돈은 병력/일반 강화, 재료는 건설/수리. 교역소 목재20·1×1·공사10초, 판매 목재1=돈1·석재1=돈2, 전사 돈10·10초, 일반 강화 첫 단계 돈30 비교안. 미채택·미검증.
- 다음 작업: 위 비용/교역 묶음 검토 후 에테론 정산식·환생 강화 효과와 가격을 연결한다. 첫60초/정비45초는 계속 제안이며 배치 가정이 필요한 문서상 계산만 수행. M2 — 05 진행 중.

- 최신 사용자 결정: 교역소 자동 환전 On/Off 토글, 교역소1개 제한. 보존량·가격·환율은 미확정.
- 현재: M2 — 05 경제·밸런스 / 06 시각 방향 진행 중. 3D 픽셀 아트 표현 가능성 검토와 제작 방향 제안. URP17.0.4 의존성 확인, 구현/화면 검증 없음.

## 일반 동작 버튼

건설 `Build.Item`을 기준으로 게임 메뉴 등 일반 동작 버튼의 모양과 상태 피드백을 통일한다.

| 항목 | 기준 (RGBA, 0–1) |
| --- | --- |
| 배경 Image | (0.09, 0.14, 0.20, 1) |
| Outline | 금색 (0.75, 0.57, 0.27, 1), Effect Distance (1, -1), Use Graphic Alpha 활성 |
| Normal tint | (1, 1, 1, 1) |
| Highlighted tint | 민트 (0.48, 0.90, 0.86, 1) |
| Pressed tint | 청록 (0.24, 0.82, 0.73, 1) |
| Selected tint | Unity 기본 (0.96, 0.96, 0.96, 1) |
| Disabled tint | 회색 (0.40, 0.40, 0.40, 0.65) |
| 전환 | Button Color Tint, Color Multiplier 1, Fade Duration 0.1초 |

상태 색은 배경 Image에 곱해지는 tint이며, 최종 화면 색을 의미하지 않는다. Outline은 배경 Image에 붙이고 텍스트에는 붙이지 않는다. 비활성 버튼은 `interactable=false`로 동작과 피드백을 함께 차단한다. 현재 마우스 조작 UI는 Navigation None을 따른다.

텍스트는 TMP를 사용하고 Raycast Target을 끈다. 게임 메뉴는 가운데 정렬, 글자 크기 19, 버튼 높이 56, 간격 8을 초기 기준으로 한다. 호버/누름으로 레이아웃이나 버튼 크기를 바꾸지 않는다. 공통 닫기 버튼 등 아이콘 버튼은 원본 프리팹의 스타일을 유지한다.

## 프리팹과 사용자 편집

각 모달 루트의 `PrototypeModalSurface.PauseGameplay`로 게임 진행 정책을 지정한다. 기본값은 false(진행)이며 게임 메뉴/전리품도 기본적으로 진행한다. 스택에 남아 있는 모달 중 하나라도 true면 게임 시뮬레이션을 정지한다. 최상위 모달을 닫아도 아래의 일시정지 요청은 유지한다. 설정은 프리팹에 저장하고 런타임에 덮어쓰지 않는다. 모달 표시 중 월드 조작 차단은 게임 진행 여부와 별개다. 결산/환생/종료처럼 게임 모델이 자체적으로 진행을 제한하는 단계는 이 옵션으로 해제하지 않는다. 블러 배경은 전용 UI 카메라로 매 프레임 갱신하며 캡처 결과는 다음 프레임에 표시한다.

모달 안에서 다른 모달을 열면 이전 모달을 스택에 보존한다. 최상위 모달만 입력을 받고 닫기/ESC는 한 단계 돌아간다. 재시작·게임 종료는 스택을 초기화한다. 배경 블러는 최상위 모달과 블러 배경 자체를 제외한 월드·HUD·아래 모달을 캡처한다. 어두움/블러 반경은 Canvas의 PrototypeModalBackdrop에서 조절한다. Blur Radius는 화면 픽셀 기준 샘플 반경이며 클수록 넓게 흐려진다. Downsample은 블러 계산 해상도를 낮추는 배수이고 1보다 큰 값에서는 반경이 0이어도 축소에 따른 부드러움이 남을 수 있다.

모달창은 `Common/Titled View`를 상속한 Variant를 `Prefabs/Modal`에 둔다. 본문 항목은 Body 아래 기존 Content에 추가한다. 메뉴 버튼 순서는 계속하기 → 다시하기 → 설정 → 포기하기다.

스타일 초기화/마이그레이션은 한 번만 수행한다. 런타임과 반복 임포트에서 사용자 스타일을 덮어쓰지 않는다. Menu의 ButtonStyleVersion 1 이후 Inspector 편집 값을 유지한다. 이후 신규 버튼도 이 문서와 Build.Item을 참고한다.


## 강화 트리 노드 · 2026-09-19

고정 설명 패널 없이 48px 픽셀 아이콘으로 표시한다. 설명·가격·부모 조건은 화면 경계 안의 호버 툴팁을 사용한다. 미강화=슬레이트 얇은 테두리/빈 단계 칸, 강화 중=민트 두꺼운 테두리/채운 칸, 완료=금색 이중 테두리/체크다. 잠금은 별도 배지로 구분하고 상태 배지는 아이콘 위 레이어에 둔다. 트리 viewport는 전체 화면이며 초기/전체 보기/리사이즈 때 모든 노드 bounds와 조작부 여백으로 맞춘다. 미발견 노드도 bounds에는 포함하지만 표시 해금 규칙은 유지한다. 픽셀 에셋은 생성→축소→기술/시각 검사→승인 해시 확인 후에만 게임 폴더로 복사한다. 상세: [강화 트리 아이콘·툴팁·전체 보기](upgrade-tree-icon-tooltip.md).

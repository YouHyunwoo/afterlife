# 과거 배포본과 보관소

과거 Windows64 ZIP4개는 `D:/area/archives/Afterlife/releases/Windows64/<배포 날짜>/`로 옮겼다. 파일명·크기·SHA-256·실제 위치는 [보관 색인](archive-index.json)에 있다. `docs/steam/builds`는 현재 ZIP을 보관하는 위치가 아니다.

새 배포본은 [공용 보관 도구](../../tools/releases/README.md)로 보관한다. 보관은 Steam 업로드와 별개다. 업로드 설정이나 Steam 게시 상태는 이번 작업에서 변경하지 않았다.

# 경제 지대

`Afterlife.EconomicSites`는 Unity 의존성이 없는 지도 지대 배치 모듈이다. 동일한 지도 시드·육지 격자·설정이면 비옥한 땅과 영맥의 위치가 같다. 시작 타일에서 상하좌우로 도달 가능한 육지만 사용하고, 지대 전체가 설정 최소 거리와 주택 SO가 지정한 시작 영역 밖에 있어야 한다. 물·다른 지대·지도 최외곽과 겹치지 않는다.

## 프로토타입 적용

`Resources/AfterlifePrototype/SettingsData/World.asset`에서 종류별 개수·크기와 시작점 최소 거리를 조정한다. 기본값은 종류별 2개, 각 3×3, 8타일이다. 모델은 지형 재생성 직후 `InitializeEconomicSites()`를 호출하고, `PrototypeView.BuildGround()`가 지도 자식으로 색 타일과 모서리 표식을 만든다. 지도 오브젝트를 제거하면 표식도 함께 제거된다. 별도 씬 참조·설치 작업은 없다.

생산은 `ProductionYieldMultiplier(Body)`로 현재 건물 부지 전체를 판정한다. 농장은 비옥한 땅, 제단·성소는 영맥에서 생산량이 2배가 된다. 인접 농장 보너스는 생산 주기에 별도로 적용한다. 배치 화면은 `EconomicSiteAt(x,z)`와 `EconomicSiteTooltip(kind,x,z,width,depth)`를 사용한다. 지대는 판 시작에 한 번 만들며 플레이 중 건물 이동이나 자연물 생성으로 재배치하지 않는다.

## 수동 검증

Unity 에디터에서 같은 `MapSeed`로 새 판을 여러 번 시작하면 지대 위치가 같아야 한다. 다른 시드에서는 위치가 바뀔 수 있다. 각 지대가 접근 가능한 육지의 시작 영역 밖에 있고 서로 겹치지 않는지 확인한다. 농장·제단·성소를 지대 안과 밖에 놓고 생산량이 각각 2배와 기본값인지 확인한다. 2×2 성소는 전체 부지가 영맥 안에 있어야 한다. 판을 다시 시작하면 오래된 지대 표시가 남지 않아야 한다.

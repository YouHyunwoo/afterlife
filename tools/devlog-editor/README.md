# Devlog 영상 편집기

Unity Recorder 영상과 원본 음원을 독립 트랙으로 편집하여 MP4로 합성하는 로컬 GUI다. 소리는 48kHz PCM 타임라인을 먼저 만든 뒤 영상과 결합한다.

## 실행

프로젝트 루트의 `tools/devlog-editor/start.cmd`를 더블클릭하거나 프로젝트 루트 PowerShell에서 `.\tools\devlog-editor\start.cmd`를 실행한다. 열린 터미널 창을 유지하고 http://127.0.0.1:8767/ 에 접속한다. 창에서 Ctrl+C를 누르면 서버가 종료된다. 이미 서버가 실행 중이면 새로 켤 필요 없이 주소로 접속한다. 기존 `.tooling/day01-tts/venv` 환경을 사용한다. 다른 환경에서는 Python 3.12에 `requirements.txt`를 설치한 뒤 프로젝트 루트에서 `python tools/devlog-editor/server.py`를 실행한다.

오른쪽 **영상 에셋 → 영상 불러오기**에서 브라우저 파일 선택기로 영상을 추가한다. 업로드 진행률과 가져온 영상 목록을 확인할 수 있다. 에셋을 선택해 프리뷰하거나 영상 트랙에 끌어 놓고, **선택한 에셋으로 클립 만들기**로 구간 편집 창을 열 수 있다. 파일 선택이 어려우면 **파일 경로로 연결**을 쓴다. 메인 프리뷰와 클립 구간 창의 영상 높이는 각각 슬라이더로 조절한다. 브라우저로 가져온 파일은 `devlog/youtube/day-01/media/video/imports/`에 저장되며 프로젝트 JSON을 저장하면 에셋 목록도 함께 보존된다. 기본 MP4 출력은 같은 `media/video/exports/`에 둔다.

## 트랙과 클립

첫 화면에서 **프로젝트 생성** 또는 **프로젝트 열기**를 선택한다. 새 프로젝트는 이름과 저장 폴더를 지정해 `이름.devfilm.json`으로 생성한다. 저장 폴더 입력창을 클릭하면 Windows 기본 폴더 선택 창이 열리고, 필요하면 경로를 직접 입력할 수 있다. 저장 가능한 폴더는 Afterlife 작업 폴더 안이다. 프로젝트는 빈 타임라인으로 시작한다. 편집 화면 상단에 이름과 경로가 표시되고 **프로젝트 → 새 프로젝트 / 열기 / 저장**, **내보내기 → MP4 내보내기**를 사용한다. `Ctrl+S`로도 저장할 수 있다. 저장하지 않은 편집이 있을 때 다른 프로젝트를 열거나 새로 만들면 확인을 거친다.

1. 영상·오디오·자막 중 종류를 선택하고 **트랙 추가**를 누른다.
2. 트랙을 선택한 뒤 **클립 만들기** 또는 트랙 왼쪽 **＋**를 누른다.
3. 영상/음원 파일을 선택하거나 경로를 불러온다. 클립별로 다른 원본 파일을 쓸 수 있다.
4. 클립을 좌우로 드래그해 시작 시간을 바꾼다. 위아래로 드래그하면 같은 종류의 다른 트랙으로 옮긴다.
5. 클립을 **더블클릭**하면 구간 편집 창이 열린다. 원본 프리뷰 아래 한 트랙에서 양 끝 손잡이는 시작/끝을 변경하고, 몸체는 길이를 유지하며 원본 구간을 이동한다. 구간 확대와 숫자 입력도 가능하다. **확인**만 적용하고 **취소/Esc**는 원래 상태를 유지한다.
6. 영상·나레이션·자막은 서로 독립적이다. 영상을 옮겨도 음성과 자막은 따라가지 않는다. 음원과 자막도 각각 드래그·복제·삭제·편집할 수 있다.
7. **미리듣기 합성·갱신 → 재생 → 저장 → MP4 내보내기** 순서로 확인한다. 오디오 합성 전에는 영상만 재생할 수 있다.

시간 눈금은 드래그로 탐색한다. 최대 300px/초 확대, 스냅 ON/OFF 및 0.1/0.5/1/5초 간격을 지원한다. 타임라인과 구간 모달의 드래그는 동일 스냅 설정을 사용한다. 실수는 **되돌리기 / Ctrl+Z**로 최대 40단계 복구한다.

영상은 위쪽 트랙이 우선한다. 같은 영상 트랙 안의 겹침은 제한하며, 겹쳐 놓으려면 다른 영상 트랙을 사용한다. 표시 가능한 영상이 없는 구간은 검은 화면이다. 모든 트랙이 비어도 최소 길이만큼 검은 영상으로 내보낼 수 있다. 오디오는 켜진 트랙을 합산한다. 위 영상에 가려진 영상의 원음은 재생하지 않는다. 트랙 왼쪽 끄기/켜기와 ↑/↓로 우선순위를 조절한다.

## 자막·음악·크레딧

녹화본에 이미 포함된 자막과 크레딧은 이미지의 일부이므로 제거되지 않는다. 오른쪽 **오디오 믹서·출력 설정 → 자막 트랙 표시·내보내기**를 켜야 편집기 자막이 추가된다. 텍스트를 바꿔도 TTS 음성은 재생성하지 않는다. 나레이션 클립에서 새 파일을 연결한다.

배경음악은 오디오 트랙의 독립 클립이다. 음원 종류를 배경음악으로 선택하면 음악 볼륨·페이드·크레딧 배율을 적용한다. 반복 옵션을 켜면 4초 이하 크로스페이드로 반복한다. 길이는 타임라인 길이 입력으로 늘릴 수 있다. 배경음악도 클립이 없는 구간에는 나오지 않는다. 기존 크레딧 영상 클립의 `credits: true`를 변환 시 유지한다. 공개 크레딧은 `docs/audio-credits.md`를 확인한다.

## 저장 및 이전 데이터

기존 Day01 프로젝트는 `devlog/youtube/day-01/edit-project/day01.devfilm.json`에서 **프로젝트 열기**로 선택한다. 구버전 샷 데이터는 열 때 메모리에서 변환하고 저장 전에는 원본 JSON을 덮어쓰지 않는다. 기존 전체 오프셋은 각 영상 클립의 원본 시작에 합쳐진다. 나레이션 길이는 WAV 길이, 자막 길이는 기존 표시 길이로 각각 유지한다. 기존 프로젝트 저장 시 시간표시 백업을 만든다. 프로젝트 파일을 다른 폴더에 저장하면 리소스 상대 경로를 새 위치에 맞춘다.

## 데이터 계약

`schemaVersion: 2`, 시간은 초, 경로는 JSON 기준 상대 경로 또는 절대 경로다.

|필드|역할|
|---|---|
|tracks[].id / name / kind / enabled|트랙 식별자·이름·video/audio/subtitle·활성 여부|
|tracks[].clips[].id / title / start / duration|클립 식별자·이름·타임라인 시작·길이|
|영상/음원 클립 path / sourceIn / volume|원본 파일·파일 내부 시작·개별 음량|
|영상 padEnd / credits|끝 프레임 유지·크레딧 음악 배율 구간|
|음원 role / loop|narration/music/effect·반복 여부|
|자막 text|독립 텍스트|
|minimumDuration|모든 트랙이 비었을 때도 유지할 최소 길이|
|narrationVolume / video.volume / music|종류별 음량 및 음악 페이드·크레딧 배율|
|export|해상도·프레임·자막 출력 여부|

`video.path`는 새 영상 클립의 기본 소스이고, 기존 `video.offset`은 v2 재생에는 적용하지 않는다. 실제 재생 소스는 클립의 path/sourceIn만 사용한다. 최대 32트랙·1000클립·1시간을 지원한다.

## 모듈 및 검증

- `project.py`: 저장·경로 변환·구버전 호환.
- `timeline.py`: 트랙 모델·v1→v2 변환·검증·영상 우선순위 구간 계산.
- `render.py`: FFmpeg·오디오 공통 유틸리티와 구버전 렌더링.
- `render_tracks.py`: 독립 오디오 합성·레이어/공백 영상 출력·자막.
- `server.py`: 로컬 API·등록 원본 스트리밍·작업 진행.
- `media_library.py`: 브라우저 영상 전송·검증·중복 제거·등록.
- `ui.html`, `editor.css`, `editor.js`: 화면·트랙 드래그·구간 편집 모달.

검증: `.tooling/day01-tts/venv/Scripts/python.exe tools/devlog-editor/test_editor.py`, `node --check tools/devlog-editor/editor.js`.

중간 산출물은 `.tooling/devlog-editor/`에 둔다. 파형·썸네일 스트립, 투명도/크기 기반 영상 합성, 전환 효과, TTS 생성 기능은 제공하지 않는다. 영상은 각 트랙의 전체 화면 컷으로 합성한다.

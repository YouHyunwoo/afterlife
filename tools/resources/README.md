# 리소스 목록 도구

저장소 루트에서 `python tools/resources/update_manifest.py`를 실행하면 `res/manifest.json`의 파일·크기·SHA-256·출처 분류를 갱신한다. Unity 에셋과 메타데이터는 수정하지 않는다.

목록 자체, Python/분석 실행 캐시, 로컬 설치본, Blender 자동 백업, 운영체제 설정 파일은 제외한다. Graphify 최종 보고서·그래프는 자료로 유지하고 `cache/`와 숨김 실행 상태는 제외한다. 이전 개발일지 명령은 호환 어댑터로 유지한다.

검증은 목록 경로의 존재와 SHA-256을 실제 파일과 비교한다. 출처 분류는 라이선스 확인을 대신하지 않는다.
